## 状态

## 原因与修复

v8 将使用中心锚点的 root 设置为 `SetAnchoredPosition(physicalW/2, physicalH/2)`。root 即使没有客户端父记录，仍位于宿主容器中，这个值会额外引入半画布的偏移。旧离线模型又对 root 减去相同的半画布量，把错误抵消，因此旧测试通过不能证明实际宿主布局正确。

中断前已将测试模型改为显式宿主容器模型。保留的 v8 更正记录记载：在 1600×1200 案例中，旧版根中心偏移为 (+800,+600)，23 项断言失败，61 条抽查越界。这是与截图症状一致的模型证据，不是实机坐标测量。

v9 将根位置改为 `SetAnchoredPosition(0,0)`，保留中心锚点、中心 pivot 与按当前画布计算的尺寸和等比缩放。新增对位置、尺寸、缩放、锚点及 pivot 的回读，未达到预期时下一次刷新重试。回归增加外部覆写根位置后恢复居中的场景。

保留 v7 首页初始化修复，以及 v8 的统一逻辑坐标、常驻不透明底色、选关底色覆盖、背景子层逐层显隐等处理。未修改玩法、线索与身份规则。
