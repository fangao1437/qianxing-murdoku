## 一、阴影：从「借边界的矩形」改成设计图的完整多边形

v17 用 `x[900,1263] / y[170,763]` 的半透明黑矩形，上边界是水平线、左边界是垂直线，
全靠胶带与档案袋遮挡才「看起来」有斜边；一旦遮挡不完整（左／上／下多个区域），
边界就缺失或露出不正确的直边。

v18 直接从设计图量出**四条边**，全部显式构造、都是清晰硬边：

| 边 | 设计图依据 | 顶点 |
|---|---|---|
| 上 | POLICE 胶带下缘斜线 | `(990,255) → (1263,212)` |
| 左 | 档案袋右缘斜线 `x=924+0.2755y` | `(990,255) → (1115,695)` |
| 下 | 档案袋底边 | `(1115,695) → (869,763)` |
| 右 | 屏幕竖直分界 | `(1263,212) → (1263,763)` |

凹角拆成 Q1 / Q2 两个凸块；另补两块设计图实测的三角形：

- **上侧阴影** TUP `[(1250,50),(1185,150),(1270,150)]`，色 `#6C2D15`
  （胶带上方、咖啡杯左下那块深棕三角，v15–v17 一直没做）；
- **左侧缺口** TLEFT `[(996,255),(1055,255),(1013,303)]`，色 `#B44926`
  （胶带下方较亮红棕三角，逐行实测 y260 x996–1053 / y280 x1001–1035 / y300 x1006–1017，
  到 y303 收尖）。

按 x 分 3 带（`<1100` / `1100–1200` / `>1200`），颜色取设计图阴影区实测中值
`#94391A` / `#8F381A` / `#873619`，保留右侧渐变的明暗过渡。
每块用 `qianxing-murdoku-tool/art/tools/fit-primitive-shape.mjs` 的 **A+B+C 顶角三角**
生成**不透明** `100003`（同色不透明重叠无缝，避免半透明叠层压暗），
共 8 块 / **114 枚**，全部 100% 或 ≥99.5% 覆盖、**0 溢出**（`shadow-elements.json`）。

误差（与设计图棕色背景掩膜 MAE）：

## 二、橙红区贴到档案袋边

设计图 y=520/560/600 处，深红背景**直接接**橙红 RED（边界 419/430/440）；
v17 中间夹了一条约 19px 的亮橙 BAG 带（400–417 / 411–428 / 422–439）。
原因是档案袋左缘 `x≈256+0.2755y` 比设计图靠左约 19px。

**`BAG_U0` 由 `-310` 改为 `-291`**（沿局部 u 右移 19px，档案袋左缘整体右移 19.6px），
使袋左缘与 RED 楔形左缘重合，中间亮橙带消失。渲染复核：v18 楔形左侧直接是深红背景，
与设计图一致（见 `preview/bag-edge-design-v17-v18.png`）。
