## 二 ★★★★ 两条根因（★ 都在源码里，都已改）

### 2.1 ★ 规划侧的 `rect` 把「编辑器几何优先」绕过去了（★ 主因）

| 位置 | 原来 | 现在 |
|---|---|---|
| `ui_controller.lua` `render` 里 `if n.pos_runtime then adapter.runtime_rect[id] = true end` | ★ 无条件接管 ✗ | ★ **继承来的 `pos_runtime` ⇒ && `cfg.geom_by_editor` ⇒ 不接管** ✓ |

★ 判据分三档（★ 一句话记住 ✓）：

| 节点的 `pos_runtime` | 谁说了算 | 例子 |
|---|---|---|
| **显式 `true`** | ★ **脚本** | `root`、`room.label.*`、`select.card.N.room.M`、弹窗键、缩略图色块 |
| **继承来的 `true`** | ★ **编辑器**（`geom_by_editor = true` 时）| `stage`、`settle.btn`、`select.card.N`、`home.*`、`hud.*`、`clues.*` |
| **显式 `false`** | ★ **编辑器** | `clues` / `clues.bg` / `clues.grid` / `clue.*` |

★ 例外照旧 ✓：★ **脚本自己建的控件**（`adapter.instantiated`，例如 25 个格子）→ 仍由脚本摆 ✓
　（它们本来就不在存档里，没有"编辑器几何"可言 ✓）

### 2.2 ★★ `inherit_pos_runtime` 里那句 `not n.pos_runtime` —— **一个 Lua 语义错** ✗✓

```lua
if (not n.pos_runtime) and n.parent ~= nil and pr[n.parent] then   -- ✗ 旧写法
```

★ Lua 里 **`not false` 也是 `true`** ⇒ ★ 它**分不开**「显式 `false`」与「没表态」✗
⇒ ★ 后果：`clues` 明明显式写了 `pos_runtime = false`（注释里还写着"该节点不继承" ✓），
　 却仍然从 `root(true)` 继承成 true ⇒ ★ **`clues.bg` / `clues.grid` 被脚本按 400×544 的规划框盖掉** ✓
　 ⇒ ★★ 这正是你那句「**网格视窗的大小我已经改了**」一直不生效的原因 ✓（v248 一并修掉 ✓）
★ 同一句错也吃掉了 `clue.N` / `clue.N.backrop*`（2026-10-05 就写着"位置归编辑器" ✗）
★ 改法：`n.pos_runtime == nil`（★ 只有**没表态**的才继承 ✓）

### 2.3 ★ 随件必须跟着"主人的框"（★ 本轮新增 `Controller:editor_card_box`）

★ 卡归编辑器之后，卡上的**关名 / 进度 / 房间缩略图**如果还按规划里那份 100% 的卡算 ✗
　 ⇒ ★ 屏幕上就是"**卡缩了、字和缩略图还在原来那个大位置上**" ✓（比不修更难看 ✓）
★ 所以：★ **读运行时那张卡**（`GetSizeDelta` + `GetAnchoredPosition`）→ 反算回设计空间 → 随件按它算 ✓
★ 两个坑（★ 都踩过 ✓ 写在这里省下一位 ✓）：
　 · ★ 控制器上**没有** `self.adapter` 这个字段 ✗（`main.lua:510` 那个是 **Murdoku 实例**的 ✓）
　　⇒ ★ 必须由 `render(adapter)` 传下去（`self:build_layout(adapter)` ✓）；
　　★ 我第一版写 `self.adapter` ⇒ **恒 nil** ⇒ 静默退回规划框 ⇒ 量出来"没生效" ✓
　 · ★ `.title` / `.info` **必须显式 `pos_runtime = true`** ✓ —— 它们是"每关算的内容" ✓
　　（不写就变成"继承来的" ⇒ 归编辑器 ⇒ 停在旧卡位上 ⇒ 截图里关名跑到卡**外面** ✓）
