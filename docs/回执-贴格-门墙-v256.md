## 〇 结论

| 问题 | 根因 | 修复 |
|---|---|---|
| 家具/提示**溢出格子** | ① `face`/`hint`/`obj` 的 **imageType 没写 = Basic** ⇒ 图片**按自己原尺寸画**，盒子 135 也没用 ② 子控件是编辑器里的 **135×135 定值**，而格子边长随关卡变（5×5 = 108 画布 / 6×6 = 89 画布）| ① 存档里把三个子控件的 `imageType → 1(Stretch)` ② 脚本按**界面层算好的格子边长**把三层钉成同尺寸、居中 |
| 门墙**不像设计图** | ① 颜色是占位色（墙 `0xFF3310A0` 紫 / 门 `0xFFD6DE1A` 黄绿）② 门太长（0.45 个格边长）| ① 存档改成 **近黑墙 `0xFF2B2B33` / 橙门 `0xFFE2622F`** ② `door_length_ratio` **0.45 → 0.30** |
| 图层顺序 | `hint` 没进 `layer_order`（层序由脚本重排，名单里没有就不会被排） | `layer_order` 插入 **`hint`（face 之上、obj 之下）** |

★ 另修一条**隐藏的**老 bug：`size_of()` 原来定义在文件**后面**，而 `_apply_edges`（很靠前）在调它 ⇒
　 真机/模拟器里 `attempt to call a nil value (global 'size_of')` 被 `pcall` 吞掉 ⇒ **墙/门的"按基准缩放"一直没生效** ✓
　 ⇒ 已把 `size_of` 提到文件靠前，并**两种返回形状都认**（真机两数 / 模拟器一个数组）✓
