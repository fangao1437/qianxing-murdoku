## 五、踩过的坑（按"形状"归类，别再犯）

> 这一整轮下来，教训比代码值钱。完整版在 [工作约定-优先直改控件.md](工作约定-优先直改控件.md)。

| 形状 | 表现 | 正解 |
|---|---|---|
| **同名概念多处定义** | 改一处另一处不变 | **只留一处定义** |
| **复用多义标记** | 借用 `instantiated` ⇒ 控件被**真销毁** | **先 grep 全部读取方**，或新建语义单一的小标记 |
| **`and nil or`** | `x and nil or y` 恒为 `y` | 含 nil/false 的分支写**显式 if** |
| **`pairs` 里 `nil` = 键不存在** | "清空"语义永远下发不了 | 清空用 **`false` 哨兵** |
| **断言锁死实现** | 实现一变测试就红，误报成 bug | 只锁**用户可感知的行为** |
| **用自己的解析器验证自己写的文件** | 循环论证 | 拿**编辑器认可的文件**当模板逐字段对齐 |
| **不看报错先推断** | 白查三轮 | **改完先看运行时报错** |
| **改完 Lua 不重新打包就跑测试** | 假红 4 条，差点改坏设计 | **先 bundle 再测** |
| **PowerShell 里 `\r\n` 是字面量** | 正则永不匹配 | 用 `\s+` 或 `` "`r`n" `` |
| **挪代码用 `TrimStart()` 裁切** | 把相邻语句一起吃掉 | **整段剪、整段贴** |
| **猜"睡多久"** | 单独跑绿、放进全量就红 | **轮询到条件成立** |
| **手改第三方二进制** | 把能用的文件改成导入会卡住的 | **工具导出什么就传什么** |

## 六、素材相关（两条路都通）

**⇒ A. 游戏自带 1543 个图片素材**（不需要导入 ✅）
目录：`https://qx.070077.xyz/api/library/catalog`，14 类
```powershell
node tools\qx\library.mjs fetch
node tools\qx\library.mjs sheet --cat=道具 --max=139
```
**⇒ 已在用**：`111051`(书架) `111064`(展示柜) `111050`(书桌) `106053`(地毯)

**⇒ B. 自己画 → 导出 `.gia` → 转存**（任意图形 ✅）
```
写 scene JSON → POST /api/export/gia → **原样**放进
  C:\Users\...\BeyondLocal\Beyond_Local_Export
→ 游戏里「导入外部资产 → 选中 → 转存所选资产」→ 素材库 → 把模板索引告诉我
```
**⇒ 已在用**：`murdoku-btn-hex`(1073742321) `murdoku-card-frame`(1073742325)
`murdoku-cell`(1073742329) `murdoku-clue-row`(1073742333)
`murdoku-panel`(1073742337) `murdoku-tape`(1073742340)

**⇒ 接入方式**：`cfg.prefab_of[节点id] = 模板索引` + `cfg.parent_of[节点id] = 父节点`
（登记在 `lua/entry_client_script.lua` ✅），适配器 `InstantiateClientUIControl` 把它造出来 ✅。

⚠️ **这类节点绝对不能进 `.gil`** ✅ —— 一旦进了，`find(id)` 会先找到那个空控件，
就永远不走实例化了（画面上一块空白）✅。`sync_plan` 的跳过名单里已经排除了它们 ✅。
