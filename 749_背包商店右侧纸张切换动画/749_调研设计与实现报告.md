## 一、千星沙箱 UI 动画能力与真机约束调研

调研来源：`docs/api-cache/mhtakr07vej4.txt`、`docs/7.1-脚本API速查.md`、`docs/API-四方对照.md`、`docs/社区知识-千星奇域-UGC-踩坑与最佳实践.md`、`docs/转换器-gil到模拟器存档.md`。

| 能力维度 | 引擎支持情况 | 真机实测风险与本项目决策 |
|---|---|---|
| 父子容器级联变换 | `ClientUIContainerControl` 支持 `SetAnchoredPosition` / `SetLocalScale` / `SetLocalRotation`，所有子控件同步继承父级平移、缩放与 Z 轴旋转 | **采用**：每帧只驱动 2 个容器节点（`anim.sheet`、`anim.under`）+ 1 个投影节点（`anim.shadow`），避免逐个操作 60+ 散落控件 |
| 原生 `game.Tween` / `TweenSequence` | 存在且标记支持 `anchoredPosition` / `localScale` / `localRotation` / `imageColor` | **不采用**：社区真机记录显示：① 隐藏期间 Tween 后台继续写；② 连续切换易发生双 Tween 覆盖打架；③ 旋转 `localRotationZ` 读回 `[0, 360)` 易在负角向 0° 补间时绕远路。改为 `OnUpdate(dt)` 纯数学解析缓动，零残留、可任意帧无缝打断 |
| 整组透明度（CanvasGroup） | **无** `CanvasGroup` / 节点级 `alpha`；且真机全局 `Color()` 不存在 | **采用**：仅对投影图元 `anim.shadow` 用整数 `0xAARRGGBB` 调制 `imageColor`（动态落影收敛），纸张主体靠物理双层叠压 + 2px 纸边轮廓线（`anim.rim`）区分新旧纸边界 |
| 图片遮罩 `enableMask` | API 存在，但 748 全档 6,248 个图片控件中未启用过 | **不依赖**：不引入未经真机验证的遮罩组件，改用合理偏移轨迹与严格 z-order 层序保证视觉干净、绝不压住外框/顶栏/按钮/确认弹窗 |
| `pos_runtime` 坐标覆写 | `build_layout` 对所有 `econ.*` 设了 `pos_runtime = true`，`Controller:render(force)` 会回写 `SetAnchoredPosition` | **精准规避**：排除 `%.anim%.` 容器走 `pos_runtime`，使动画期间即使触发整页 `render(force)` 也不会把运动中的纸张拉回静止位 |

## 二、方案设计：「双纸层容器 + 落地阴影 + 解析缓动」

### 2.1 控件树重组（保持 100% 原静止视觉与层序）

在 `econ.ui742` 下为商店与背包各自建立一对以纸张中心为轴心的同级容器（同步对齐 `childList` 与序列化 `holder` 顺序）：

1. **调查商城右侧（轴心 `(448.33, -28.33)`，尺寸 `510 × 660`）**：
   - 保持固定不动：外木框 `s8`（位于下方）、底部取消/购买按钮与热区 `s71..s74 / cancel / purchase / hit.clear / hit.purchase`（位于上方）、右上钱包栏 `s75..s78 / currency / wallet`、确认弹窗 `s148..hit.yes`（最顶层）。
   - `econ.shop736.anim.under`（旧纸层，平时隐藏）：完整克隆纸面、标题铭牌与 22 段缝线、图框/说明框/四颗图钉、两套道具图标（`s110..s122`、`s125..s132`）及 5 个介绍文本框（`name / price / owned / desc / status`），用于过渡期定格展示「上一份介绍」。
   - `econ.shop736.anim.sheet`（新纸层，紧压在 `anim.under` 上方）：内含过渡期动态投影 `anim.shadow`、2px 暖棕纸边轮廓 `anim.rim`，以及原 63 个商店右侧介绍控件（相对坐标平移 `-shopBase`，静止世界坐标与 748 误差 `< 0.001px`）。

2. **调查背包右侧（轴心 `(395.67, -44.0)`，尺寸 `408.5 × 616.33`）**：
   - 保持固定不动：皮箱内胆、原倾斜装饰底纸 `paper.under`（`-2.11°`，位于下方）、左侧物品格/数量标/点击热区与返回旗。
   - `econ.bag741.anim.under`（旧纸层，平时隐藏）：完整克隆 `paper.top / paper.label / paper.body / pin0..pin3` 及 5 个介绍文本框（`title / meta / desc / usage / history`）。
   - `econ.bag741.anim.sheet`（新纸层，紧压在 `anim.under` 上方）：内含 `anim.shadow`、`anim.rim` 及原 12 个背包右侧介绍控件（相对坐标平移 `-bagBase`，静止世界坐标与 748 误差 `< 0.001px`）。

### 2.2 动效曲线与视觉手感（时长 `0.28s`）

- **商店轨迹**：新纸从右下方轻斜扫入覆盖（`dx = +78~+84, dy = -34, rotZ = -3.4° / -2.5°` 交替微变），既避免覆盖右上调查币栏，又呈现自然的递纸覆上手感。
- **背包轨迹**：新纸从右上方微斜飘落覆盖（`dx = +68~+74, dy = +36, rotZ = +3.6° / +2.6°` 交替微变），契合皮箱右侧便签叠的自然落纸方向。
- **缓动组合**：
  - 平移与旋转：`EaseOutCubic`（`1 - (1-u)^3`）—— 干脆入场、末尾轻柔回正；
  - 抬升落地缩放：`EaseOutQuart`（`1 - (1-u)^4`）—— 新纸从 `1.045×` 落贴到 `1.000×`，同时下方旧纸微幅被压至 `0.986×`；
  - 动态投影 `anim.shadow`：随落地进度偏移从 `(15, -18)` 收回至 `(1, -1)`、透明度从 `0x58` 平滑淡至 `0x06`，动画结束瞬间隐藏 `anim.under / anim.shadow / anim.rim`。

### 2.3 状态机与边界处理

- **首次进入页面**：静默记录介绍签名，不播放入场动画。
- **任意介绍变化触发**：包含选中道具、切换道具、取消选择、以及商店提示文案变化（如「请先选择道具」「调查币不足」）。重复点击同一道具介绍未变时不重播。
- **快速连点打断**：旧纸层立刻接管上一份最新快照，新纸从起点流畅重播，绝不卡半路或错字。
- **离页/切页兜底**：一旦离开 `shop`/`bag` 或在两页间切换，立即停止动画、隐藏旧纸/阴影/纸边并归位新纸至精确基准坐标，确保无残影。
- **零稳态开销**：全部新控件均在 `STATIC_PATH_655` 登记 O(1) 静态路由；非商店/背包页及稳态帧 0 次引擎 API 调用、0 次 `GetChildren`。

## 六、v4 迭代升级：16 段等弧长柔性弯曲纸带链 + 上/下分段跟随（无半透明、非逐帧的真软纸覆放）

> **新版产物**：`749_背包商店右侧纸张切换动画/749_背包商店右侧纸张切换动画_v4.gil`（`7,893,888` 字节，SHA256 `01d0f3c4d1497b61...`，原 v1 / v2 / v3 存档完整保留）

### 6.1 僵硬根因定位与「不用半透明、也不用逐帧渲染」的两全方案

核查 v3 实机录屏（`20261127-0927-10.7100921.mp4`）后定位了僵硬的两大核心原因：
1. **整张纸仍是单一刚体矩形**：只有整体平移、整体旋转与整体缩放，四条边框在每一帧都保持笔直，人眼一眼识别为“硬纸板滑进来”；
2. **前段位移衰减过快**：`EaseOutCubic` 在前 2 帧就走完大半位移，来不及展示纸张轻拂落下的柔和姿态。

### 10.2 基尔霍夫薄板方程控制模型与边界条件

沿纸张无量纲弧长 $\xi = s/L \in [0, 1]$ 建立一维圆柱可展 **Kirchhoff-Love 薄板弯曲方程**：

$$D \frac{\partial^4 w}{\partial s^4} + \rho h \frac{\partial^2 w}{\partial t^2} + c \frac{\partial w}{\partial t} = q(s, t)$$

选取两组精确解析边界条件模态叠加，并配合临界阻尼式 $C^1$ 时间包络：
1. **悬臂-自由端主落置模态**（上端引导接触 $w(0)=w'(0)=0$，自由底端自然零弯矩 $M(1)=-Dw''(1)=0$、零剪力 $V(1)=-Dw'''(1)=0$）：
   $$P_{\text{kl}}(\xi) = \frac{1}{3}(6\xi^2 - 4\xi^3 + \xi^4), \qquad P_{\text{kl}}'(\xi) = \frac{4}{3}(3\xi - 3\xi^2 + \xi^3)$$
2. **简支气垫穹拱模态**（纸底受空气阻力微拱，两端零弯矩 $w(0)=w(1)=0,\ M(0)=M(1)=0$）：
   $$P_{\text{air}}(\xi) = \frac{16}{5}(\xi - 2\xi^3 + \xi^4), \qquad P_{\text{air}}'(\xi) = \frac{16}{5}(1 - 6\xi^2 + 4\xi^3)$$

由此推导出纸张在 3D 空间的精确出平面倾角 $\phi(\xi, u) = \arctan(\partial w / \partial s)$、离面高程 $w(\xi, u) = \int_0^s \sin\phi\,\mathrm{d}\sigma$ 与投影几何：
- **右手轻拿上右角顺放**（$\theta_{\text{head}} > 0$）：左上角贴底落平（商店实测 `tlY = 264.7 ≤ 265 + 14`），右上角轻扬 `~8.8px`（`trY = 273.8`，距标题铭牌留足 `> 13px` 净空），彻底消除顶边截角与塌角；
- **纯透视平滑宽度**：移除局部 `topPinch`，横向宽度仅由真实焦距 `perspF = 4200` 下的 $w(\xi)$ 透视给出，商店相邻纸带半宽跳变 `maxStepX = 0.44px`（背包 `0.46px`），亚像素级光滑彻底消除右上角台阶感；
- **严格不可伸长与实色朗伯明暗**：每段步长受 $\min(\cos\phi, 1 - hw\cdot|\Delta\theta|/\Delta s)$ 护栏保护，左右纸边弧长严格 $\le$ 静止弧长（`0px` 拉伸、左下角绝不向下戳出）；纸面明暗由 3D 法向 $\sin\phi / \cos\phi$ 朗伯光照明暗驱动，100% 不透明（`alpha = 0xFF`，零半透明产物）；
- **既有约束完整保留**：商店标题铭牌与「取消 / 购买」按钮原位静止且层序居上、逐叶子显隐闭环、购买全流程绝不触发动画、稳态 120 帧 0 开销。
