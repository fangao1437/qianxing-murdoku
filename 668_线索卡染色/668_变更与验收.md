## 一、纠错：上一轮把「删红底」理解错了

667 把用户说的「删红底」执行成「连卡片模板里的阶梯渐变一起隐藏」，结果实机变成全白卡 + 深色字。用户本轮明确：

> 线索卡本身的染色不要删，把原来那个阶梯渐变红色素材放在 backrop1 的位置，文本颜色改回来

正确的两层次是：

| 层 | 要删吗 | 是什么 |
|---|---|---|
| `art657.game.notebook.page` | **删**（隐藏） | 卡片区**背后**那块静态大红底板 325×468 |
| `art658.clueN.bg` + `art661.clueN.*` 28 层 | **不删** | **卡片本身**的红色阶梯渐变染色 |

所以 668 从 666 重建（666 的 Lua / 26 条文本 / 控件几何与 667 逐字节相同，等价于完整撤销 667 的卡片改动、风险最低），只隐藏 `art657.game.notebook.page` 一条记录，让卡片区背景露出白色底板 `art657.game.notebook.frame`（`#FDFAEF`）；卡片本身仍是红渐变、文字仍是白色。

## 二、「阶梯渐变素材放在 backrop1 的位置」

666 两套 `clue` 模板的层序本来就是：

```
art658.clueN.bg (23)  →  art661.clueN.* 28 层阶梯渐变 (42..69)
    →  art658.clueN.rule 白线 (70)  →  backrop1 (71)  →  backrop2 (72)
```

即整套阶梯渐变**紧邻 `backrop1` 之前**；`backrop1` / `backrop2` 为 `#00FFFFFF` 透明。脚本 `Controller:_grid_paint_highlight()` 给 `backrop1` 写 `HIGHLIGHT_TINT = 0xFFFFD44B` 时，因为它在 28 层渐变**之上**，黄色能盖住整张卡 → 选中态整张染色。

**本轮保持该层序，不移动**：若把 `backrop1` 移到渐变之下，染黄反而会被 28 层渐变盖住，选中高亮就失效了。这正是用户要的「卡片本身的染色不要删」。
