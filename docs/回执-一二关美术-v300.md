## §1 一句话

第一轮是"每格 3 层色块"，像图解；第二轮把家具改成「**6 层官方基础形状拼装**」（深色外形=描边 → 主体 → 内面 → 细节），
并把 **跨格家具合并成一件**（分组 + 锚点格 + 溢出，不再拆成两格），同时补上**房间名标签**。
"obj 底层架构"没有推倒重来：只把每格的家具层从 3 层加到 6 层、并新增两条按格下发的键（`furn` / `furn_anchor`），
`object` 老路原样保留（离线用例仍在用）。

## §3 美术决定（细节见设计仓库 README）

1. **主体/台面/柜体一律用 `100001` 直角矩形**：asset-hunt 实测 106xxx 的圆角矩形四角半径不一致、带手绘缺口
   （106046 底边 1.7% 缺口 = 第一轮"纸片感"的来源），107xxx 虽然干净但部分自带装饰角（像画框）。
   ⇒ 第一轮用的 `106053`/`107002` 全部弃用。
2. **描边 = 同形状放大 ≈2.5%/边、染深色**（`#6B5B45`）：原作描边实测 2.5%/边（shelf 5%、statue 3.1%），
   但官方白模没有 stroke，只能"垫一层"。
3. **投影用 `106056`**（白心向外渐隐的柔光圆；染黑 = 柔和圆影），给桌/植物/雕塑垫底，桌面才有"落在格子上"的感觉。
4. **椅子**：加深坐垫（`#C6B183`）+ 加宽扶手到 0.13 格 + 靠背亮条 ⇒ 俯视能读出"靠背 + 两扶手 + 坐垫"。
5. **雕塑**：两级石座 + 肩（宽扁圆）+ 头（小圆）分开 ⇒ 读成"台座上的半身像"（第一轮是"柱子 + 一个圆"，像台灯）。
6. **跨格合并只给 table/carpet**：其它家具一格一件——**两盆相邻的植物是两盆**（第一版把它们并成一件，花盆被转了 90°、还只剩一盆，预览时露馅）。

## §5 未验证 / 风险（真机前先看）

1. ★ **真机未验**：模板新增的 `obj2..obj6` 在 `InstantiateClientUIControl` 克隆格子时**是否一起克隆**。
   - 同类先例：v283 的 `portrait` 层来自同一个 `content`，真机已通过 ⇒ 判定"很可能通过"，但仍无真机证据。
   - 失败症状很好认：家具只剩**深色外形那一层**（= L1），主体/细节全无。
2. **跨格溢出的两个前提**：
   - ① `content` 容器**没有开启裁切**（脚本不改 mask；若真机开裁切，长桌会被裁在格子内）；
   - ② 锚点格 `SetAsLastSibling()` 生效（若引擎忽略，邻格地板色会盖掉溢出的半件）。
   真机症状：桌子只剩一半。
3. **106xxx / 105090 在真机的渲染**：模拟器对非基础形状只显示缺失框；本轮实际用到的非基础形状素材只剩 `106056`（柔光投影）与少数彩色素材。
   若真机不显示 ⇒ 投影会丢（家具仍在），把 `furn_art.lua` 里 `IMG.soft` 换成 `100001` + 低透明度即可。
4. **控件量**：每格 19 个子控件 → 第二关 36 格约 684 + 其他 ≈ 800（官方上限 1000/组）；**真机帧率未测**。
5. **编辑器再存一次**：新增记录的 GUID 在 `1073746100–1073746117`；若在编辑器里"另存/转存"导致 GUID 重排，重跑 `probe_guid_collision`。
6. **房间名位置**：只做"优先没有家具的格"，没有原作的避让排版；4 个房间名在某些关卡里可能压到棋子头像（棋子在 cell 内、labels 在其上）。
