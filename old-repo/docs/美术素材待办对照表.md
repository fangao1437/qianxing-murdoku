## 五、替换时的**注意事项**（踩过的坑）

1. **图片必须成对改**：`imageSource` + `imageId` 两个字段一起改 —— 只改一个不生效
   （见 `docs/工作约定-优先直改控件.md`）。
2. **改完要回读验证**：用 `tools/gil/` 下的工具读回来确认，**不要只看"写入成功"**。
3. **静态引用大多不支持拉伸**：真机日志里 `imageType` 显示 `Stretch` 才说明这个素材
   能拉伸；`Basic` 就只能按原样铺 ⇒ **需要拉伸的地方（房间色块、家具）请选「底板」类素材**。
4. **新记录必须写进 `g.recHolder`（子消息 `/#9`）**，不是 `g.tree` ——
   否则编辑器读不到（这条我查了整整一轮才找到，详见 `gilread.mjs` 的注释）。
5. **房间名**：在 `lua/levels/case_00N.lua` 里加一行就会自动显示，界面零改动：
   ```lua
   room_names = { "餐厅", "厨房", "前院" },   -- 按房间号顺序
   ```
   没写就显示「区域 N」占位（**不编名字**）。
