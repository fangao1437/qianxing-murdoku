> 背景：用户实测 v357（层序修正）后仍反馈「还是没渲染出来」，日志里有

## 2 根因（两层，v357 只修了第一层）

### 2.1（v357 已修）board 内兄弟顺序
家具被 `SetSiblingIndex(1/2)` 放到 `td.<tag>.board` 的子控件前部，落在底图/格子之下。
→ 已改为 `SetAsLastSibling()` + 地毯先建。

### 2.2（v358 真正根因）页面把共享棋盘整块盖住了
- 教程 UI 结构（v356 存档实测）：
  - `td.<tag>.bg`（整屏面板底图）
  - `td.<tag>.board`（**共享棋盘**：底图 27 / 38 / 44 个子控件，运行时家具也挂这里）
  - `td.<tag>.page.1 … page.N`（**每页各自又复刻了一整套棋盘**）
- 实测每页 svg 子控件：`l1.page.1=52`、`l1.page.2=55`、`l2.page.1=75`、`l2.page.2=82`，
  其中 **27 / 38 / 44 个是不透明格子底板**（比共享底图还多一份）。
- `td.*` 子控件顺序 = 渲染顺序（后者在上）：`bg < board < page.1..N`
  ⇒ **page 的棋盘底图整块盖在 board 上**，board 里的家具永远看不见。
- 根因代码：`tools/gil/replica_tutorial.mjs` 从 v354 引入「共享底图」后，
  逐页调用 `board(page, boardId, …, U(656))` **漏掉了 sharedBase/mode 参数**，
  于是每页 `renderSvg(baseSvg, true)` 又把底图画进 page 一份；共享 board 变成"白做"。
  （v354 验证过：各页 base 组里会被复刻的那 27/38/44 个格子控件完全一致 ⇒ 共享底图本来就成立。）

## 3 修复（v358）

`tools/gil/replica_tutorial.mjs`：

1. `board()` 增加 `mode` 参数；
2. 共享趟（`sharedBase` 非空）：**只画底图**，挂 `td.<tag>.board`；
3. 逐页趟：**只画提示层**（`mode="overlay"`），不再画底图；caption / 首页棋子照旧；
4. 结果层序：
   ```
   td.<tag>.bg（面板底）
     < td.<tag>.board（棋盘底图 → 地毯 → 家具）
       < td.<tag>.page.N（提示层/候选/红叉/高亮列/卡片/图例/按钮）
   ```
   家具在底图之上、提示层之下 —— 正是设计要的层序。

**记录数**：从 4563 → **4151**（−412 = l1 8 页×27 + l2 4 页×38 + home 1 页×44，全是重复底图）。
