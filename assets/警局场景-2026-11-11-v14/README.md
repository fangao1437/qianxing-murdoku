## 一、三个问题的修正

| # | 实机问题 | v14 修正 |
|---|---|---|
| 1 | 橘红色区域没有到档案袋边缘 | ① 档案袋右边缘整体右移 24px 到设计图实测位置（局部 u 上限 310→334，左边缘不动），DARK 橘红大三角随之延伸到档案袋右/底边缘；② 橘红楔形底端由 (456,638) 延到 (453,713)，正好落在档案袋左边缘线上（`x=256.6+0.2753y`），不再半途收尖 |
| 2 | 档案袋阴影部分表现错误 | 删除 v13 那条把阴影切断的亮橙 DARK 补缝带；阴影左边界改为**严格贴合档案袋右边缘**。阴影改用「1 个竖直大矩形 + 1 个沿袋边的旋转矩形 + 1 组小缺口等腰三角」构造，连续无碎片、上边界被胶带/黑边自然遮住 |
| 3 | 太多细矩形 → 斜边锯齿 | 所有多边形不再用竖条扫描填充。倾斜形状一律「矩形 + 旋转」；斜边用官方 `100003` 等腰三角（底边贴目标边、顶点在中垂线最远内点）+ 其它大块同色补色。**不透明同色重叠无缝**，每个图元三个顶点都在目标凸多边形内（凸性保证零溢出），内部任意重叠 |

### 通用构造法（本轮核心，可复用）
```
fillConvex(poly):
  对整条多边形每条边放 1 个 100003 等腰三角（内法线指向重心，顶点二分到「仍在 poly 内」的最深处）
  再扇形剖分，每个三角形三条边各放 1 个 100003 补尖角
  全部同色不透明；外边界 = 原生图元的边，零锯齿；内部重叠不可见
```
数值自检：DARK 三角 100% 覆盖、阴影补缝三角 100% 覆盖、相框补缝三角 100% 覆盖；离线导出放大 3× 复核斜边无台阶。中途试过「逐格实色网格」和「仅扇形剖分」，分别出现方格色块和覆盖不足（92.5%），已废弃。
