# 690 · 通用线索卡（同构异色）：变更与验收

**需求**：基于 689，参考当前普通线索卡的设计，为通用线索设计一张**风格相同、但一眼能看出差别**的通用线索卡，并写入存档。

## 一、689 的现状（为什么要做）

689 里**没有独立的通用线索卡美术层**：网格视窗 `clues.grid` 的 `itemPrefabIndex` 指向普通 `clue` 模板，通用线索只是它的第 1 个实例（pos=1）。运行时 `_fill_general_item` 只做三件事：

1. 隐藏普通卡四槽 `who / what / letter / face`；
2. 点亮 `gen.backrop / gen.title / gen.body` 三件（`gen.backrop` 是官方素材 107133，330×79.4）；
3. 把 `row.<关>.clue` 的正文写进 `gen.body`。

结果：**通用项仍是枣红渐变票券**，只是换了个标题，和普通卡几乎分不出来。历史文档（`671/669/670/667` 验收、`01-仓库规格摘要.md` §6.5）只把它当"功能/图层"处理，从未给过视觉规格。

## 二、设计：同一套语法，换一套身份

**风格相同**（照搬 672 定案的普通卡，全部逐字段复用）：

| 项 | 口径 |
|---|---|
| 尺寸 | 模板 334×85.4 / 外框 330×85.4 / 卡面 324×79.4 / 3px 边 |
| 构造 | 左上 45° 斜分界 + 右侧梯形（矩形＋遮盖三角＋补角三角）+ 中间双三角异色区，7 枚图元**直接复用 672 的解析几何参数**，只换颜色 |
| 图元 | 原生 `100001` 矩形 / `100002` 椭圆 / `100003` 等腰直角三角，零溢出、无外部资产 |
| 排版 | 左槽 / 中正文 / 右徽，白字正文，标题在左上 |
| 选中 | 只染最外层框 `HIGHLIGHT_TINT = 0xFFFFD44B`，露出 3px 一圈黄，卡面尺寸不变 |

**可辨差别**（5 处，均为通用卡专属）：

| # | 差别 | 普通卡 | 通用卡 | 语义 |
|---|---|---|---|---|
| ① | 色相 | 枣红 `#68262A` / 暗红描边 `#491B1E` | **靛蓝 `#2A3E66` / 深靛框 `#20304F`** | 暖＝人的口供；冷＝客观规则 |
| ② | 左槽 | 52×52 人物头像 + 角色名 | **金色双环章（外环 52 / 内芯 42）＋「公」** | 不属于任何人、公共/公理 |
| ③ | 右徽 | 字母 A–V | **金字「真」** | 通用线索始终为真 |
| ④ | 分隔线 | 无 | **金色规则线**（x −100..144，y 14，避开环章） | 规则卡 |
| ⑤ | 标题 | 黑字（模板内） | **金字 `#E8C877`** | 与金饰成套 |

配色对照：`#491B1E / #68262A / #9D3033 / #702830 / #611F23` → `#20304F / #2A3E66 / #4C72A8 / #334A78 / #22345A`，金色 `#D9A441` / 金字 `#E8C877`，正文仍纯白。

> 备选：若真机上冷色与米白纸面显得跳，可只把 `690_通用线索卡图元.json` 的 `colors.general` 换成「深墨棕 + 金」（同构、同层序），重新 `FORCE=1 node 构建690.mjs` 即可，不影响任何结构。

## 三、技术方案（写入存档的方式）

**关键约束**：通用项与普通项共用同一个 `clue` 模板实例 ⇒ 新图元**不能静态可见**，否则会同时出现在每一张普通卡上。因此：

1. **两套 `clue` 模板各克隆 12 枚 `gen690.*`**（运行时源 1073742421 + 编辑器母本 1073742428），全部**静态隐藏**；层序插在 `gen.backrop` 之后、`gen.title` 之前（childList 与 recTop 同步）。
2. **改造既有三件**：
   - `gen.backrop`：官方素材 107133 → `100001` 纯色，330×79.4 → **330×85.4 靛蓝外框**（盖住普通卡的暗红描边）；
   - `gen.title`：字色黑 → 金，文案「通用线索」不变；
   - `gen.body`：`260×60 @ (0,−0.4)` → `236×56 @ (14,−2)`，避开左环章，白字不变。
3. **内嵌 Lua 只改两处**（可反向逐字节还原 689，689 的每帧同步链 / 性能优化全部保留）：
   - `_fill_general_item` 与 `_fill_grid_item` 的显隐名单：`3 → 15` 项（原 `gen.*` 三件 + 12 枚 `gen690.*`）。有通用线索时 pos=1 全点亮、pos>1 全熄灭；没有通用线索的关卡，12 层保持静态隐藏，绝不出现在普通卡上。
   - 高亮目标 `backrop1 → gen.backrop`：因为 330×85.4 的靛蓝外框盖住了原描边，改到这里才能让通用卡选中时仍有「3px 一圈黄」，`self._gen_hl_orig` 缓存随之记录靛蓝原色。
   - **未动**：`focus_general` / `general_focus` / `_has_general_clue` / `clue_hint_general` / 689 的 5 处性能门控 / 685 每帧抬层不变式 / 686 离场收起。

**层清单**（每套 12 层，共 24 条）：`base`（靛蓝主色，整卡覆盖红卡面）、`hi`、`trap`、`lo`、`mid1`、`mid2`、`corner`（7 枚同构渐变/梯形）、`rule`（金线）、`seal.outer`、`seal.inner`、`mark`（文本「公」）、`badge`（文本「真」）。两枚徽记的字号按 `letter` 口径设置（「真」30/20 与字母徽一致，「公」24/18 略收）。完整参数见 `690_通用线索卡图元.json`。

## 六、范围与真机待验

- **未导入游戏、未做真机/试玩**；PNG 为离线模拟（图元、颜色、文本色均从 .gil 实读，文字为占位示意，字号为近似值）。
- 存档里**只有第 2 关**配了通用线索内容源（`row.2.clue` → `clue.2.1`「地毯上没有人」），因此新卡目前只在第 2 关的列表第 1 项出现。要给其它关加，按 `01-仓库规格摘要.md` §6.5 三步：关卡 Lua 写 `general_clues`、编辑器建 `row.<关>.clue` 容器并写正文、接受列表多一项。
- 新增层沿用 672 的 4 个非标准旋转角（−111.695° / 40.954° / 33.874° / −146.126°），真机若某个 `100003` 不出图，按 `docs/美术资产-原生图形构造与v12-v15演进.md` 用沿斜边共线的旋转矩形替补（与普通卡同一风险、同一解法）。
- `100002` 椭圆做双环章、`gen.backrop` 由官方素材换成白模 `100001` 染色，均为本轮首次用法，需真机确认出图与 `imageColor` 乘算表现。
- 字号字段（文本块 `#512/#513`）按 `letter` 口径推定，真机字重/行高待验；若「公」「真」偏大偏小，只改这两个值即可。
- 689 及历史版本全部保留未改；690 为新增版本，**未提交/推送 Git**。
