# 715 UI 多比例适配收官报告

2026-11-19 · 交付版本 **v16** · [最终存档](./715_UI多比例适配_v16.gil) · [构建及布局回归](./715_UI多比例适配_v16/构建.mjs)

本次以 v16 作为后续维护基线。实机反馈已确认全局背景在 4:3 和 19.5:9 通过，v15 获得「总体通过」反馈。v16 只收尾选关页的四卡水平居中与两角撕边。收官时已从 v15 重建 v16，60 次离线布局检查全部通过，重建产物与交付件的 SHA-256 一致。v16 两项视觉微调和最终触控手感仍待实机签收。

## 画面怎么适配

| 图层 | 随窗口变化的规则 | 解决的问题 |
|---|---|---|
| 警局主画、装饰拍立得和火漆 | 以 1600 宽换算设计高度，按原画 1600×817 的有效区域等比覆盖窗口。相纸继承背景变换，火漆使用相同倍率和平移 | 高窗裁左右，长窗裁上下，边缘保留纹理。火漆与它压住的相纸保持相对位置，中央解题棋盘独立布局 |
| 选关底板 | 移动端取暖色板与四条边框内缘的交集，留采样余量后等比放大到覆盖窗口 | 左右两侧显示板面纹理。底板放大不带动卡片或翻页热区 |
| 四张关卡卡片 | 按白框外缘计算整排跨度并居中，三段净间距统一到约 51.94 个设计单位。衬纸、阴影与对应卡片一起移动，动态标题、缩略图与点击框从白框定位 | 首尾留白相等。翻页后仍按当前卡位显示和命中，尾页空位不接收点击 |
| 选关两角撕边 | 从 16:9 到 20:9 逐渐增加内移，之后封顶。右上主要向下、左下主要向右，两角维持贴边 | 长屏多露出撕纸纹理；4:3、16:9 保持原位置 |
| 移动端顶部按钮 | 关卡返回、提交、重做、撤销及选关返回从各自基准位置统一下移 20 个设计单位，描边、图标和点击区同行 | 为顶边描边留空间，保留右上三键的原间距 |

## 本次复跑与指纹

复跑使用 Node.js、仓库的 GIL 读写工具和 Lua。测试从重建后回读的存档提取布局逻辑与四端白框数据，覆盖 4:3、16:9、19.5:9、20:9、21:9，每种比例运行四端状态，每个状态依次检查首页、尾页、返回首页，共 **5 × 4 × 3 = 60** 次。断言覆盖白框整排居中、卡间净距相等、可见卡片与缩略图及点击矩形对齐、命中关卡编号正确、尾页空位禁用，以及两角撕边同时跨边并有部分进入画内。

## 实机签收范围

在此前反馈过的长屏手机上打开 v16 选关首页，以白框外沿比较首尾留白，并观察右上、左下撕纸是否多露出一段且仍贴边。点开最左和最右卡，翻到尾页并返回，核对实际进入的关卡与所点标题一致。4:3 可作为对照，观察卡组居中和两角原构图。离线回归使用控件替身，原生裁剪、安全区与触屏事件以客户端结果为准。
