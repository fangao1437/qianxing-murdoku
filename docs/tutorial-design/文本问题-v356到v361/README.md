## 二 ★★★ 文本在 `.gil` 里的位置（★ 统一路径 ✓）

```
记录
 └─ #505 → #503 → #75   = 【文本属性组】
      ├─ #501  颜色（varint，如 20）
      ├─ #504  字色 ARGB（varint，如 0xFF827C6D = 4286749805）
      ├─ #505 / #507  遮罩色 / 描边
      ├─ #508 / #509  水平 / 垂直对齐（1 = Center）
      ├─ #510  文本本体 → #501 = UTF-8 字符串（wt=2 叶子）
      ├─ #512 / #513  fontSize / minimumFontSize
      └─ 状态块里的 #505 尺寸对（位置/尺寸，稀疏编码：0 分量不写）
```

★ **注意两个坑** ✗：
1. ★★ **`#510` 在 `#85`（图像块）里是【拉伸开关】**（varint）✗ —— ★ 同号字段不同义 ✓
2. ★★ **空文本时 `#510` 是空消息（wt2/len0/无子）** ✓ ⇒ ★ 写文本必须**复用它** ✓
   　 ✗ 不能再造一个 `#510`（同组两个 `#510`，引擎取哪个不确定 ✓）
