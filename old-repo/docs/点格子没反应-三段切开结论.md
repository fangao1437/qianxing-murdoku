## 4. 建议的修法（★ **先别改** ✗ —— 只给位置）

**主修（一行级）**：给 `clue.<i>.face` 补上事件 —— 即 `ui_controller.lua:2145-2147`：

```lua
push({ id = "clue." .. i .. ".face", kind = "button", parent = "clue." .. i,
       rect = { ... }, image = wportrait, style = "portrait", visible = inWin,
       event = (wid ~= nil and wid ~= "") and { action = "suspect", id = wid } or nil })
```
* `wid` 就是角色 id（`split_by_name` 第 4 个返回值 = `bestIt.id` ✓ 见 `:1307`）
* 这就是「头像已并进线索卡」之后**该有的那个入口** ✓，不动布局、不新增控件 ✓
* ⚠️ 必须在 `who ~= nil` 的那一支里（那里才有 `wid` ✓）

**备选**：把 `:1870` 的 `n_tray` 恢复成真实人数（并把 `tray` 容器 `visible` 打开 ✗）——
但那会与 2026-10-02 的定稿冲突 ✗ ⇒ **不推荐**。

**测试侧（同源）**：`tools/sim/probe_cursor.mjs:54` 的 `click('tray.A')`、
`play_test.mjs:229` 的 `textOf(ri,'tray.A')` 都是**旧入口**，要改成点线索卡上的头像 ✓
（第 6 次「测试落后于设计」✓ —— 但**这次代码也真的缺一个入口** ✗，不只是测试旧 ✗）

**附带修法（另一条，独立）**：`engine_adapter_qianxing.lua:4556 / :4562` 的
down / up 回调**没有传 `src_id`** ⇒ 它们的 `r`/`c` **完全依赖 `node.event` 自带的那一份** ✓。
反事实实测（探针 D2）：把事件表换成兜底 `{action="click"}` 后 ——
