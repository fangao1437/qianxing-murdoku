## 1. 设计结论

1. **三套教程、三种形态**，按玩家所处的屏决定：
   - **首页教程**：出现在「选择关卡」上，**单页总览**（目标 / 三条铁律 / 房间与门），右侧放一张示意盘。
   - **第一关教程**：出现在关卡内，**左侧抽屉 + 右侧真实棋盘**，8 步：认识棋盘 → 选人 → 放人 → 推理 1/2/3 → 收口 → 指认。
   - **第二关教程**：同一抽屉形态，4 步：复述四步法 → 一句假话 → 怎么抓谎 → 谁在说谎。
2. **棋盘图不是另画的插画**：第一/二关直接把**真实棋盘**留在屏幕右侧（玩家自己的棋盘），教程只改高亮、候选、标记；因此「操作 / 推理」每一步都能配一张与现场一致的棋盘图，且不需要为每一步新建控件。
3. **抽屉占左侧 538px**（盖住线索区，露出棋盘 608–1192），与现有 `teach.*` 深色面板同一视觉语言；翻页、关闭、跳过沿用现有行为（右上一颗叉、离开该屏自动收、一局只自动弹一次）。
4. 视觉不使用新素材：墙 `#29282B`、门 `#DC5B28`（工程真机实测值）、房间地面取 `Controller.ROOM_COLORS`、强调色 `#E8A23C`（沿用地板/通用线索的暖橙）。

## 2. 逐屏内容

### 2.1 首页教程（单页）

- 眉标：`教程 · 玩法总览`
- 标题：`先摆人，再指认`
- 副标题：`数独 × 推理：每行每列各站一人，靠线索收窄，最后揪出盗窃者`
- 五条规则（左列）：
  1. **目标：摆满当事人，再指认** —— 每名当事人（含 1 名受害者）各占一格；全部摆好后指出盗窃者；受害者屋里若还有别人，还要说清有没有同伙。
  2. **每行、每列恰好一人** —— 放下一个人，整行整列自动打叉。
  3. **只能站「可站」的格子** —— 椅子、地毯可以站；桌子、植物、书架、雕像不能站。
  4. **「旁边 / 隔壁」怎么算** —— 只算上下左右贴着的格子：同屋直接算，跨屋必须中间有门，隔着墙不算。盗窃者也一定落在受害者隔壁的屋里。
  5. **操作：点卡 → 笔记 → 长按放下** —— 点卡选人；轻点只写铅笔笔记；长按进度环走完才放下；放错用撤销。
- 右列：示意盘（5×5 / 三间屋 / 三扇门 / 5 枚棋子，1 受害者 + 1 待指认）+ 房间图例 + 标记图例 + `坐标 =（行,列）`。
- 底部：`第一关教程会带你走一遍完整推理，随时可以跳过`；按钮 `稍后再看` / `开始办案`。

> 示意盘不是任何真实关卡（不剧透第一关答案）：`layouts/layout-demo.json`。

### 2.2 第一关教程（8 步 · 案件 001《夜盗独行》）

| 步 | 标题 | 正文要点 | 棋盘图 |
|---|---|---|---|
| 1 | 认识棋盘 | 左边线索卡、中间棋盘、右边工具；5×5、三间屋（大屋/内室/外间）、三扇门；行号 1–5 自上而下、列号 1–5 自左而右 | `l1-1` 空盘 |
| 2 | 选人：点一张线索卡 | 点卡＝选中卡上那个人；卡上的话是他的口供，可能说的是别人；选中后话里提到的位置会亮起 | `l1-2` 第 5 列高亮（卡 1「收藏家在第 5 列」） |
| 3 | 放人：轻点写笔记，长按放下 | 轻点只留铅笔小字、不占位；长按到进度环走完才落下大字母；放下后整行整列自动打叉（图上淡叉＝将被划掉的格） | `l1-3` 笔记 + 长按环 + 行/列虚框 + 淡叉 |
| 4 | 推理 1：地毯上只有一个人 | 卡 3「只有值班保安站在地毯上」→ A 只可能在地毯 4 格 | `l1-4` 4 个 `A?` |
| 5 | 推理 2：B 只能站 (2,2) | 卡 5「前台姑娘在桌子旁边」→ (2,2)/(3,1)；(3,1) 是地毯，站上去就和卡 3「只有值班保安在地毯上」冲突 ⇒ B=(2,2)。第 2 行与第 2 列被占 ⇒ A 的 (2,4)(2,5)(3,2) 出局 ⇒ A=(3,1) | `l1-5` B/A 已放 + 3 个被划掉的 `A?` |
| 6 | 推理 3：剩下的椅子 | 卡 4「夜班清洁工站在椅子上」→ (4,2)/(5,4)；(4,2) 与 B 同列 ⇒ C=(5,4) | `l1-6` C 已放 + (4,2) 划掉 |
| 7 | 收口：只剩两种摆法 | 卡 1「收藏家在第 5 列」+ 卡 2「古董商在植物旁边」→ A/B/C 已定，只剩 D/V 互换的两种摆法；把 D 换到外间 (4,3) 时「盗窃者要在受害者相邻屋里无辜最多的那间」不成立 ⇒ 唯一摆位 D(1,3)、V(4,5) | `l1-7` 两种摆法（一种被划掉） |
| 8 | 指认：谁一直留着两格 | A/B/C 全程各只有 1 个可能格，只有 D 一直留着 2 格 ⇒ 盗窃者＝D；受害者独处内室 ⇒ 无同伙 | `l1-8` 终局 + 金圈 D / 蓝标 V |

> 第 7/8 步的判据来自仓库设计层（`案件001-线索清单.md` §四「主动因素规则」与 `规则规格-偷窃版.md` R3/R4）；**这两条判据尚未落进 `murdoku_core`**（`回执-线索卡位置提示-2026-10-17.md` §四），见 §7 风险 3。

### 2.3 第二关教程（4 步 · 案件 002《双影》）

| 步 | 标题 | 正文要点 | 棋盘图 |
|---|---|---|---|
| 1 | 复述：四步推理法 | ① 每行每列一人 ② 只能站椅子/地毯 ③ 线索收窄 ④ 看门：只有门连通的两间才相邻（本关侧廊只通大厅） | `l2-1` 6×6 + 门高亮 |
| 2 | 新规则：至多一句假话 | 整条假、最多一条、不会预告是哪一句；受害者的话也可能是假；「地毯上没有人」是**通用线索**，不算谁的卡 | `l2-2` 5 个地毯格打叉 |
| 3 | 抓谎：先当全真，再逐条摘 | 全真摆不出 ⇒ 必有一句假；逐条摘、找自洽；「某人在某人的同一列上方」形状上恒假（一列只站一人）；图上红虚线是讲解用的，游戏里不会画 | `l2-3` 第 3 列高亮 + 两个 `?` + 红叉 |
| 4 | 收口：说假话的人就是盗窃者 | 判题只报「摆位还没成立」，不揭晓哪句假；把假话揪出来后指认它的主人 | `l2-4` 地毯叉 + 门高亮 |

> 第二关**不教同伙**：两关的受害者都独处一屋（`case_002` 的 `roles.accomplice` 省略），且仓库 `收尾` 记录写明同伙规则已废止。
> 第 4 步的「说谎者＝盗窃者」是仓库第二关设计层的判据（「只剩一个可选位置时他说谎」），同样未落进 core。

### 5.2 本设计需要新增/改动什么

1. **面板改形**：`teach.<t>` 由「1240×780 居中、3 页」改为「538×832 靠左抽屉」，正文区改为「步骤栏 + 单步正文 + 线索卡 + 候选 pills」。
2. **首页**：沿用居中面板（1260×800），单页；右列新增 1 个棋盘插图区（见 5.3）。
3. **控件预算（建议）**：
   - 抽屉公共：eyebrow / title / sub / close / 8 个步骤按钮（`step.i` + `step.i.on|off`）/ 正文标题 / 正文 / 线索卡 4 件 / 3 个 pill / 上一步 / 下一步 / 跳过 ≈ **30 件/套**，共 90 件。
   - 棋盘标记：每格加 1 个 `mark` 文本（大字母候选/红叉），5×5 → 25、6×6 → 36，共 **61 件**；行列号 **11 件**。
   - 首页示意盘：若复用真棋盘则不需要；若做静态插图，≈ 25 格 + 4 家具 + 4 标记 ≈ **35 件**。
