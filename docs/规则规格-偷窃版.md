# 规则规格 · 偷窃版

> 2026-11-17 本轮按用户纠正：**线索一律不撤下，只有身份规则存在条件调用。** 旧版“先撤下本人线索，再按剩余候选数分流”是错误附加条件，作废。715采用本版规则。

## 1. 基础规则

- N×N棋盘、N人，包括受害者，每行每列各一人，各人占一格。
- 家具可站性以occupiable为准；墙划分房间，门仅建立直接相邻，不合并房间。
- 家具“旁边”为同房间上下左右四邻可站格；方位线索按其显式参数判定，不暗加同列条件。
- 恰有一名盗窃者，受害者不能是盗窃者。没有显式同伙的关卡不引入同伙。

## 2. 所有线索保留，身份规则条件调用

最多一条线索为假，假话必须由盗窃者本人说出；其他人、受害者及通用线索必真。假话在完整摆位中必须实际为假，不能把它删除、忽略或作为任意真假值。

- **全真选位**：全部线索为真时，人物在人数规则前仍有多个合法位置；应用人数规则后，本人位置必须真正收窄到唯一格，才具备此身份资格。已由全部线索固定的人，不能只因所在房间人数合适就成为盗窃者。
- **说谎身份**：在“本人个人卡为假，全部其他个人卡及通用线索为真”的完整约束下，该人物在人数规则前必须恰有一个合法位置；随后检查人数规则。候选零格或多格均不满足说谎触发条件。
- 上述不是让设计者任选身份条件：每个分支必须满足对应的真值、候选位置和人数条件。汇总所有合法身份及盘面，最后验收联合唯一。

## 3. 可执行验收定义

H为每行每列、可站格、家具及房间等基础约束，C_i为第i张卡的完整逻辑命题，G为全部通用线索。

1. 全真集合：S0 = H ∧ G ∧ 所有C_i。这里不使用人数条件。
2. 对每个非受害者t，使用S0中t出现的全部不同格P0(t)。只有|P0(t)|>1时，才检查人数规则是否使其收窄为唯一格。
3. 对每个潜在盗窃者t及其个人卡j，假话分支集合：Sf(t,j) = H ∧ G ∧ ¬C_j ∧ 所有i≠j的C_i。**C_j仍以假值约束参与，绝不是撤卡集合。** 当前每人一张个人卡；整张卡作为真假单位。
4. 用Sf中的完整摆位投影计算t的位置；恰好一格时才满足说谎身份条件，随后过滤人数条件。
5. announce=none仅在玩家确知全真时排除假话分支；one仅在玩家确知恰有一句假话时排除全真分支；unknown两类均核查。隐藏元数据不能作为玩家知识。
6. 汇总所有合法的（完整摆位，盗窃者）组合，去重后必须恰有一个。不得预读solution、roles.thief、meta.false_clue筛选；只在求解完成后比对。

“候选格”指至少有一个满足该分支全部线索真值和基础约束的完整摆位支持的格。不是浅蓝格、人工笔记格，也不依赖读卡顺序。不能先用人数条件把多格缩成一格，再反过来宣称说谎触发条件满足。

## 4. 人数规则

- 盗窃者所在房间Rt必须与受害者房间Rv有门直接相连。
- 只比较与Rv直接门相邻的房间，不与Rv自身或全场所有房间比较。
- 无辜人数排除盗窃者；只有关卡显式存在同伙时才额外排除同伙。
- tie_policy=forbid时，Rt无辜人数必须严格最多，禁止并列。
- 旧“受害者同区有人就必须有同伙”规则已废止。

## 5. 冗余与验收边界

正常求解始终保留全部卡。为评估设计冗余而额外做的删除卡片实验，必须明确是反事实实验，不能倒灌成身份规则。删除卡片会改变身份触发条件，结果可能是零解而非更多解，不能只用“删卡后解数增加”评价必要性。固定作者身份的删卡数字只能作为辅助诊断，不能证明身份联合唯一。

运行时按预设答案结算不等于逻辑唯一解证明。必须独立枚举全部身份、校验卡片归属、真假、候选格阶段与人数条件，再与作者答案比对。第3、6关不得因为关卡编号被强行只验预设身份。

## 6. 历史纠正

- 旧v17验证脚本仍有按第3/6关编号选择分支、遗漏假话候选单格条件等问题，旧PASS不等于本规格通过。
