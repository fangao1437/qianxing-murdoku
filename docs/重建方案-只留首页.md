# 重建方案（用户 2026-10-02 提议，我补充精确步骤）

> **用户原话**：「干脆一点，只保留首页内容，其它干脆删了重建，反正有备份，不用反反复复的修了」
>
> **我同意。** 16 轮修补的结论是：**编辑器里摆的那套容器（`select` / `board` / `left` / `right` /
> `topbar` / `modal` / `intro` …）本身就带着问题** —— 真机上它们收不到光标、
> 而且脚本对它们的可见性控制**会被 `ui_controller` 每帧覆盖**。
> 而**脚本自己用模板创建的东西是好的**：格子在关卡里能点、`selbtn` 的字段和
> `home.select` 逐项一致、事件也绑对了。**所以重建的方向是"编辑器只留最少的东西，
> 其余全部脚本创建"。**

---

## 一、你在编辑器里要做的（约 5 分钟）

### ① 保留

| 控件 | 为什么留 |
|---|---|
| **`home`**（容器节点，全屏） | **真机证明它的子控件能点**（`home.select` ✅）。它是唯一被验证过的容器。 |
| **`home.title` / `home.select` / `home.continue` / `home.shop` / `home.bag`** | 首页现有内容，**能点、坐标正确**，不用动。 |
| **`tpl.cell`**（模板引用控件 → 格子模板） | 脚本靠它拿模板索引（`cfg.cells.prefab = 1073741876`）。**千万别删。** |
| **`root`** | 客户端 UI 根，删不了也不用管。 |

### ② 删掉（这些就是"反反复复修"的来源）

```
select, board, left, right, topbar, toolbar, modal, intro, assets
```

> **删之前先备份这份 `.gil`**（你说过有备份，再确认一次）。
> 删完存盘，**先别急着导出** —— 先做下面第 ③ 步。

### ③ 新建一个干净的容器

| 新建什么 | 名字 | 设置 |
|---|---|---|
| **容器节点** | **`stage`** | 全屏（1600×900 或按画布 1920×1080）；**必勾「显示常驻光标」**；**不要勾**「屏蔽区域内点击事件穿透」；**不要勾**「屏蔽按键事件穿透」（隔离交给 `home`） |

**⇒ 这一个容器就是**以后所有脚本创建的东西的父级**** —— 它干净、空、没有任何历史包袱。

### ④ 再做一个模板引用控件

| 新建什么 | 名字 | 指向 |
|---|---|---|
| **模板引用控件** | **`tpl.stage`** | 指向**同一个格子模板**（就是 `tpl.cell` 指向的那个）；**把它挪到画布外**（比如 200000,200000） |

**⇒ 有了它，脚本就能在 `stage` 下**批量创建任何控件**（按钮、卡片、格子），
**全部走"脚本创建"这条路** —— 而这条路真机证明**能收到点击**。
