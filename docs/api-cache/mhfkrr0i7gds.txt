一、网格视窗控件的功能
网格视窗
可以作为滚动列表使用，制作道具背包、商品列表等
网格视窗控件是客户端控件，可以挂载
客户端脚本
，支持通过
客户端脚本
进行调用
查询接口：
可通过
GridScrollerControl
在API文档里查询关联脚本接口
二、网格视窗的实现原理
网格视窗的列表采用复用列表结构，出于性能考虑，仅会加载处于可见范围内的列表项

网格视窗列表发生滚动时：
对列表项内容进行刷新(
触发回调)
，可以使用接口
RefreshItems
触发，从而实现滚动到对应位置时，显示准确列表项内容的效果
三、网格视窗的配置
1.列表设置

可被光标射线检测：
网格视窗控件可以响应光标的交互

是否可滚动：
网格视窗的列表内容在超出本体长度时，可以通过滚动显示原来看不到的部分

显示滚动条：
当网格视窗可滚动时显示此开关，控制滚动条的显隐

滚动方向：
决定列表为横向(左右滚动)还是纵向(上下滚动)
选项
说明
横向
列表滚动形式为左右滚动
纵向
列表滚动形式为上下滚动

列表项大小：决定列表中每项内容的宽度和高度

边距：决定列表内容距离网格视窗控件顶部、底部、左边、右边的距离

排列限制和预览数量：将预览数量对应的列表项展示在界面中，以模拟实际运行时的效果
选项
说明
自动换行
同一行中列表项的排布超出网格宽度时，自动换行
固定行数
列表项将根据配置的列数和预览数量，自动分配每行的列表项个数
2.列表项来源

引用控件模板：
网格视窗的列表项将以此控件模板为基础显示

注意：
仅配置在列表项来源中的模板可应用网格视窗的列表滚动效果，配置在网格视窗层级下的控件不会应用此效果
3.手柄导航
(1)通用手柄导航规则

可被手柄摇杆导航选中：
控制手柄导航是否可选中此控件
开启后可编辑手柄四向移动时选中的其他控件
(2)网格视窗的导航规则

若网格视窗内的列表项可以被手柄聚焦(即手柄导航的框定位到对应控件)，则选中网格视窗控件时将默认聚焦首个列表项

当手柄聚焦于网格视窗内的列表项，且手柄摇杆推动的位置不存在其他列表项时(
如选中左侧第一个列表项的同时向左推手柄)
，将选中对应方向网格视窗外的控件
