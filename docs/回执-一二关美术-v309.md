## §1 这一轮做的事：**家具统一成一条链路**

| 家具 | 以前（v302–v308） | 现在（v309） |
|---|---|---|
| 桌子 / 书架 / 地毯 | 手搭层（`furn`，≤12 层） | **不变** |
| 椅子 / 植物 / 雕像 | 图元拼法（运行时实例化 / 静态烘焙两条旁路） | **改手搭层（`furn`，9/10/10 层）**，与桌子地毯**同一条链路** |

- 素材仍是**官方基础形状**：`100001` 矩形、`100002` 椭圆、`107102` 干净圆角矩形；
- 全部**轴对齐**（不依赖旋转），尺寸按原作"长边占格"：椅 0.836 / 植物 0.760 / 雕像 0.912；
- 颜色取原作渲染图主色（奶白 `#FEF7E4`、棕金 `#D9C08A`、叶片 `#79CFA1`、盆 `#FCA161`、石材 `#C9C9D2` 等）；
- 两条旁路**关掉**：`M.FURN_BAKED = false`（静态烘焙默认关闭，数据仍在 511/512 存档里可回退）、
  `if false then` 不生成运行时图元记录、root 不再下发 `baked_level` ⇒ **不再碰 `fart.*` 两个容器**。
