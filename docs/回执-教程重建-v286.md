## 五 真机核验清单（★ 本轮唯一未验证项就是"实机导入"）

1. **导入 `482-教程UI并入-v286.gil` 不报「控件 GUID 重复 / 界面控件设置错误」**（本轮目标）。

3. 日志首屏应有 **`[tut] 自检 OK 14/14`**（★ 这是脚本侧检查的判据，不是"调用成功"）。

     `尺寸 0` 就是被裁剪的经典症状。
4. 点 **上一页 / 下一页 / 重置 / 关闭** 都生效；页签点了能跳页、选中页签的 `state.sel` 亮。
