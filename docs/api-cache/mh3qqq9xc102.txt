一、容器节点控件的功能
主要
作为其他客户端控件的挂点
，可以使光标常驻显示、屏蔽按键和点击事件
容器节点控件是客户端控件，可以挂载
客户端脚本
，支持通过
客户端脚本
进行调用
查询接口：
可通过
ContainerControl
在API文档里查询关联脚本接口
二、容器节点控件的配置
1.功能设置
隔离手柄导航：
手柄按照距离最近控件导航时，内外相互不穿透
屏蔽按键事件穿透：
容器节点内的按键事件交互不会穿透到界面外
屏蔽区域内光标事件穿透：
容器节点内的点击事件不会穿透到界面外
显示常驻光标：
使光标常驻显示
2.手柄导航

可被手柄摇杆导航选中：
控制手柄导航是否可选中此控件
开启后可编辑手柄四向移动时选中的其他控件
