## 逐条回答

### Q1 · 存档里模板是【几份记录】？

**结论：★ 成立（用户是对的）** ✓
—— **一份本体 ＋ 每个引用处一份实例，两份各自带【独立的一套子控件】** ✓
**不是**「一份定义 ＋ 引用只存 id」✗

**证据**
1. `[实测]` 上表：两个 `clue` 各有 **7 个自己的子控件**，**id 完全不重叠** ✓
2. `[官方原文]` `docs/api-cache/mhbgxf0nynww.txt:285`：
   > 「除**客户端控件容器画布中的客户端控件**以及**客户端控件模板中的控件**外，其他控件均为服务器控件，**服务器控件的模板索引无法被客户端脚本调用**」
   ⇒ ★ **官方明确点了【两个】存放客户端控件的地方**：① 容器画布 ② 客户端控件模板 ✓
3. `[官方原文]` 同上 `:10-11`：「界面控件组管理-**界面控件组库-客户端控件模板**，点击【添加客户端控件】后可以选择添加所需的客户端控件并**存为模板**」
   ⇒ ★ **"客户端控件模板"是库里的一个条目** ✓

**可信度**：`[实测 ＋ 官方原文]` —— **两份独立副本**这条是实测；"哪份叫本体"见 Q4 ✓
