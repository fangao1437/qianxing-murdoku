## 二、数据来源（关卡数据 → 文案）

1. 关卡定义 → `Core:clue_results()` 产出 `vm.clues[i].text`；
   `def.text(ctx, cl)` **只读** `ctx.name` / `cl.*`（全是关卡里写死的东西，**与棋盘状态无关**）⇒ `ui_controller.lua:4180-4182`。
2. 文案**按关卡缓存一次**：`Controller:_grid_text_payload()`（`:4186`）；缓存键 = **关卡表身份 + 条数**；回调里只**查表**（`:4178-4185`）。
3. 每次填充从**本次要显示的那批**里取当前项：`local cl = pay.items[pos]`（**`:4338`**）。
   - `pos` 的算法：`pos = GetItemIndex(item) - (_grid_base or 1) + 1`（索引基准自动探测；真机基准 = 0）。
4. 列表项**会被复用**（滚动/回收）⇒ **每次填充都按当前 `pos` 重判**（`:4348`）。

### 三个"人物标识"的形状差异（**踩过多次的坑**）

| 来源 | 形状 | 例子 |
|---|---|---|
| `cl.who`（关卡数据里的） | **显示名** | `老宅主` |
| `core.selected` / `core.placed` 的**键** | **id** | `V` |
| **视图记录** `self.core:view().clues[pos].who` | **id（权威）** | `V` |

- 真机证据（`ui_controller.lua:4350`）：`★ 灰白诊断：pos=3 who=老宅主 placed=false` ⇒ **`cl.who` 是显示名**，用 `core.placed["老宅主"]` 恒为 nil ⇒ **灰白永远不开**。
- 因此 id 的取法演进过三版（`:4349-4360`）：先 `portrait.X` → 再 `core:view()` → **2026-10-09 又把这里的 `core:view()` 删掉**，因为"**取到的值一定会被覆盖**"（`:4360`）。
  ⇒ **当前 id 的权威来源是视图记录**（`:4427` 注释），但**主路径上那段已被删除**，实际以 `:4422` 起的 `_grid_item_rec` 段为准。

## 四、缓存与"值变了才写"

| 机制 | 作用 | 行号 |

## ★★ 四、一处**必须纠正的口径**：`clue_row_h` / `clue_max_visible` 属于【老路径】✗

本文 §一 把这两项列在「渲染载体：网格视窗」标题下：
```
行高 / 可见条数 | clue_row_h = 127.2（画布 106）；硬上限 clue_max_visible | :137、:113、:136
条数           | math.min(#self.core:view().clues, M.LAYOUT.clue_max_visible)   | :1231
```

⇒ ★ **但网格视窗根本不用这两个数** ✗ —— 它的布点由**存档里 `clues.grid` 的配置块**决定 ✓（我实测 ✓）：

```
#80/502      = 列表项大小 → 360 × 96          ← ★ 项高是 96 ✗ 不是 127.2
#80/503      = 列表项间距 → 8, 8
#80/504      = 边距 上/下  → 20, 20
#80/#505[0]  = 边距 左/右  → 20, 20
#80/506      = itemPrefabIndex → 1073742421
```
（字段对应关系用**官方 getter 的返回顺序**交叉确认过 ✓
　`GetItemSize()`→x,y · `GetItemSpacing()`→x,y · `GetPadding()`→top,bottom,left,right ✓）

⇒ ★★ **一屏可见数（原来靠 `clue_max_visible` 硬编码）现在应当【算】出来** ✓：
```
可见数 = floor((视窗高 − 上边距 − 下边距) / (项高 + 纵间距))
       = floor((544 − 20 − 20) / (96 + 8))
       = floor(504 / 104) = ★ 4 项
```
⇒ ★ **而网格路径的条数用的是 `#lv.clues` 原值（7）** ✗ —— 见 `ui_controller.lua`
　 「条数别再用 `core:view()` 去数」那段 ✓ ⇒ ★ **7 是【总条数】，不是可见数** ✓✓
