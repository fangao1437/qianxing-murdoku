## 三、671 / 672 的关键结论（复用优先读这段）

**控件位置**（两套 `clue` 模板一致，模板局部坐标，中心 800,450）：

| 控件 | 几何 | 角色 |
|---|---|---|
| `backrop1` | 330×85.4 `#FF56565E` | **染色区**，Lua `_grid_paint_highlight()` 写 `imageColor`；在卡下面、露 3px |
| `backrop2` | 324×79.4 `#FF68262A` | **红色卡面主色**，整卡铺满；红色就放在这一层 |
| `art671.clueN.hi` | 100003 `w=112.288 h=56.144 rot=45` | 左上亮红 `#9D3033` |
| `art671.clueN.lo` | 100003 同尺寸 `rot=225` | 右下暗红 `#611F23` |

两枚三角顶点严格落在 `x638..962 / y410.3..489.7` 内（构建时硬校验）：

```
hi: (638,410.3) (638,489.7) (717.4,410.3)
lo: (962,489.7) (962,410.3) (882.6,489.7)
```

**层序**（recTop 与 childList 同步）：
`backrop1 → backrop2 → hi → lo → letter / what / face / who`

> 670 的教训：新渐变层插在 `who` 之前不够 —— `letter`(73)/`what`(74)/`face`(75) 比 `who` 更早，
> 必须插在**最早的文本/头像控件之前**，否则正文、字母、头像会被盖住，只剩角色名可见。

**最少图元**：每套模板视觉层 **32 → 4**（含两个 backrop），新增仅 2 层/模板。
边缘由 `backrop2` 矩形给出 ⇒ 平直；无安全矩形/补漏矩形 ⇒ 无竖直浅红细线与左下深红溢出；
整卡铺满主色 ⇒ 不漏底色；`backrop1` 仍只染 3px 一圈 ⇒ 旧高亮方案保留。
