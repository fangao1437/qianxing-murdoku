# baseline —— 两份关键存档（都在，别删）

| 文件 | 是什么 | 为什么留 |
|---|---|---|
| **`93-重建前-掩盖态.gil`** | 重建**之前**的存档（编辑器里有 `home` / `select` / `board` / `left` / `right` / `topbar` / `modal` / `intro` / `assets` …） | ★ **"点不动"这个 bug 在它上面**查不出来** —— 因为就绪判据写死的 `board` / `cell.1.1` **恰好还在**，判据为真、`on_start` 正常执行、缺陷完全不可见。**它是"隐藏耦合被掩盖"的现场证据。** |
| **`97-重建后-暴露态.gil`** | 重建**之后**的存档（编辑器里**只留 `home` + `stage` + 三个模板引用**，其余全部脚本创建） | ★ 同样的判据在它上面**永久为假** ⇒ `on_start` 永不执行 ⇒ 主页消失 + 隔断失效 ⇒ **症状爆炸、立刻定位**。**它是"一删就现形"的证据，也是当前开发的新基线。** |

## 用途

1. **回归验证**：以后改动"就绪判据 / 容器名单"这类东西时，
   **两个存档都跑一遍** —— 在 93 上必须也正常（不能因为名字变了就崩），在 97 上必须正常（新结构）。
2. **复现"查不出来"**：如果以后又遇到"明明有问题却看不见"，先回到 93 复现那个"被掩盖"的状态。
3. **对照实验**：93 → 97 的差异就是"删掉编辑器容器"这一件事，
   可以干净地验证"脚本创建"这条路（`stage` → `selbar` → `selbtn.*`）。

## 结论（写进这里，免得以后忘）

> **如果一个 bug 只在"我没动过的东西"里才查不出来，
> 那它不是查不出来，而是**我一直在依赖那个东西恰好没变**。**
