## 五 ★★ 真机回来之后：怎么把结论收回项目（★ 这一步别省 ✗）

★ ★★ **在编辑器里手改过的脚本，必须回收进 `lua/`** ✗✓ —— ★ 否则下一轮打包会**覆盖掉它** ✓

```powershell

#    同步脚本本来就会把【旧脚本】归档 ⇒ 先看归档目录里有没有意外内容
Get-ChildItem _backup\sandbox-scripts | Sort-Object LastWriteTime | Select-Object -Last 8

# ② 若确认有人在编辑器里改过 ⇒ 逐段并回 lua/，然后重新打包
lua tools/bundle_client_script.lua

# ③ 改完必须重跑关口（★ 判据见 docs/技术架构.md §八 ✓）
node tools/lua53check/check.cjs dist/client_script.lua --run     # LOAD OK / RUN OK ✓
Get-ChildItem tests -Filter '*.lua' | Where-Object { $_.Name -notlike '_*' } |
  ForEach-Object { lua $_.FullName }                             # 23 套 / 0 红 ✓
```

★★ **规矩** ✓：★ **`dist/` 是产物，`lua/` 是源** ✗ —— ★ 只改 `dist/` 等于把改动**写在会被覆盖的地方** ✓
