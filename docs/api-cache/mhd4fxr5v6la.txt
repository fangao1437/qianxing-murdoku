一、光标检测区域控件的功能
光标检测区域控件
是可接收光标射线事件的区域，例如：可以与图片，文本框控件一起组成一个最基础的按钮
光标检测区域控件是客户端控件，可以挂载
客户端脚本
，支持通过
客户端脚本
进行调用
查询接口：
可通过
CursorEventArea
在API文档里查询关联脚本接口
