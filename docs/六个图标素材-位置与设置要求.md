## 三、位置要求（**画布 1600×900，Y 向上，原点左下**）

### ⚠️ 先说清楚一个坐标系陷阱（**我第一版就在这里错了**）

布局图 `draw_layout_v2.mjs` 用的是**图片坐标：x 从左边、y 从**上边****：

```js
L130  // ① 左上：返回菜单
      iconBox(60, 48, 62, '<');          // y=48 是**从上边**算的
L163  text('RIGHT TOP  (TOP -> BOTTOM)', …);   // 右上三键明确「从上到下」
      iconBox(IX,  48, IS);   // 提交
      iconBox(IX, 144, IS);   // 重置
      iconBox(IX, 240, IS);   // 撤销
L197  // ⑦ 右下：放大镜
      iconBox(IX, 694, IS, 'Q');         // y=694 靠下
```

而**引擎画布是 Y 向上（原点左下）**（佐证：`topbar pos=(0,407) size=1600x87` ⇒ 顶边正好贴画布顶）。

**⇒ 换算公式：`引擎 y（下边） = 900 − 图片 y（上边） − 高度`**

### 换算结果（**三种写法都给全，按编辑器里习惯的那种用**）

| 控件名（建议） | 素材 | **① 布局图坐标**<br>(x, y 从上) | **② 引擎中心坐标**<br>(原点=画布中心, Y 向上) | **③ 屏幕坐标**<br>(原点=左上, Y 向下) | 尺寸 |
|---|---|---|---|---|---|
| `hex.back` | `hex-back` | (60, 48) | **(-709, 371)** | **(91, 79)** | 62×62 |
| `hex.confirm` | `hex-confirm` | (430, 46) | **(-295, 371)** | **(505, 79)** | 150×66 |
| `hex.submit` | `hex-submit` | (1448, 48) | **(683, 367)** | **(1483, 83)** | 70×70 |
| `hex.redo` | `hex-redo` | (1448, 144) | **(683, 271)** | **(1483, 179)** | 70×70 |
| `hex.undo` | `hex-undo` | (1448, 240) | **(683, 175)** | **(1483, 275)** | 70×70 |
| `hex.hint` | `hex-hint` | (1448, 694) | **(683, -279)** | **(1483, 729)** | 70×70 |

**三者的换算关系**：

```
② 引擎中心 x = ① 布局图 x + 宽/2 − 800
② 引擎中心 y = 450 − (① 布局图 y + 高/2)          ← 450 = 画布半高
③ 屏幕 x      = ① 布局图 x + 宽/2                   （距左边）
③ 屏幕 y      = ① 布局图 y + 高/2                   （距上边）
```

**⇒ 自查（这四条必须成立，否则一定是算错了）** ✅：

| 检查 | 期望 | 实际 |
|---|---|---|
| **返回菜单在最左上** | 屏幕 y 最小、x 最小 | **(91, 79)** ✅ |
| **放大镜在最右下** | 屏幕 y 最大、x 最大 | **(1483, 729)** ✅ |
| **右上三键从上到下** | 屏幕 y 递增：提交 < 重置 < 撤销 | **83 < 179 < 275** ✅ |
| **右上三键右边缘对齐** | 屏幕 x 相同 | **1483 / 1483 / 1483** ✅ |

> **我第一版就是在这里错的**：直接把布局图的 (60, 48) 当成引擎坐标 ⇒
> 返回菜单会跑到画布**中心偏上**而不是左上角。原因是布局图的 y 是**上边距**，
> 而引擎的 y 是**控件中心到画布中心**的偏移 —— 两个 48 完全不是一回事。

## 四、设置要求

| 项 | 要求 |
|---|---|
| **图片** | **静态引用 → 选中对应素材** |
| **尺寸** | **必须**原样**（62/150×66/70）—— ⚠️ 改不动；不对就告诉我，我按新尺寸**重新生成**素材 |
| **父子关系** | **必须挂在客户端控件容器**之外****（**图片只能走服务器控件** —— 官方：服务器控件的模板索引无法被客户端脚本调用）|
| **层级** | **放在对应按钮的**下面**一层**（先摆图标，再把按钮摆上去）|
| **可点性** | **不要给图标加点击事件** —— 点击由对应按钮（`action.back`/`action.redo`/`action.hint`/`action.submit`/`action.undo`/`confirm.ok`·`confirm.no`）负责 |
| **按屏显隐** | **不用你管** —— 脚本会按屏 `SetVisible` |
| **命名** | **按上表**（`hex.back` 等）—— 脚本靠名字找；换名请告诉我 |

**⇒ 两条硬约束（你的实测结论）** ✅：
1. **尺寸在"生成素材"这一步就定死**，之后调素材尺寸或图片尺寸**都不会影响显示**；
2. **图片只能挂在客户端容器**之外****（它只能是**服务器控件**）。
