## 3. 复核拿到信息后的落地步骤

1. 打开 `lua/engine_adapter_qianxing.lua`，把 `M.API` 里对应钩子的真名填上（只改这一段）。
2. 跑接线自检：
   ```lua
   local Q = require("engine_adapter_qianxing")
   print(Q.report())     -- 期望：21 项全部「已绑定」
   ```
   > 注意：`on_hold`（长按放置）和 `on_right`（右键切 X）是**必须**接上的两项，
   > 否则玩家只能写笔记、放不了棋子。若 7.1 没有独立的"长按"事件，
   > 就用按下/抬起时间戳自己算（`on_press` + `on_release`，阈值取 300–500ms）。
3. 跑离线自检确认逻辑没被带坏：`lua tests/selftest.lua`
4. 按 `docs/编辑器搭建指南.md` 第 4 步把 `on_ready / on_input / on_tick / on_signal` 挂到编辑器事件上。
5. 如果第 7 项（能否碰场景实体）结论与预期不同，按结论决定表现层（音效/镜头/粒子）
   是留在 Lua 还是移到节点图；`M.SIGNALS` 的表不用动。
