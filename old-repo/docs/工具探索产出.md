## 七、★ 还踩过的**小坑**（★ 各一次就够 ✓）

```lua
★ ① 别用 pwsh 内联 node -e 带引号 ✗ —— PowerShell 会吃掉引号 ✓
   ⇒ 一律**写成文件再跑** ✓
★ ② 中文路径必须 fileURLToPath ✓
   —— new URL().pathname 会 URL 编码 ⇒ ENOENT ✓
★ ③ PowerShell 的 String.Split('123') 是按【字符集】分割 ✗
   —— 数"出现几次"要用 [regex]::Matches(...).Count ✓
★ ④ 测试跑的是【打包产物】dist/client_script.lua ✗
   ⇒ 改源码后**必须重新打包**再验证 ✓（否则"破坏验证"会假绿 ✓）
```
