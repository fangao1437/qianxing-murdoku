## 一、依据：本机 GitHub v15 的原生基本图形构造法

来源：`qianxing-murdoku/docs/美术资产-原生图形构造与v12-v15演进.md`（commit `c9f94d0`，已 push）。

| 原则 | 本轮落实 |
|---|---|
| 每个图元完全落在目标凸区域内（零溢出），同色不透明重叠无缝 | 10 个阶梯色阶逐级自检：覆盖率 ≥99.91%、所有图元顶点在目标多边形内 |
| 斜边用压缩/旋转的 `100003` 等腰三角的**一条长底边**，其余用大块同色矩形补色 | 每级 = 1 个安全矩形 + 1 枚压矮旋转等腰三角（斜分界）+ 若干同色补漏矩形 |
| 不用竖直小矩形扫描斜边（v10–v12 已废弃，产生锯齿台阶外沿） | 斜分界由三角原生边给出；补漏矩形的右边界始终收在斜边以内，外沿不出现台阶 |
| 不依赖父级裁剪（659 实机确认不生效） | 可见 clip 容器 = 0 |
| 渐变按「离散色阶」实现 | 燕尾旗 3 级、线索卡 5 级，边界均为干净斜线 |

三角形旋转角全部为**正角**：`45°`（卡片 / 票券）、`60.75°`（燕尾旗），落在 660 已实机验证的 43°–71° 区间；燕尾旗 V 凹口两枚三角沿用 `rot 0/180`。
