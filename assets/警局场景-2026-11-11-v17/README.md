承接 v16（`assets/警局场景-2026-11-11-v16/`）。方法依据：本机 GitHub `qianxing-murdoku` 的
v15 及 `docs/美术资产-原生图形构造与v12-v15演进.md`；新增拟合工具

用户本轮反馈：**取消 v14→v15 的过渡柔化**、**阴影形状按设计图质感做清晰**；
**边缘有溢出、顶部有分叉**、**重新按设计图形状严格构造**，并指出「三角形的斜边构造法
完全够拟合该形状」。

## 一、取消柔化：x=1263 恢复清晰硬边

设计图在 `x=1263` 本来就有一条清晰竖直分界：以 `y=300` 为例，
`x=1260` R=129、`x=1266` R=154，**跳变 +25**。
v15 为「交界太硬」加了 20 条半透明渐隐带（`x=1223→1283`），v16 沿用，
把它抹成了 +3 的软过渡，阴影区看着「糊」。

**v17 全部删除渐隐带**：单个染黑 0.18 的整条 `100001` 主矩形
`x[900,1263] / y[170,763]` 直接到 `x=1263`，硬边一次到位。

| | x=1260 | x=1266 | 跳变 |
|---|---|---|---|
| 设计图 | 129 | 154 | **+25** |
| v16（柔化） | 147 | 150 | +3 |
| **v17（硬边）** | 130 | 157 | **+27** |

左斜边仍由后画的不透明档案袋遮挡自然形成；上边界 `y=170` 藏在胶带带内，不露水平硬线。
校验：`scene-v17*.json` 里 `fadeStrips=0`；`x≥1300` 与拍立得照片块与 v16 **逐像素差 0**。

## 二、楔形：按设计图严格拟合（不再用大钝角三角去「盖」）

用户在两张局部图里指出的两处问题，定位到了 v16 的两枚大钝角三角：

- **边缘溢出**（图 1，v16 的 x376,y472 起）：长钝角三角顶点 `(409.6,458.4)` 把楔形
  左缘向左鼓出，越过档案袋左缘。逐行实测：

  | y | 设计图左缘 | v16 左缘 | v17 左缘 |
  |---|---|---|---|
  | 450 | 422 | **412（溢出 10px）** | 421 |
  | 550 | 427 | **404（溢出 23px）** | 426 |
  | 600 | 440 | **422（溢出 18px）** | 441 |
  | 660+ | 无（止于 653） | 仍有 RED 到 710 | 无 |

- **顶部分叉**（图 2，v16 的 x442,y218 起）：楔形顶端由多枚 `fillTri` 三角拼成，
  收不成单一尖点，留下两条细尖角夹一道亮橙缝。

**严格拟合流程**（`fit-primitive-shape.mjs`）：

1. 设计图（等比缩到 1600×900）按 `#C75C18` 逐行取最长连续段 → 416 行 `{y,left,right}` 样本；
2. 左边界分 3 段、右边界 1 段做最小二乘 `x=a·y+b`：

   | 边界 | y 范围 | 拟合直线 | MAE | MAX |
   |---|---|---|---|---|
   | 左上 | 233–320 | `x=-0.357y+556.173` | 1.70 | 3.67 |
   | 左中 | 320–500 | `x=-0.187y+505.530` | 0.33 | 1.11 |
   | 左下 | 500–649 | `x=+0.287y+268.998` | 0.61 | 4.05 |
   | 右 | 233–649 | `x=-0.049y+488.323` | 0.29 | 1.52 |

   综合残差 **MAE 0.5px / MAX 4.05px**；
3. 四线交点构成严格凸四边形
   `(477.458,220.703) (449.654,298.660) (412.101,499.382) (456.168,653.161)`；
4. 用 **A**（整幅每边等腰三角）+ **B**（扇形剖分补尖角）+
   **C**（顶角三角：顶点贴多边形顶点、两腰贴相邻边，三顶点全在边界上 → 零溢出）
   生成 **26 枚 `100003`**；几何自检 **100% 覆盖 / 0 溢出**。

v17 用这 26 枚**彻底替换** v15/v16 的「2 个 `fillTri` + 2 枚大钝角三角」。
渲染复核：目标凸区内部亮橙洞 **0**，顶端收成单一尖点，下缘不再越过档案袋左缘。

## 五、校验

- 两份 `.gia`：根层无 `field 4`、`.gia+4=2a05362e`、文本包含性正确；
  artkit 两份 `ok=true / budgetExceeded=false / kind=3 / trailer 0x679`。

- 硬边：`fadeStrips=0`，`x=1263` 跳变 +27（设计 +25）。
- `x≥1300` 与拍立得照片块与 v16 逐像素差 0；楔形内部亮橙洞 0。
- 阴影区与设计图 MAE：v16 22.84 → v17 **22.63**；中段 19.44 → **19.19**。
