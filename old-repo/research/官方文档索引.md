## 已取到正文的两篇（含要点摘录）

### 《界面控件》`mhnapxrumtzy`

- 界面控件分**固有控件**（小地图/技能区/队伍信息/生命值条/摇杆/退出按钮/选项卡/聊天/
  网络状态/挣扎按钮/语音…：不可移除、不可移动、不可调尺寸，仅少量配置）与
  **预制控件**（交互按钮/道具展示/文本框/弹窗/进度条/计时器/计分板/卡牌选择器/界面动效/
  全屏界面动效/图片/自定义按钮/自定义开关/悬浮交互页/特殊数字）。
- **交互按钮 / 道具展示**：点击与外接设备输入都能触发，交互后**向节点图发送「界面控件组触发时」事件**。
- **文本框**：填了自定义变量就会**实时刷新** → `clue.<n>` / `hud.*` 可以不走脚本、直接绑变量。
- 通用配置：**索引**（保存为控件模板后才有，供节点图引用）、变换（设备/位置/大小/缩放/旋转/
  **锚点**/中心/层级/初始可见性）。
- **渲染模式**：`时序渲染(旧)` vs `层级渲染(新)`（月之六版本引入，之后新建存档默认新）。
  旧的层级参数不生效，后加控件会串层；官方建议统一用新的。
- 素材库：可复用控件组合，支持矩形/圆形**遮罩**；可用在自定义开关/自定义按钮/悬浮交互页/
  页签/单选项视窗/图片控件里。

### 《局内存档》`mhzcw29qjjma`

- 定义：保存玩家**在特定关卡内产生的数据**，离开关卡也保留，再进关卡时带入。
- 数据结构：可配多个**局内存档模板**，同时只能启用一个；模板内含多个**局内存档结构体**（定长列表）。
- 支持类型：**GUID / 整数 / 布尔值 / 浮点数 / 字符串 / 阵营 / 三维向量 / 元件ID / 配置ID**
  （及各自的列表）；**不支持结构体、字典、实体、实体列表**。
- 读写：每个结构体会在玩家实体上生成同名**局内存档变量**，用**自定义变量节点**读写；
  **读档发生在实体创建之前**（所以"实体创建时"事件里能查到数据），**存档发生在离开关卡时**。
- 限制：列表必须预设最大长度，存档时**超长截断**；关卡总数据量超限会导致**无法试玩或发布**。
- 升级：只允许**纯增量**（新增结构体 / 新增成员）；删除、替换、缩减长度、改成员类型都会
  导致读档失败、玩家数据重置。编辑器内置**对比模板**功能校验升级是否合法。
- 入口：系统菜单 → 【局内存档管理】。

**对本工程的直接影响（已据此改代码）**：`serialize()` 的嵌套表**写不进局内存档**，
所以 `Murdoku.save_now()` 改为存「**分享码字符串** + 3 个整数」，读档时用 `decode_state()` 还原。

### 为什么 `raw.githubusercontent.com` 会超时（实测结论）

同一时刻的对照结果：

| 探测目标 | 结果 |
|---|---|
| `example.com` | ✅ 200 |
| `api.github.com` | ✅ 200 |
| `act-webstatic.mihoyo.com` | ✅ 200 |
| `raw.githubusercontent.com` | ❌ 30s 超时（多次），偶尔 `fetch failed` |

→ **不是全局断网，也不是抓取器坏了，而是这个域名在当前网络下不可达**
（典型是 DNS 污染 / SNI 阻断，或"本机代理只代理了部分域名"）。
会话早期它还能通、后来完全不通，符合代理节点抖动或链路策略变化的特征。
补充两点：`cdn.jsdelivr.net` 会 302 跳到 `raw.githubusercontent.com`，
而抓取器**不跟随跨域跳转**，所以这条路也不通；`r.jina.ai` 直接失败，
`api.codetabs.com` 返回 522（是它自己回源超时）。
