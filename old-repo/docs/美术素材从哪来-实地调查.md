## 零、★ 完整通路（已实测跑通）

```
我：用 JS 描述想要的图形（矩形/椭圆/三角形/四角星/五角星/六边形/文字…）
      ↓  POST https://qx.070077.xyz/api/export/gia
      body = { scene: <场景>, giaGroupName: "<素材组名>" }
      ↓
得到一个合法的 .gia 文件
      ↓
你：在千星沙箱里「外部资产」导入它
```

**实测输出**：

```
场景：512×512  图元 3 个：rectangle, hexagon, textbox
✅ 导出 tools/qx/out/demo.gia  5676 字节
   头：大小−4=5672 ✅  类型=3（3=.gia）  体长=5652  尾=0x679 ✅  体长自洽=✅
```

**工具**：`tools/qx/gia.mjs`（`scene()` / `add()` / `exportGia()` / `header()` 都导出了，可以当库用）

### 两个踩过的坑（已修，注释在代码里）

| 坑 | 症状 |
|---|---|
| 直接 POST 场景本身 | **422 Unprocessable Entity** —— body 必须是 `{ scene, giaGroupName }` |
| `'file:///' + process.argv[1]` 判断"是否直接运行" | 路径含中文时 `import.meta.url` 是**百分号编码**的 ⇒ 永远不等 ⇒ **跑起来一行输出都没有**。用 `pathToFileURL()` |

### `.gia` 与 `.gil` 是**同一个容器格式**

```
[u32 文件大小−4][u32 1][u32 806][u32 类型][u32 体长][protobuf 体][u32 0x00000679]
                                    ↑ .gil=2   .gia=3        └ 大端
```

**⇒ 整段头都是大端**（尾也是；我第一版把尾读成小端 ⇒ 误报"尾标记错"）。
**⇒ 所以 `.gia` 也能用 `tools/gil/gilread.mjs` 那一套读** —— 同一个格式，只是第 4 个字段不同。

## 一、另一条路：**游戏自带的 1543 个图片素材**（不用导入）

那个外部编辑器的 API 是**同源相对路径**，可以直接调：

| 端点 | 作用 |
|---|---|
| `/api/library/catalog` | **图片素材目录**（130 KB）|
| `/api/library/sprite/<id>.png` | 单张 sprite |
| `/api/export/gia` | 导出 **GIA**（"游戏素材格式"，**支持文字**）|
| `/api/export/lua` | 导出**客户端绘制脚本**（"可再次导入"，只画图片图元）|
| `/api/export/png` `/svg` `/css` `/json` | 常规格式 |

### `/api/library/catalog` 里有什么

**1543 个游戏图片素材，14 类**：

| 分类 | 数量 | id 区间 | 适合做什么 |

## 二、"看图挑"这条路也打通了

目录里**只有 id 和分类名，没有单张素材的名字** ⇒ 想知道哪张是椅子只能看图。
所以我做了 **接触表**：把一类的 sprite 拼成一张大图，我直接看图挑。

```powershell
node tools\qx\library.mjs fetch                       # 拉目录
node tools\qx\library.mjs list 道具                    # 看某类的 id
node tools\qx\library.mjs sheet --cat=道具 --max=139   # 下载该类 sprite
powershell -File tools\qx\make_sheet.ps1 -Dir tools\qx\sprites\9 -Out out.png -Cols 14
```

**已拼好的接触表**（我实际看过）：

| 文件 | 内容 | 我看到的 |
|---|---|---|
| `tools/qx/out/sheet-props.png` | 道具 ×139 | 苹果/食物/卷轴/钥匙/宝箱/武器/饰品/药水/宝石 |
| `tools/qx/out/sheet-creation.png` | 造物 ×42 | 各元素史莱姆、兽面、**戴口罩角色（112030/112031）**、**戴礼帽侦探（112040/112041/112042）** |
| `tools/qx/out/sheet-deco.png` | 装饰图案 ×64 | 四角星、雪花、猫头徽章、手势、圆形插画 |
