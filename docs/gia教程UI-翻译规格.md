# 教程 UI 资产（翻页 + 单击活动样式）→ 客户端 Lua 翻译规格

> 对象：`assets/教程UI系统_翻页单击活动样式.gia`（171,822 B）
> 内部 `filePath` = `155266770-1783347769-1073741835-\教程模版v1.3_提醒了部分字段无需翻译.gia`，`gameVersion` = **6.7.0** 〔实测〕
> 目的：把这份「服务器节点图实现的教程 UI」翻译成**我们能用客户端 Lua + 存档控件落地**的规格：
> ① 关闭图标 → 米白色小 x；② 页标 → 菱形小点；③ 侧边大箭头翻页；④ 翻页 / 关闭状态机。

> **证据等级**：`[实测]` = 工具输出（命令见 §6）；`[推断]` = 由实测结构推得、未见真机；`[UNKNOWN]` = 读不出来。
> 全部结论都来自 protobuf wire 解码与官方素材 PNG，**没有一处猜字段名**。

## §0 一句话 + 三个必须知道的前提

1. 这**不是**「服务器节点图」实现——文件里那个节点图叫 `[玩家]教程节点图`（`which=9`），
   里面用的节点是 **`向服务器节点图发送信号`**（客户端→服务端方向），属**玩家/客户端节点图**。
   ⇒ 它的逻辑**可以 1:1 搬进客户端 Lua**，不需要服务端。〔实测〕（`graph.mjs` 输出 + 节点单元引脚名，见 §3.2）
2. 它的翻页/显隐几乎**不靠脚本**，而是靠**控件自身的「页签（Tab）」能力 + 数据里声明的"页签项→控件显隐"表**。
   这套声明式表在 `.gia` 里**完整可读**（§1.5 / §2.1），是本份规格最有价值的部分。
3. 资产里的**素材是默认占位**：菱形点用的是「基础形状」纯白方块、箭头按钮的图标是「深色圆盘+金环」，
   **不是**用户参考图里的青色大箭头。⇒ 图形要我们自己定（§1.6 给了 100004 菱形 / 100005 箭头的实测依据）。〔实测〕

| 1 | #1073744222 | **教程-未被选中** | 图片 7.5×7.5 + 图片 10×10，imageId 均 `100001` |
| 2 | #1073744225 | 教程-被选中 | 图片 7×7 + 图片 10×10，`100001` |

⇒ **"选中"= 换成 `教程-被选中` 那套图组，"未选中"= 换 `教程-未被选中` 那套**；
控件内 4 条记录 = 4 个页签项各自的外观（1 未选 + 3 选中）。**Lua 侧等价做法 = 每个点准备
`off` / `on` 两张图，`SetVisible` 互斥**（§4 给了命名）。

**菱形从哪来**〔实测〕：素材 id 全是 `100001` = **基础形状第 1 张 = 纯白方块**（256×256，alpha 全满）。
所以资产里"点是白的方块"，**不是菱形**。要 `◆` 必须自己选形状：
- **`100004` = 基础形状里的菱形**（alpha 轮廓实测：宽度先增后减的 4 角星形）⇒ **页标就用 100004**；

> 这 6 张就是模拟器唯一能预览的图元区间 `100001–100006` ⇒ **菱形页标用 100004 不需要外部资产**。
