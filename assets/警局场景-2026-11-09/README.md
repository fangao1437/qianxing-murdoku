## 二、输入与链路

- 图 A：有档案袋、拍立得与右上角咖啡杯的设计图；图 B：同场景无遮挡背景图。两图背景**像素级一致**（未遮挡区 diff=0），所以用 B 的对应区域以 12px 羽化覆盖即可无损去掉杯子。
- 去杯子成品、干净背景、透明前景留在 `BeyondLocal/Beyond_Local_Export_SourcePNG/`，未入库（源图属用户素材）。
- 资产链：设计图 --精测--> 拼图站 scene JSON（纯官方基础形状分层）--> `/api/export/gia` --> `.gia` --> 游戏内「导入外部资产 → 转存所选资产」。
- 画布按官方界面 **1600×900**（原图 1280×720，元素 ×1.25）。

## 三、精确测量（本轮的关键）

直接在全图做颜色阈值或颜色距离分类**会被背景暗角渐变污染**：底色从 `RGB(183,74,32)` 暗到 `(51,18,6)`，中间值恰好落在深橙/橘红主色附近，凸包会被撑成整幅画。正确顺序：

1. `scene-no-cup.png`(A) 与 `background.png`(B) 逐像素差分，`max|RGB_A - RGB_B| > 14` 即前景，先剥出物件；
2. 仅在差分 mask 内做到主色距离分类 + 凸包 + 直线拟合；
3. 原图 1280×720 --×1.25--> 设计 1600×900 --> 档案袋局部坐标：
   `u = (X-666)cos15.4 - (Y-331)sin15.4`，`v = (X-666)sin15.4 + (Y-331)cos15.4`。

测得：

| 区域 | 原图顶点 | 设计坐标 | 局部 (u,v) |
|---|---|---|---|
| 深橙四边形 | (820,250) / (460,590) / (820,485) | (1025,313) / (575,738) / (1025,606) | (351,78) / (-196,368) / (273,361) |
| 橘红楔形 | 每行稳定 x≈330–380，y≈200–590 | — | u∈[-265,-225]，宽 40–60、长 460–520 |
| 分割线 | y = -0.27x+176 / +704 | — | v = -281 / +356 |

深橙区两直角边为 **469 与 293（非等腰）**，斜边局部斜率 −0.53、底边 v≈365。实现时夹到档案袋右边缘 u=300 得 A′(300,105)，按「大小足够」把左下扩到 (−300,400)、底边抬到 v=395，斜边 `v = 105 + 0.492·(300-u)`，用 100 条局部竖矩形随档案袋旋转铺满——单条平滑斜边、形状贴合、零溢出。

## 四、可复用实测结论

1. **GIA 导入格式**：能导入的样本 protobuf 根层**没有** `field 4`；带 `field 4 = 1` 是「经典模式」标记，导入失败。`artkit check` 只验容器头，查不出这个字段，必须解析根层。
2. **官方基础形状**：`100001` 直角矩形、`100002` 圆、`100003` **等腰直角三角形**（`rotation=-135` 为直角在右下，`-45` 直角在右上，`45` 直角在左上，`135` 直角在左下；`W=2H` 时两直角边相等，`L=W/√2`，直角顶点相对元素中心 `(+L/4,+L/4)`）。`type=polygon/triangle/path` 与自定义 `points` 会被忽略，仍渲染成默认三角形。
3. **两到三个三角形拼不出非等腰的斜切四边形**：斜边固定 45°，错开拼接必然形成 M 形山峰；按精测顶点铺细矩形更准。
4. **柔和投影**：`106056` 柔光圆，7 位纯黑 `#000000` + opacity 0.26–0.28，尺寸 = 物件 ×1.18–1.20，中心右下偏移 (+28,+32)，与物件同旋转。**9 位 ARGB `#66000000` 拼图站不支持，会解析成红色**；只放大 1.06× 会被物件完全盖住而看不见。
5. **官方暗角**：`106060` 就是径向暗角素材（同组 106055/106058），单层染黑 1800×1040 铺满即柔和环形暗角。`100006` 圆环单层放大有硬椭圆边，不必叠加。四条边各放柔光椭圆是「条形」，四角各放柔光圆会在中间露竖直亮带，均已实测排除。
6. **文本框**：`textBox.fontSize` 与 `rotation` 确实写入 GIA（rot=0/9 导出差 20 字节，与图元旋转编码一致），但**导出 PNG 预览器忽略二者**，固定渲染成水平小字，不能拿预览验收文字。
   - 项目硬口径：框高 ≥ 2×字号、窄框宽 ≥ 1.5×字号；本版 `fontSize 48` / 框 `480×120`。
   - 文字垂直偏移实测：设计图相对黄带中心 −3～+3px（居中），游戏内 v3 为 −28～−33px（偏上），故三个文本框统一 `y+30`。
   - `rotationZ` 与 scene `rotation` **同号**（同一套导出链路），不要取负。
7. **黄带中心线**（1600×900）：上 `y = 367.6 - 0.1584x`（rot +9），下 `y = 606 + 0.1336x`（rot −7.6）。

## 五、复现

1. 改 `scene-v10.json`（元素坐标、颜色、素材 id、文本框参数都在里面）；
2. `node build-v10.cjs`（脚本内直接构造场景；也可改成读上述 JSON）向 `https://qx.070077.xyz/api/export/{gia,png}` POST；
3. 用 `artkit.mjs check --kind=gia --json` 验容器，另需确认 `.gia+4` 不是 `2001`；
4. 产出 `.gia` 放入 `BeyondLocal/Beyond_Local_Export`，游戏内导入并「转存所选资产」。
