## 一 根因（本地离线复现，可重复验证）

`lua/ui_controller.lua` 的 `build_layout` 里：

```lua
local furn_recs = nil
local level_id = nil
do
  ...
  local furn_tpl, furn_span, furn_offset = {}, {}, {}   -- ← 声明在 do 块里
  ... 填空 ...
end
...
furn_tpl = (furn_tpl and furn_tpl[r] and furn_tpl[r][c]) or false   -- ← 在 do 块外
```

**Lua 不报错**：`do` 块外那三个名字解析成**全局 nil** ⇒ 每个格子节点下发
`furn_tpl=false / furn_span=false / furn_offset=false` ⇒ 适配层一件都不实例化 ✗
（`furn_art` / `furn_recs` / `level_id` 是**函数作用域**声明的，所以它们一直正常 ——
这正好解释"别的东西都对、只有家具不出现"。）

复现证据（本地）：修前 `格子节点里 furn_tpl 非 false 的个数 = 0`；修后 **case_001 = 8 件 / case_002 = 12 件**，
且 `furn_span`/`furn_offset` 全部配套（抽查：`cell.1.2=furn.plant`、`cell.6.2=furn.shelf` ✓）。
