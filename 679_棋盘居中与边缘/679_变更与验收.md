## 一、注释卡边缘：颜色连贯 + 形状

### 678 的两个问题（用户反馈）
| 项 | 678 | 设计稿 |
|---|---|---|
| 颜色 | 主体齿用纯基色 `#8C2800`，描边 `#592520` 深棕且齿带相接成 11px 宽粗带 ⇒ 齿比主体亮部暗一截、凹口一整块深棕 | 撕纸边的齿与**主体亮部同色连续**，只有一圈细深棕描边 |
| 形状 | 规则「矩形平段 + 尖三角」，凹口 6~10px 深，齿像方块 | 圆润波浪撕纸边，凹口是浅 V 形 |

### 679 改法（沿用 678 的 24 齿层，原地改几何/颜色/img/rot，不新增记录）

| 项 | 678 | **679** |
|---|---|---|
| 主体齿色 | `#8C2800` | **`#AF3200`**（672 渐变 mid 同色 ⇒ 与亮部连贯） |
| 描边色 | `#592520` | **`#6B2A12`**（浅一档深红棕 ⇒ 消除深棕粗带） |
| 齿尖 | `100003` 尖三角 w16/h4 | **`100002` 椭圆**（圆润齿角） |
| 齿高 / 齿距 | 16 / 22（凹口 6px，分离方块） | **20 / 22（凹口 2px 浅 V 形，连成波浪带）** |
| 描边齿高 | 22（相接） | **24（相接，凹口只露细描边）** |
| 主体 / 描边矩形 | 142×66 / 148×72（缩进 9px） | **144×66 / 150×72（缩进 8px）** |

### ★ 三轮迭代（复用优先读）
1. 初版椭圆 `8×16` 太窄 ⇒ 齿成**分离圆球**（比 678 更不像设计稿）。
2. 改大椭圆 `14×16` 与主体重叠 ⇒ 仍是分离圆球，只是更饱满。
3. **定稿**：缩进 9→8px、**齿高 16→20（≈齿距 22）** ⇒ 齿连成波浪带、凹口收成 2px 浅 V 形；
   大椭圆 `8×20 @±76` 与主体重叠 4px 提供圆角，矩形 `6×20 @±75` 保留平边缘段
   （用户上一轮补充「部分区域还需要矩形来塑造平边缘，图形不必局限我给的」）。

### ★ 零溢出仍成立
23 枚 672 渐变三角本地 `x∈[-70,51]`；缩进收到 8px 后主体半宽 **72**，余量 2px ⇒ 渐变更安全。
像素级掩膜闸门（4×）：主体 **166,092** 像素 ⊆ 描边 **溢出 0**；
渐变 **93,060** 像素 ⊆ 主体 **溢出 0** ⇒ `zeroSpur = true`，构造边缘无毛刺。

## 二、棋盘移动端 y 居中（x 不变）

### 口径测量（不靠目测）
| 项 | 值 |
|---|---|
| 移动端截图 | **1280×576**（2.222:1） |
| x 缩放 | `k = 1280/1600 = 0.8`，`x0 = 0` |
| 等比缩放后可见原图区 | `y∈[90, 810]`，**可见中心 y = 450** |
| 映射验证 | 深色框原图 `y∈[107,733]` → 截图 `y∈[14,513]`，反解 `y0≈90`，上下对称裁切 |
| 棋盘深色框实测 | 截图中心 `263.5` vs 屏幕中心 `288` ⇒ **偏上 24.5px** |
| 换算 1600 口径 | `24.5 / 0.8 = 30.63px` ⇒ **取 Δy = +30**（棋盘中心 420 → **450**） |
| 白底板 / 斜网格纸 | 截图中心 278.5 / 287.0（偏上 9.5 / 1.0px）——大背景纸本就铺满，视觉重心由棋盘主体决定 |
