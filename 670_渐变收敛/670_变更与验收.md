# 670 渐变收敛：变更与验收

**基准**：`669_旧高亮方案.gil`（SHA `567a1045…5d55d`，6,976 条），保留未改
**产物**：`670_渐变收敛.gil`（SHA `13f6a790…f672`，7,040 条，可直接导入）
**当前最新成果**。

用户反馈：「红色拼接图形没有完全被收敛在边界内，导致描边有毛刺，而且上方有一条设计图没有的白带，把全卡染为同样的渐变样式，确保拼接图形不溢出 + 边缘完全平直 + 不漏底色」。

---

## 一、根因

669 把 661 那套**针对 330×85.4 精算**的 28 层 `fillRegion` 图元做了非等比缩放（`SX=0.9818`、`SY=0.9297`）。661 的每一级是「大安全矩形 + 1 枚压矮旋转等腰三角（长底边贴 45° 斜分界）+ 若干同色补漏矩形」，三角斜边角度由 `w/h/rot` 决定，补漏矩形右边界按 `polyRight(poly, y)` 逐行算 —— **非等比缩放后这三者全部失配**：

- 部分图元顶点越过 324×79.4 边界 → 黄描边内侧的**毛刺**
- 部分采样点无人覆盖 → **漏出暗底色**
- `art658.clueN.rule` 白线（330×5 @ 卡片顶边，缩放后 324×4.65）画在渐变之上 → **设计图没有的顶部白带**

## 二、解法：按目标尺寸重新生成，而不是缩放

1. **隐藏**两套模板各 30 层旧渐变（含 `rule` 白线），共 60 层 —— 白带随之消失。
2. 用 661 的 `fillRegion` 算法，针对 **`backrop2` 的 324×79.4**（`x638..962 / y410.3..489.7`，中心 800,450）重新生成一整套：
   - `art670.clueN.base` 324×79.4 `#611F23` **铺满整卡**（与 `backrop2` 同色，兜底不漏底色）
   - 4 级 45° 斜向阶梯：`s300 #68262A` → `s250 #70272E` → `s200 #68262A` → `s095 #9D3033`
   - `D` 值按 324/330 等比缩放（294.55 / 245.45 / 196.36 / 93.27），保持原有视觉比例
   - 每级自带 **零溢出顶点自检 + 覆盖率 ≥99% 自检**；三角旋转角统一 45°（安全正角）
3. 新增层插在 `backrop2` 之后、`who` 文本之前；`recTop` 与 `childList` 同步同序。

| 自检（8 个色阶区域） | 结果 |
|---|---|
| 图元溢出顶点 | **全部 0** |
| 最低覆盖率 | **99.91%** |
| 三角旋转角 | 全部 **45°** |
| 每模板新增层 | 32（1 base + 6/6/7/12），共 64 |

**保留 669 原样**：`backrop1 #FF56565E`（染色区 330×85.4）、`backrop2 #FF611F23`（324×79.4）、白字、卡片区白色底板、内嵌 Lua、26 条文本、v19 背景子树。

**效果**：整卡红渐变铺满、边缘由 base 矩形与安全矩形给出而完全平直、不漏底色；选中态 `_grid_paint_highlight()` 仍只染 `backrop1`，**3px 一圈变黄、卡面渐变不变**。
