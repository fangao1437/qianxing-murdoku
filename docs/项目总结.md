## 四 ★★ 这一轮（六轮修复）真正学到的东西 —— 平台事实

★ 这些都是**真机或模拟器实测**出来的 ✓（★ 不是猜的 ✓ 可直接当结论用 ✓）：

1. ★★ **`.gil` 存不下控件的文字** ✗ —— ★ 344 条记录里**一条"非名字文本"都没有** ✓
   ⇒ ★ 按钮文案只能 ① 编辑器里手填 ② 脚本运行时写 ✓（`tools/gil/_probe_texts.mjs` 可复核 ✓）
2. ★★ **几何的权威是编辑器那份** ✓ —— ★ 脚本一旦每帧下发几何，就会把用户调好的位置覆盖掉 ✓
   ★ 现在的唯一规则：★ **只有"脚本自己建的控件"与"显式 `pos_runtime = true` 的那几类"才由脚本摆** ✓
3. ★★ **`.gil` 里的位置是【画布绝对】坐标**（1600×900、中心为原点、y 向上）✓，
   ★ 设计空间是 1920×1080（左上原点）✓，★ 两者差 `5/6` 缩放 ✓ ——
   ★ **CSS 像素永远不要直接抄进 Lua** ✓
4. ★★ **父级不在原点时，容器坐标要放在原点** ✗✓ ——
   ★ 否则 `.gil`（绝对）/ 引擎（父级相对）/ 转换器三方读法**不一致** ✓（`win` 就是这么改对的 ✓）
5. ★★ **状态块是稀疏编码** ✓：值为 0 的分量**根本不写** ✓ ⇒ ★ "缺字段" ≠ "没有这条" ✓
6. ★★ **模拟器有的做不到** ✗：★ 点不动 `hex.*` 那一族 ✓、★ 不实例化网格列表项（放不了子 ✓）、
   ★ 看不到运行时设的图（胶囊底图 ✓）⇒ ★ 这几件事**只能真机** ✓
7. ★★ **`.gil` 的父指针有两处** ✓：★ 父的子列表 `#503` ＋ ★ 记录自己的顶层 `#504` ✓
   ⇒ ★ 建控件时**两处都要改** ✓（只改一处 ⇒ 复读核对当场报错 ✓）
8. ★ **文字对齐**：`/505/503/75/508`（水平 0左/1中/2右）＋ `/509`（垂直 ✓）✓
   ★ 缺 = 0 = 左对齐 ✓ ⇒ ★ 文字框比按钮宽时**必须**显式设居中 ✓
