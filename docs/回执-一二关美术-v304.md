## §1 三点改动（其它一律没动）

| 用户要求 | 改动 |
|---|---|
| **横桌双腿往内收** | `table["h2"]` 的两条腿 `dx ±0.736 → ±0.600`（腿在桌面宽度内的比例从 88% 收到 72%）；竖向 `v2` 与单格 `1` 的腿本来就在内侧，未动 |
| **加上阴影** | 三套桌子的投影层统一加强：`106056` 柔光圆 **只放大到桌面宽度（不再向两侧溢出）**、往下偏 `dy +0.22~0.26`、高度撑到 `0.96~1.76`，阴影色 `0x9A000000`（≈60% 黑） ⇒ 桌沿/腿下方能看到柔和投影（实测桌下像素 217,205,180 → 168,158,139，约暗 20%） |
| **椅子改回上版** | 图元数据生成里对 `chair` **去掉"越界/极细丢弃"**，回到上一版（v302）那套未过滤图元 ⇒ 靠背弧、扶手内线等细线都回来了 |
| **稍微修一下阴影边缘** | 对 `chair` 只做**软裁剪**：图元超出整件包围盒的那一边把尺寸截到包围盒（中心不动、图元不丢）⇒ 阴影边缘不再跨过格线（实测 16 条图元被裁），椅子轮廓线全保留 |
| **其它内容不用动** | 植物 / 雕像 / 书架 / 地毯 / 房间名 / 尺寸策略 / 图元总量 …… 全部保持 v303 |

## §4 未验证 / 风险

1. ★ 真机仍待验：`InstantiateClientUIControl` 用 `tpl.prim`（新模板），失败症状"家具整件不见"；
   回退命令 integrator 已给（`--family=79` / `--guid-base=1073746400`）。书架/桌子走手搭层，不受这条影响。
2. 桌子阴影是"柔光圆 + 60% 黑"，**比原作略重**（原作阴影非常淡）。真机若觉得重，把 `lua/furn_art.lua` 的
   `C.shadow` 从 `0x9A000000` 改回 `0x70000000` 即可（一处）。
3. 椅子"软裁剪"只裁**尺寸**、不动中心：如果真机上某条阴影边缘仍在格线外，说明那条图元中心就在格外
   （数据里没有），到时把 `dy` 整体再收 5% 即可。
