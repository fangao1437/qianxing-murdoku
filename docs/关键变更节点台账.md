## 一、判定规则

1. 一条「主题线」只认**最终收口档**：回执写明「定版 / 收尾 / 收官 / 闭环 / 归一 / 用户真机确认」的那一版。
2. 同前缀连续编号的回执（例如「回执-一二关美术-v299 … v310」）合并为一条线，取末版。
3. 被后续文档明确推翻的结论（例如 v357 的层序修正、v210/v211 的性能数字）不单列。
4. 自述「仍未解决 / 待验 / 未闭环」的版本不列为节点。
5. **609–638 属于「近 30 版」，不重复计作里程碑**；其中确属主题线收口的另作标注。
6. 每个节点必须能指向**一个结果存档**和**一份方法文档**；方法缺失的在 `里程碑方法汇编.md` 中补齐。
