## §1 ② 第二关大量错位 —— 根因是我们 v320 引入的缩放回归（已修）
v320 把"模板层缩放"改成**按模板画布分 x/y**：
```
fx = 实例宽 / 画布宽,  fy = 实例高 / 画布高
```
但 `cfg.furn_tpl_canvas` 当时**只登记了 `rug_2`**，横桌/竖桌没登记 ⇒ 按默认 108×108 算：
- 6×6 关格子≈89px，横桌（画布 216×108，跨 2 格）：`fx = 89×2/108 = 1.65`、`fy = 89/108 = 0.824`
  ⇒ **横桌所有层被横向拉宽约 2 倍**，从格子里溢出去 —— 这就是截图里那些跨好几格的"土黄色大条"；
- 竖桌（画布 108×216）同理被纵向拉长。

**v321 修复**：`furn_tpl_canvas = { rug_2={216,108}, table_h2={216,108}, table_v2={108,216} }`，
其余家具按 108×108 默认。修复后：
- 5×5 关：fx=fy=1（横桌 2 格=216px 与画布 216 相等）；
- 6×6 关：fx=fy≈0.824（等比，不再溢出）。
