## 一 ① 选关「只出一张」—— 真因与证据

### 1.1 为什么是它（和你给的"397 之后"对得上）

| 版本 | 改了什么 | 与本 bug 的关系 |
|---|---|---|
| v255（397） | `tint` 分支加了一句 `self:_fit_child_to_cell(ctrl, target)` | ★ **入口就在这里**（"`face` 钉成格子大小"） |
| v256（399/400） | `image` 分支也加了同一句 | **第二条触发路径**（卡片 `image` + `tint` 都会下发 ⇒ 各触发一次） |
| v257（401） | 给 **`rect` 分支**的贴格钩子加闸门 `^cell%.%d+%.%d+$` | ★ **只堵了一条路** ⇒ 症状仍在（你看到的"依旧只有一张"）✓ |

事故链（一句话）：

```
select.card.N 没有 face 子控件
  ⇒ target = self:sub(id,"face") or ctrl   ← 落到【卡片自己】
  ⇒ _fit_child_sized(ctrl, w, h)
  ⇒ SetSizeDelta + SetAnchoredPosition(0, 0)
  ⇒ 四张卡各自被钉到【父级中心】⇒ 叠在一起 ⇒ 看起来只有一张
```

### 1.2 修法（两处 + 一道兜底）

- 新增 `is_cell_id(id)`（`id:match("^cell%.%d+%.%d+$")`）
- `image` 分支：`if is_cell_id(id) then self:_fit_child_to_cell(ctrl, target, id) end`
- `tint` 分支：`if is_cell_id(id) then self:_fit_child_to_cell(ctrl, target) end`
- `_fit_child_to_cell` 内部再兜一道（第三个参数是 id 且不是格子 ⇒ 直接返回）

### 1.3 证据：有效 Red → Green（可复跑）

新增用例 **`tests/card_fit_gate.lua`**（假控件树跑真适配器，8 条断言）。

```
# 改前（git stash 掉适配器那一次改动）
[murdoku] 图层贴格：select.card.1 ← 格子 209×291.6      ← ★ 卡片自己被"贴格"
  FAIL  image：卡片位置没被改（仍 0,0）                  ← ★ 位置被钉成 (0,0) = 叠在一起
  FAIL  tint：卡片位置没被改（仍 0,0）
card_fit_gate: 6 passed, 2 failed

# 改后
[murdoku] 图层贴格：face ← 格子 108×108                  ← ★ 只有格子的 face 被贴
card_fit_gate: 8 passed, 0 failed
```

⇒ **Red 是有效的**：失败点正是生产行为（卡片位置被改成 0,0），不是用例写错。

### 1.4 ★ 为什么模拟器一直没抓到这个（重要）

`_fit_child_to_cell` 第一步要读 `size_of(ctrl)`；**模拟器桥接没有 `GetSizeDelta`**
⇒ 读不到尺寸 ⇒ `early-return` ⇒ **塌陷在模拟器里根本不发生**。
所以这条只可能被"假控件树单测 + 真机截图"抓住 —— 模拟器 A/B 永远给不出红灯。
（这也是本项目第 N 次"模拟器绿、真机红"，判定按平台事实 §5：**环境差异，不是玩法缺陷**。）

## 八 v263 追加 —— 墙加长 4，填掉格与格之间的缝（2026-10-18 02:0x）

> 用户真机反馈（原话）：「**选关修好了**，现在**墙稍微有一点缝隙**，把**墙的长度增加 4**，填满现在的空隙即可」

| 项 | 内容 |
|---|---|
| 缝从哪来 | 每格只画**自己那一条边**，长 = 格子边长 `cw`；相邻两格各画各的 ⇒ 取整误差在**四角**留 1–2px |
| 改法 | 新增配置 `cells.edge_overlap = 4`；`tlen = cw + overlap`（**只加墙，不加门**） |
| 为什么位置不变 | `localScale` **绕中心**缩放 ⇒ 加 4 = 两端各溢出 2 ⇒ 角上相邻两格**重叠**，缝消失 |
| 日志 | `边缘适配 wall.up：基准 24x8 → 目标 130x8`（← 126+4；改前是 126）|
| 门 | 仍 `cw × door_length_ratio(0.30)` ⇒ 明显短于墙，观感不变 |
| 用例 | 新增 `tests/wall_overlap.lua`（7 条）：**Red 5/2**（目标 126）→ **Green 7/0**（目标 130）；双向钉住"门没被拉长" |
| 回归 | ✅ **34 套全绿** |
| 交付 | ★ **`408-墙加长4-v263.gil`**（1,637,850 B / 内嵌 v263）|
