## 三、两个已知的坑

| 坑 | 现象 | 对策 |
|---|---|---|
| ★ Lua `io.open` 打不开该路径 | `err = No such file or directory`（★ 路径明明对 ✓） | ★ **用 PowerShell 同步** ✗ 不要在 Lua 里做 |
