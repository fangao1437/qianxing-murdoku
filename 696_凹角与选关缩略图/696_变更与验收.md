## 三、B · 选关卡片：棋盘缩略图 + 底部关卡名

选关卡片静态美术：白纸 202×286（`#FCFBF7`）+ 棕色 `inner` 174×224（`#5C371F`），
棕色区域下方露出约 15px 白色边缘。全部改动在**内嵌 Lua**（5 项可逆补丁），零静态文本改动：

| # | 改动 | 说明 |
|---|---|---|
| **B1** | `Levels.ui_list()` 增 `walls` / `doors` / `room_grid` | `room_grid` 由 `RoomMap.compute_rooms(rows, cols, RoomMap.build_walls(lv,…))` 现算，逐格房间号 |
| **B2** | `Controller:push_room_thumb` 重写 | 棕色 `inner` 比例区域（x+6.9% / y+16.4% / w86.1% / h78.3%，内缩 8px）画 `rows×cols` 格底色（按 `room_grid` 取 `ROOM_COLORS`）+ 墙（深墨 `#20262C` 细条）+ 门（橙红 `#DC5B29` 短条，占格线中段 44%）；**不画任何家具**；旧 6 个房间大色块全部 `visible=false` |
| **B3** | 卡片文本对调 | 底部白色边缘 `.info` → 关卡**短名**（去掉「案件 NNN · 」前缀，如「旋转档案」），`style="card.name"`；顶部 `.title` → 规格信息（6x6 / 嫌疑人数） |
| **B4** | `level_card_parts` 增 `short` | 短名提取 + 去尾空格 |
| **B5** | `Adapter:color_of_style` 增 `card.name` | 返回深棕 `0xFF4A2E1C`，保证关卡名在白纸上可读（原静态控件是白字） |

节点 id 形如 `select.card.N.cell.r.c` / `.wall.k` / `.door.k`，由 `layout_plan` 动态创建；
`apply_screen_hide` 在关卡内会按 `select.` 前缀整体收起，不影响棋盘页。
第7关实测每卡 **36 格 + 17 墙 + 5 门 + 6 个隐藏旧块 = 64 节点**，家具节点 **0**。
