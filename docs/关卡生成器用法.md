# 关卡骨架生成器（`tools/new_level.lua`）

> **它只做一件事**：你把「答案摆在哪 + 墙在哪 + 门在哪」画成一张纯文本图，
> 它立刻告诉你**这个空间结构成不成立**（R3/R4），成立就生成一份格式合法的关卡文件。
>
> **它不生成线索。** 线索是这个游戏的谜题本体，得你来设计（或让工具暴力搜，见 §6）。
>
> 规则依据：`docs/规则规格-偷窃版.md`；设计数学：`docs/关卡设计手册.md`。

---

## 一、为什么需要它

关卡设计里最容易翻车的**不是线索**，是**空间结构**：

> 受害者所在的区域叫 Rv。盗窃者必须待在**与 Rv 相邻、且无辜人数最多**的区域里，
> 否则玩家按规则推出来的答案和你的答案不一致（就是所谓 R3/R4 不自洽）。

人数分布要同时满足好几条不等式，靠脑子记很容易做出一关"看起来对、其实永远解不开"。
这个工具把那部分**算给你看**。

### 它会拦住的三类错误

| 报错 | 含义 | 怎么改 |
|---|---|---|
| 盗窃者不在相邻区域 | 盗窃者所在区和 Rv 之间没门（或根本没连通） | 加一扇门，或把盗窃者挪进相邻区 |
| 盗窃者所在区域不是相邻区域里无辜人数最多的 | 人数分布不满足 R3 | 调人数分布（手册第二节的不等式） |
| 相邻区域无辜人数并列 | `tie_policy = "forbid"` 下并列即非法 | 让某个相邻区多/少一个人，或改 `--tie=allow` |
| `k ≥ 2` 必须有同伙 | 受害者与别人同区 → 那个"别人"必须是同伙 | 补 `--accomplice=<id>`，或让受害者独处一区 |

## 二、输入图文件格式

纯文本，UTF-8，三块（后两块可选）：

```
# 注释以 # 开头（可出现在任何位置，含行内说明行）

.  .  D  .  .          ← 第 1 块：网格（必须最先出现）
.  B  .  .  .             每行一格，空格分隔
A  .  .  .  .             字母 = 该格站着谁；. = 空格
.  .  .  .  V             角色 id 可以多字符（如 V1、boss）
.  .  .  C  .

--- walls ---          ← 第 2 块：区域边界 / 墙
v 1 3                     v r c = (r,c) 与 (r,c+1) 之间有一道墙
h 2 1                     h r c = (r,c) 与 (r+1,c) 之间有一道墙

--- doors ---          ← 第 3 块：门径（决定"相邻"）
v 2 3                     同样两种写法；有门 = 两个区域算相邻
h 3 2
```

**语义提醒**：

- **墙**把网格切成区域（房间）；**门**只影响"哪两个区域算相邻"，不改变区域划分。
- 同一对格子可以既不是墙也不是门（那就是普通连通，**算同一个区域**）。
- 墙/门的位置必须是**真实存在的相邻格子对**，写越界会被拒。
- **区域是自动算出来的**（连通分量），不用你标区域号。

一份可直接跑的示例：`tools/examples/level_grid_example.txt`（内容 = 现有的 case_001）。

## 三、用法

```powershell
cd "D:\新建文件夹\miHoYo Launcher\qianxing-murdoku"
$lua = "$env:LOCALAPPDATA\Programs\Lua\bin\lua.exe"

# 先干跑，只看结构自洽不自洽（不写文件）
& $lua tools\new_level.lua tools\examples\level_grid_example.txt --thief=D --victim=V --dry
```

### 全部选项

| 选项 | 说明 |
|---|---|
| `--id=case_004` | 关卡 id（默认 `case_00N`，N 自动取下一个） |
| `--name=案件 004 · 标题` | 关卡名 |
| `--subtitle=...` | 副标题 |
| `--difficulty=easy\|normal\|hard` | 难度标记 |
| `--victim=V` | 受害者 id（默认：网格里**最后一个**字母） |
| `--thief=D` | **盗窃者 id（必填）**，或写 `--auto-thief` 让工具猜 |
| `--accomplice=C` | 同伙 id（不写 = 本案没有同伙） |
| `--announce=none\|one\|unknown` | 线索全真 / 有一句假话 / 不告诉玩家 |
| `--tie=forbid\|allow` | 相邻区域无辜人数并列是否允许（默认 `forbid`） |
| `--names=A=管家,B=医生,V=老宅主` | 角色显示名（不写就显示「角色A」） |
| `--out=lua/levels/case_004.lua` | 输出路径 |
| `--dry` | 只算结构、不写文件 |

**退出码**：结构自洽 → `0`；不自洽或参数有误 → `1`（可以直接接进 CI / 脚本）。

## 四、它打印什么

以 `case_001` 的正确设计为例：

```
网格 5×5，墙 9 段，门 3 处

===== 空间结构自检 =====
  区域数 3；受害者 V 在区域 #2（k=1）
  门相邻区域：#1(无辜 2)  #3(无辜 1)
  无辜人数最多的是：#1（各 2 人）

  ✅ R3/R4 自洽 —— 你的设定站得住
     盗窃者在 #1，正好是人数最多的相邻区域 ✔
     k=1 → 同伙可有可无（现在 没有）
```

算错的时候会明确告诉你错在哪、并给三种改法：

```
  门相邻区域：#1(无辜 3)  #3(无辜 0)
  无辜人数最多的是：#1（各 3 人）

  ❌ R3/R4 不自洽 —— 先改空间/答案/角色，再谈线索：
     - 盗窃者所在区域不是相邻区域里无辜人数最多的
```

> ⚠️ **字段语义容易看错**（这个工具的第一版就写错了，已修并在注释里标注）：
> `structure_report()` 返回的 `info.best` 是**人数**，`info.best_rooms` 才是**区域号列表**。

### 别忘了试错

结构对了不等于答案是唯一解。**一定要故意填一个错的盗窃者再跑一次**，
确认工具真的会拦住你（不然你可能是在"自检通过"的假象里设计）：

```powershell
# C 在区域 #3，但人数最多的是 #1 → 应该报 ❌ 并 exit 1
& $lua tools\new_level.lua tools\examples\level_grid_example.txt --thief=C --victim=V --dry
```

## 五、生成之后

```powershell
& $lua tools\new_level.lua tools\examples\level_grid_example.txt --thief=D --victim=V `
    --id=case_004 --name="案件 004 · 标题" --names=A=管家,B=医生,V=老宅主
```

产物是一份 `clues = {}` **空的**合法关卡文件，末尾会打印下一步。要点：

1. **填线索**（§6）。
2. **登记到 `lua/levels/init.lua` 的 `LIST`** —— 不登记就永远不会被加载：
   ```lua
   LIST = { "levels.demo_selftest", "levels.case_001", "levels.case_002",
            "levels.case_003", "levels.case_004" }
   ```
   > ⚠️ **登记顺序 = 游戏里的关卡顺序**，`结算面板「下一关」`按这个顺序走。
3. **`& $lua tools\validate_levels.lua 3`** —— **必须看到「唯一解: OK」**。
   这一步会同时查格式 / 结构 R3R4 / 假话 / 唯一解。

## 六、线索怎么写

### 6.1 上限（`tests/ui_math.lua` 会自动查）

| 限制 | 值 | 原因 |
|---|---|---|
| 线索条数 | **≤ 18** | 界面只生成 18 行线索控件，超出的玩家看不到 |
| 棋盘 N | **≤ 7** | 8×8 摆位总数 16 亿，剪枝也救不回来 |

### 6.2 可用的线索原子

关系型线索（推荐，表达能力最强）：

```
col_offset(who, other, d)      who 的列 - other 的列 = d
row_offset(who, other, d)      who 的行 - other 的行 = d
distance(a, b, d)              曼哈顿距离
compass(who, other, 'ne'|'nw'|'se'|'sw')
abs_col_from(who, n, from='right'|'middle')
abs_row_from(who, n, from='bottom'|'middle')
alone_with(a, b)               两者同区且区内没别人
between(who, a, b)
is_role(who, role) / not_role(who, role)
```

**❌ 不要用 `left_of` / `right_of` / `above` / `below`** ——
它们要求两人同行或同列，而本作开了 `one_per_row` + `one_per_col`，
所以这四条**恒为假**。要表达方位请用 `col_offset` / `row_offset` / `compass`。

### 6.3 假话

- 整关**至多一句**假话（个人线索 + 全局线索合计）。
- `--announce=one` → 告诉玩家"有一句假话"；`unknown` → 不告诉；`none` → 全真。
- 写完线索再填 `meta.false_clue = <序号>`。
- **判题不揭晓哪条不成立**（规则硬要求）。

### 6.4 反镜像（很容易中招）

当线索里用了角色别名（`@thief` / `@accomplice`）把位置钉住时，
**别人的位置可能整体镜面对称也满足全部线索** → 唯一解校验会挂。
补一条**实名身份线索**即可，例如：

```lua
{ type = "not_role", who = "D", role = "accomplice" }
```

`case_002` 里就留着这么一条，专门防镜像。

### 6.5 想不出来就让工具搜

```powershell
& $lua tools\find_clues.lua lua/levels/case_004.lua
```

**暴力搜索，可能几十分钟**，只当兜底用。正式关卡更推荐手写 + 用
`validate_levels.lua` 反复迭代。

## 七、完整流程（一关从零到能玩）

```powershell
cd "D:\新建文件夹\miHoYo Launcher\qianxing-murdoku"
$lua = "$env:LOCALAPPDATA\Programs\Lua\bin\lua.exe"

# ① 画图 → 干跑结构
& $lua tools\new_level.lua tools\examples\level_grid_example.txt --thief=D --victim=V --dry

# ② 故意填错一个，确认自检真的会拦（别在假绿里设计）
& $lua tools\new_level.lua tools\examples\level_grid_example.txt --thief=C --victim=V --dry

# ③ 结构过了 → 生成文件
& $lua tools\new_level.lua tools\examples\level_grid_example.txt --thief=D --victim=V `
    --id=case_004 --name="案件 004 · 标题"

# ④ 手写线索（改 lua\levels\case_004.lua 的 clues 表）
#    每写几条就回来跑一次 ⑤

# ⑤ 唯一解校验（最关键的一步）
& $lua tools\validate_levels.lua 3

# ⑥ 看玩家实际会读到什么线索文案（顺带确认哪条是假话）
& $lua tools\dump_level.lua case_004 tools\sim\out\lv.json

# ⑦ 登记进 LIST 后，模拟器里真打一局到破案
node tools\sim\win_path.mjs --level=case_004

# ⑧ 全量自检 + 打包 + 同步到游戏
powershell -ExecutionPolicy Bypass -File tools\check_all.ps1
```

## 八、常见报错对照

| 现象 | 原因 | 解决 |
|---|---|---|
| `用法：lua tools/new_level.lua <图文件> …` | 没给图文件 | 第一个位置参数就是图文件路径 |
| `读不了图文件：…` | 路径写错 | 用相对工程根目录的路径 |
| 网格每行格数不一致 / 出现看不懂的字符 | 格式问题 | 每行空格分隔、只允许 `.` 和角色 id |
| `墙/门 越界` | `r`/`c` 超出网格 | 检查 `h r c` / `v r c` 的取值 |
| 区域数 = 1 | 没画墙 → 整张图一个区域 | 补 `--- walls ---` |
| 门相邻区域：（一个都没有） | 没画门 → 没有相邻区域 | 补 `--- doors ---` |
| `k ≥ 2` 但没有同伙 | 受害者与别人同区 | 补 `--accomplice=<id>` |
| `写不了 <路径>` | 输出目录不存在 | 先建目录，或用 `--out=` 指到已存在的位置 |
| 生成成功但游戏里看不到这一关 | **忘了登记 `LIST`** | 见 §5 第 2 条 |
| 校验报"多解" | 线索不够强 / 有镜面对称 | 加线索，或加反镜像的实名线索（§6.4） |
