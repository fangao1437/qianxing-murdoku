## 三、P1 · 棋盘缩略图正方形居中

`Controller:push_room_thumb` 只改网格计算（1 项可逆 Lua 补丁）：

```lua
-- 696：铺满（被拉伸成 223×287）
local gx, gy = area.x + pad, area.y + pad
local gw, gh = area.w - pad * 2, area.h - pad * 2
local cw, ch = gw / cols, gh / rows

-- 697：取短边做正方形，在棕色区域内水平 / 垂直居中
local gw, gh = area.w - pad * 2, area.h - pad * 2
local side = math.min(gw, gh)
local gx = area.x + (area.w - side) * 0.5
local gy = area.y + (area.h - side) * 0.5
local cw, ch = side / cols, side / rows
```

- 所有关卡 `rows == cols`，所以每格也是正方形；整幅棋盘 `223.2×223.2`，
  四周留白，不再把棕色区域上下拉长。
- 墙线 / 门线沿用同一组 `gx/gy/cw/ch`，随网格一起居中；房间底色、门墙色、
  零家具、底部白边的关卡短名与深棕字色全部不变。
