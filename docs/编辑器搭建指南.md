## 步骤 0：界面控件相关入口在哪（最容易迷路的一步）

**总入口：左上角系统菜单 →【界面控件组管理】**

注意：这是在**千星沙箱**（PC 端编辑器）里，**不是**游戏内按 ESC 的「局内编辑器」。

打开后界面分五块：菜单栏、库窗口、详情窗口、预览窗口、编辑按键处、参数配置窗口。
**左栏选中什么，右栏的"添加"按钮就叫什么** —— 找不到"添加界面控件"通常就是看错了栏：

| 左栏选中的是 | 右栏叫 | 添加按钮 | 用来加什么 |
|---|---|---|---|
| **界面布局** | 界面布局详情 | 【**添加界面控件**】 | 往这张布局上加**单个控件**（文本框/图片/预设按钮…）和**客户端控件容器** |
| **界面控件组库**（自定义模板） | 界面控件组详情 | 【**添加界面控件模板**】 | 以预制控件资产为基础**建一个控件组模板**（客户端控件容器也能从这里加） |

### 要摆棋盘的三级路径

```
1) 系统菜单 → 界面控件组管理 → 左栏【界面布局】→ 右栏【添加界面控件】→ 选【客户端控件容器】
2) 选中刚加的容器 → 画布设置 → 【前往编辑】          ← 打开容器详情
3) 容器详情里 →【添加控件】                          ← 按钮叫"添加控件"，不是"添加界面控件"
   在这里加 cell.1.1 … cell.5.5、tray.A、hud.title 等**客户端控件**
```

### 加完必须做的两件事（否则等于没加）

1. **容器与里面的控件要处于「激活且可见」** —— 官方规则：容器隐藏或销毁时，
   里面的客户端控件**全部销毁**、脚本停止运行；
2. **界面布局要被「职业」引用才生效** —— 官方原文："玩家在关卡游玩时使用的界面布局，
   需要通过**职业**进行配置"。打开「职业」编辑界面 → **选择布局** → 引用你的界面布局
   （默认布局通常已配好，自定义布局要自己挂）。

   **两条到达「职业」的路（官方都说可以）**：

   - 路 A：`战斗预设` → `职业` → **选择布局** → 引用你的界面布局
   - 路 B：`界面控件组管理` → 左栏【界面布局】选中你那张 → 右侧【参数配置】窗口 →
     **【打开玩家编辑】** → 跳到「职业」配置界面 → 设置它应用的**默认界面布局**
     （官方原文："界面布局的参数配置窗口也可以直接跳转到该编辑界面"；
     "当前界面布局的默认应用配置，作为某位玩家运行关卡后的默认界面"）

   > ⚠️ **2026/9/24 实测踩坑（卡了很久）**：布局没被职业引用时，试玩进关卡后
   > **画面上一个客户端控件都不会出现**（只有原神默认 HUD），于是挂在控件上的客户端脚本
   > **永远不执行、日志一行都没有**。看到的是"日志功能坏了"的假象，其实是控件压根没被创建。
   > **排查顺序应该是：先看画面里控件出没出来 → 再看日志。**
   >
   > 另外官方明确："**界面控件组库中制作的类似元件库中制作的元件，实际游玩时并不显示，
   > 需要添加至界面布局中才会显示**"。所以容器必须走【界面布局】→【添加界面控件】，
   > 而不是【界面控件组库】→【添加界面控件模板】。
   >
   > 官方还定义："界面布局依赖玩家运行，运行时**每个玩家有且仅有一个生效的界面布局**"。

### 控件加进去了、但画面上看不见？（先读这个）

**2026/9/24 实测结论：绝大多数时候不是"没生效"，而是"好几层透明叠在一起"。**
从外到里逐层看：

| 层 | 控件 | 本身画东西吗 | 要做什么才看得见 |
|---|---|---|---|
| 1 | **客户端控件容器** | ❌ 透明画布 | 它的唯一作用是"让里面的客户端控件能在运行时显示"，**它自己永远不画任何东西** |
| 2 | **容器节点**（如 `board`） | ❌ 透明 | 官方定义："容器节点主要作为其他客户端控件的**挂点**" |
| 3 | **预设按钮**（如 `cell.1.1`） | ❌ 默认透明 | 必须给它配「按钮状态节点」的外显样式（见下） |
| 3′ | **文本框** | ⚠️ 看内容/颜色/大小 | 见下面的"三件事" |
| 3″ | **图片** | ✅ 选了图就可见 | **验证链路时用它最省事** |

**给「预设按钮」配外观（官方《预设按钮》三步）**：

1. 在按钮**下面**加一个子控件（**图片**最好使，文本框也行）；
2. 选中按钮 → 右栏【基础】→ **按钮设置 → 按钮状态节点**；
3. 把那个子控件**拖拽到【默认】状态节点上**；或者**单击【默认】状态节点**，
   在弹出的子控件列表里勾选它。

状态共四种：`默认 / 悬停 / 按下 / 不可用`；
配好后**点状态节点的播放键**就能在编辑器里直接预览，不用试玩。

**30 秒自检**：在容器里（或 `board` 下）加一个**图片**控件 → 选一张图 → 摆到屏幕中间。
**看到图片 = 容器链路完全正常**；看不到，才需要回去查布局/职业/可见开关。

**文本框看不见的三件事**（按概率排序）：

1. **对比度**：文本颜色默认纯白 `#FFFFFF`、背景 `0%` 全透明、描边极淡。
   试玩场景顶部通常是亮天空 —— **白字打在亮天空上基本等于隐形**。
   调成大红/纯黑，或把背景拉到 100% 黑底。
2. **大小**：字号 256 的"111"展开有 400+ 像素宽。若 `大小 W×H` 装不下，
   **实机会把文字裁掉**（而编辑器预览窗口常常不裁剪 → 造成"预览有、实机没有"）。
   字号大就顺手把 `大小` 设成 W≥1200、H≥300。
3. **内容为空**：新加的文本框内容是空的，自然什么都不画。

### 还找不到时的排查顺序

1. 是否在**局内编辑器**里找？客户端控件与脚本只在**千星沙箱**侧配置；
2. 左栏有没有**选中一张界面布局**？（界面布局库不能为空，最少一个；默认应有「默认布局」）
3. 版本是否 **7.1+**（客户端控件/脚本是 7.1 新增能力）；
4. 创作权限 / 先行体验是否开通；
5. 想加的是**卡牌选择器**？官方明确：它只能加到「界面控件组库」，**不支持加到界面布局上**。

### 选中不同控件时，右栏长什么样（用来判断自己在哪一层）

| 你选中的是 | 右栏能看到 | 该点哪里 |
|---|---|---|
| **客户端控件容器**（服务器控件，位于**界面布局**里） | 界面配置 / 参数配置，里面有**画布设置**、索引、初始可见、变换、锚点、层级 | **画布设置 → 前往编辑**，进入容器详情 |
| **容器节点 / 文本框 / 预设按钮**（**客户端控件**，位于容器详情里） | 只有 **基础 / 脚本** 等 | 说明**你已经在容器画布里了**：用容器详情的【**添加控件**】继续加；「画布设置」在这一层不存在 |

> ⚠️ **「客户端控件容器」≠「容器节点」**：
> 前者是**服务器控件**，只能加在**界面布局**上，是"画布的宿主"，有「画布设置」；
> 后者是**客户端控件**，只能加在容器画布里，作用是"其它控件的挂点"，没有「画布设置」。
> 如果在界面布局里选中的控件右栏只有「基础 / 脚本」，多半是加成了「容器节点」，
> 回到界面布局 →【添加界面控件】→ 重新选 **客户端控件容器**。

## 步骤 2：搭界面控件（最重要的一步）

框架的 `lua/ui_controller.lua` 会按 **控件 id** 去找控件，所以**命名必须完全一致**。

### 2.1 顶层容器

建立一个**客户端控件容器**（这是脚本的宿主，见步骤 4），内部按下面的分区放子容器：

| 容器 id | 作用 | 设计坐标（1920×1080） |
|---|---|---|
| `root` | 全屏根 | 0,0,1920,1080 |
| `topbar` | 顶部工具条 | 0,0,1920,104 |
| `left` | 左侧面板 | 24,128,392,880 |
| `tray` | 头像卡区（在 left 内） | 40,148,360,300 |
| `clues` | 线索卡区（在 left 内） | 40,470,360,430 |
| `legend` | 操作图例（在 left 内） | 40,916,360,76 |
| `board` | 中央棋盘（含 R/C 坐标尺） | 480,176,880,880 |
| `actions` | 底部大按钮条 | 480,940,880,120 |
| `right` | 右侧信息栏 | 1420,128,460,880 |

> 坐标在 `ui_controller.lua` 的 `M.LAYOUT` 里，改那里就能整体挪版；
> 想省事的话：编辑器里按上表摆好位置，脚本里把 `set_rect` 钩子留空即可（位置由编辑器决定）。

### 2.2 棋盘格子：`cell.<行>.<列>`

在 `board` 里放 `rows × cols` 个**自定义按钮控件**（本框架默认 5×5 = 25 个），命名规则：

```
cell.1.1  cell.1.2  ... cell.1.5
cell.2.1  ...
...
cell.5.5
```

每个格子需要：

- **默认态外观**：地板/木纹底图
- **悬停态**：murdoku 的蓝色描边辉光（4px 描边，`rgb(99,180,255)`）
- **按下态**：缩小到 0.98
- **四边墙**：建议做成独立的四张小图（上/下/左/右墙），由脚本按 `walls` 显隐；
  或者把墙直接画进底图（那就不需要脚本控制墙）
- **家具/物体**：把图片控件叠在格子上，命名 `cell.<r>.<c>.obj`（脚本会把 `object` 属性写给它）

格子里要能显示：棋子头像（图片控件 `cell.<r>.<c>.face`）、棋子名（文本框）、草稿小字（文本框）。

### 2.3 头像托盘：`tray.<棋子id>`

每个嫌疑人一个自定义按钮，命名 `tray.A`、`tray.B`…（id 必须和关卡数据里的 `suspects[i].id` 一致）。
里面放头像图片 + 名字文本。三种视觉状态要和脚本对齐：

- `portrait`：未放置
- `portrait.selected`：已选中（murdoku 的选中脉冲：缩放 1.12 → 1.03 → 1）
- `portrait.placed`：已放上棋盘（灰掉 + 下沉 2px，像被"盖章"压下去）

### 2.4 线索面板：`clue.<序号>`

放 N 条横排文本框（默认最多显示 9 条，见 `M.LAYOUT.clue_max_visible`），命名 `clue.1`…`clue.9`，
再加一个 `clues.more` 用来提示"还有几条"。每条线索三种样式：

- `clue`：未满足（普通色）
- `clue.ok`：已满足（打勾、变绿、或加删改线）
- 失败时由脚本播放 `shake`

### 2.5 工具与操作按钮（id 固定，脚本按 id 绑事件）

顶部工具条：

| 控件 id | 文案 | 说明 |
|---|---|---|
| `tool.place` | 放置 | 三个工具互斥，选中态 `tab.active` |
| `tool.x` | X 标记 | 点格子 = 划掉这格（不可能） |
| `tool.eraser` | 橡皮擦 | 单击清格，**双击清空全盘** |
| `action.undo` / `action.redo` | 撤销 / 重做 | 无步数时禁用 |
| `action.submit` | 提交 | 未摆满时禁用；**偷窃版下它只校验硬约束，不揭晓任何线索层面的对错**（规格 5.3），通过后进入两段式指认 |
| `action.hint` | 提示 | |
| `action.reveal` | 揭示 | 直接摆出答案（教学/放弃用） |
| `action.howto` | 玩法 | 打开规则弹窗 |
| `action.share` | 分享 | 弹出棋局分享码 |
| `action.restart` | 重开 | |
| `action.back` | 返回列表 | |
| `hud.title` / `hud.subtitle` / `hud.timer` / `hud.moves` | — | 文本控件 |

底部长按/触屏友好按钮条：`action.q.place`、`action.q.note`、`action.q.x`、`action.q.eraser`、`action.q.accuse`
（最后一个等价于"提交并进入指认"）。

### 2.6 坐标尺

棋盘外圈要有 `ruler.r.<行>`（R1…Rn）与 `ruler.c.<列>`（C1…Cn）两组文本控件，
脚本会按棋盘尺寸自动生成/显示（murdoku 默认只在提示时显示，本框架默认常显）。

### 2.7 右侧信息栏

| 控件 id | 内容 |
|---|---|
| `hud.progress` | 已放置 n / 总数 |
| `hud.score` | 位置正确 n / 总数 |
| `hud.violations` | 当前硬性冲突（同行/同列两人等） |
| `hud.share` | 分享码 |
| `hud.toast` | 提示消息（提交结果、指认结果） |

### 2.8 结案弹窗与开屏教程

用**弹窗控件**做一个通用弹窗容器，脚本会在里面填不同内容（id 由脚本创建）：

- `modal` + `modal.title` / `modal.body` / `modal.stats` / `modal.suspect.<角色id>` / `modal.again` / `modal.share` / `modal.next` / `modal.cancel`
- **偷窃版两段式指认**会用到 `modal.no_accomplice`（"他独自作案（没有同伙）"按钮）
- 开屏教程：`intro` + `intro.dots` / `intro.title` / `intro.body` / `intro.next` / `intro.skip`（5 页）
- 分享码窗口同样复用 `modal`

> 弹窗由脚本按状态显隐，编辑器里不需要做任何流程。

### 2.9 偷窃版额外要搭的东西

| 需求 | 控件 | 说明 |
|---|---|---|
| **门径**的表现 | 格边的门贴图（上下左右各一张） | 脚本会把 `doors = {up,down,left,right}` 写进格子属性；注意**墙与门可以同时存在**（墙是区域边界，门是跨区域通道） |
| 告知"有没有假话" | `hud.subtitle` 文本 | `meta.announce="one"` → 显示"※ 线索中有一句假话"；`"none"` → "※ 线索全部为真"；`"unknown"` → **什么都不显示**，玩家自己推断 |
| 区域推断面板 | `hud.violations` 文本 | 脚本会把「受害者区域 #N、区内 k 人、门相邻区域及各自无辜人数、盗窃者应在哪个区域」写进这个控件。这些量玩家自己也能数出来，属于**合法推理助手**（真正藏起来的是线索对错） |

## 步骤 3：素材

### 4.1 把映射和本地 `.lua` 关联起来（「暂无引用」怎么解决）

官方《客户端脚本》文档原文：

> 通过**编辑文件路径**将客户端脚本与本地文件关联，**保存并试玩**时就能使对应文件的 lua 脚本正常运行

官方三步顺序：**(1) 新建脚本映射 → (2) 编辑脚本映射路径 → (3) 在打开的文件夹中选择要关联的本地文件**。
关联成功后，「文件路径」列会显示**文件名**，不再是「暂无引用」。

另一条路是「**新建客户端脚本**」：编辑器会在脚本根目录里**顺手建一个同名 `.lua`**，映射与文件同名、自动关联。
⚠️ 如果你在那个保存框里**取消了**，映射会留下来但**永远挂着「暂无引用」**——这正是常见现象。

**脚本根目录**（随关卡存档 id 变化）—— ⚠️ **在 `LocalLow` 下，不是 `Local`**：

```
C:\Users\<你>\AppData\LocalLow\miHoYo\原神\BeyondLocal\<uid>\Beyond_Local_Save_Level\<关卡存档id>\external_lua_file\

本机 = C:\Users\18182\AppData\LocalLow\miHoYo\原神\BeyondLocal\153793556\Beyond_Local_Save_Level\1073741826\external_lua_file\
```

> **大坑（2026/9/24 实测，卡了两个小时）**：原神真正的本地数据在 **`AppData\LocalLow`**，不是 `AppData\Local`。
> `external_lua_file` 这个目录是**关卡第一次打开时游戏自己建的**（本机 LocalLow 那棵建于 1:22:09，
> 同级的 `1073741826.gil` 就是关卡存档本身）。
> 如果把 `.lua` 复制进 `AppData\Local\...` 下**自己新建**的 `BeyondLocal\...\external_lua_file\`，
> 那么编辑器弹出的「选择.lua脚本」框打开的是 **LocalLow 那个空目录**，显示
> **「没有与搜索条件匹配的项。」**——看上去像"文件不存在/关联不生效"，其实是**放错了根**。
>
> **一眼判断哪棵树是对的**：同级目录里应该有 `<关卡id>.gil` 这样的**关卡存档文件**；
> 只有 `external_lua_file` 而没有任何 `.gil` 的那棵，就是放错的那棵。
>
> `tools\install_script_to_sandbox.ps1` 已修正：**LocalLow 与 Local 两个根都同步**（LocalLow 优先）。

**症状一：文件选择框里一个文件都没有，写着「没有与搜索条件匹配的项。」**
→ 十有八九就是上面的 `Local` / `LocalLow` 搞混了。处理：

1. 在工程根目录跑
   `powershell -ExecutionPolicy Bypass -File tools\install_script_to_sandbox.ps1`
   （会打印 `[LocalLow] synced -> ...`，并校验字节数）；
2. 回到**还开着的**选择框，点地址栏右侧的**刷新（↻ 圆形箭头）**；
3. `client_script.lua` 就出现了，**双击**它。

**症状二：文件能看见、也点了「打开(O)」，但「文件路径」列仍是「暂无引用」** —— 按顺序排查：

1. **入口位置对不对**：点「文件路径」列里那支 ✏️ / 直接点「**暂无引用**」这几个字，
   或**右键那条脚本记录 →【修改引用路径】**。
   ❌ 不要右键左侧的 `murdoku` 文件夹节点（那是文件夹级菜单）。
2. **选文件的手势**：在弹出的文件夹窗口里**双击 `client_script.lua`**。
   只单击选中再点【打开(O)】也可以，但双击最不容易漏（漏了就是"看起来点了、其实没提交"）。
3. **列表是快照**：本窗口的列表是**打开时拉的一次**。列没变就**关掉「客户端脚本资源管理器」再打开**，
   或干脆**退出关卡重新进入**再看一眼。
4. **还不行就别折腾这条记录了**，改用编辑器自己的流程重建：
   - 删除现在那条「新建客户端脚本」（挂着「暂无引用」的）；
   - **右键 `客户端脚本映射\murdoku` →【新建客户端脚本】** → 在打开的文件夹里把文件名写成 `client_script` → **保存**；
     编辑器会同时建出文件和映射，两者同名 → **必然关联成功**；
   - 文件名只能 **ASCII**（不要中文）；
   - 建完后跑 `tools\install_script_to_sandbox.ps1`，用打包产物**覆盖**它新建的那个同名文件。
5. **关联成功后一定要「保存关卡」再试玩**，否则打包上传的还是旧状态。
6. 列表里那条记录的 **ID（本机 `1073741825`）就是 `scriptMappingId`**，
   挂控件、写「脚本变量」时都要对到它。

## 步骤 5：节点图接线（Lua 覆盖不到的部分）

### 5.0 两条从官方文档抄来的硬事实（会影响你怎么搭）

**① 局内存档存不了嵌套结构。** 官方《局内存档》（`mhzcw29qjjma`）写明：

- 结构体成员只支持 **GUID / 整数 / 布尔值 / 浮点数 / 字符串 / 阵营 / 三维向量 / 元件ID / 配置ID**，
  以及它们的**列表**；
- **不支持：结构体、字典、实体、实体列表**；
- 列表类型**必须预设最大长度**，存档时超长会被**截断**；
- 关卡总数据量超限会导致**无法试玩或发布**；
- 数据结构**只能增量升级**（新增存档结构体 / 新增成员），删改会导致老玩家**读档失败并重置**。

→ 所以本工程的存档设计是：**把整盘状态压成一个分享码字符串**再存
（`Murdoku.save_now()` 存 `state_code` 字符串 + `moves/elapsed/solved` 三个整数）。
不要试图把 `serialize()` 那种嵌套表塞进局内存档。

**② 交互事件默认是发给节点图的。** 官方《界面控件》（`mhnapxrumtzy`）写明：
交互按钮 / 道具展示控件在"点击和外接设备输入"后**向节点图发送「界面控件组触发时」事件**；
文本框里填的**自定义变量会实时刷新**；控件保存为界面控件模板后才有**索引**供节点图引用。

→ 在 7.1 的脚本能力把点击直接交给 Lua 之前，点击链路是「控件 → 节点图」。
**长按的替代方案：双击。** 官方客户端脚本**只有 `CursorDown/Up/Click/Drag`，没有长按事件**，
所以在 7.1 里做"长按放置"要么自己按 dt 计阈值、要么换成双击。本工程选**双击**：
适配层只把 `CursorClick` 转成 `{action="click"}`，双击判定由 `ui_controller` 用
`OnUpdate(dt)` 累加的时钟完成（窗口 0.35s）。**单击的作用是铅笔笔记，会延迟 0.35s 生效**
—— 这是双击方案的固有代价，但换来"怎么才算放下"的确定性。

7.1 的客户端脚本环境还有两条会咬人的限制：**没有 `os`/`io` 库**（计时只能累加 dt），
以及 **`debug.*` 除 `traceback` 外都不可用**。

另外两条搭建时的坑：

- **渲染模式要选「层级渲染(新)」**（月之六版本新增，之后新建存档默认用它）。
  旧的「时序渲染」下层级参数不生效，后加的控件会串层。
- **锚点设置**：分辨率变化时按锚点继承相对位置，本工程的坐标是 1920×1080 设计值，
  记得给每个控件配锚点，否则换分辨率会整体错位。

## 附：框架概念 ↔ 编辑器控件的对照表

| 框架里的东西 | 编辑器里对应的控件 | 谁驱动 |
|---|---|---|
| 棋盘格 | `cell.<r>.<c>` 自定义按钮 | Lua（属性 + 事件） |
| 格子里的棋子头像 | `cell.<r>.<c>.face` 图片控件 | Lua |
| 墙 | 格子上的四张墙贴图（或画进底图） | Lua（按 `walls` 显隐）/ 编辑器 |
| 家具物体 | `cell.<r>.<c>.obj` 图片控件 | Lua（按 `objects` 写图） |
| 头像托盘 | `tray.<id>` 自定义按钮 | Lua |
| 线索列表 | `clue.<n>` 文本框 | Lua |
| 计时/步数 | `hud.timer` / `hud.moves` 文本框 | Lua |
| 操作按钮 | `action.*` 自定义按钮 | Lua |
| 结案弹窗 | `modal` 弹窗控件 | Lua |
| 落子/破案音效 | 音效播放器 | **节点图**（收信号） |
| 结算/排行/成就 | 外围系统 | **节点图** |
| 存档 | 局内存档 | **节点图 + Lua 序列化** |
