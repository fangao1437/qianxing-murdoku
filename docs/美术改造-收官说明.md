## 三、⑦ 输入隔离：**你按一个键就知道结果**

启动日志会告诉你方法：

```
[murdoku] 2D/3D 输入隔离：主页/选关容器已屏蔽穿透 2 个
[murdoku]   验收：在关卡里按任一键盘快捷键 —— 出现「✅ 键盘事件仍能收到」
            即说明隔离没有副作用；若没有，去掉 main.lua 里的 seal_containers 即可（一行）。
```

**⇒ 按一个快捷键（如 Q/E），看有没有这一行**：

```
[murdoku] ✅ 键盘事件仍能收到（第一个键：…）
```

| 结果 | 含义 | 怎么办 |
|---|---|---|
| **有** ✅ | 隔离**没有**伤到脚本自己的键盘监听 | 什么都不用做，⑦ 完成 |
| **没有** ❌ | 屏蔽把键盘一起挡住了 | 删掉 `main.lua` 里 `seal_containers({ "home", "select" })` 那一行 |

**⇒ 这一行不依赖 `debug_key`** —— 它是验收结论，不是调试信息。
