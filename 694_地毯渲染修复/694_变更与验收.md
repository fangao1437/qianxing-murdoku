## 二、根因（实测确认，不是推测）

之前 692/693 我判断成「逐格绘制被关掉」，方向错了。逐格路径**从来就没在真机生效过**：

| 版本 | `_spawn_furn_tpl` 的 rug 分支 | 逐格 `furn` 手搭层 | 真机结果 |
|---|---|---|---|
| 685~688 / 689 / 690 | `return self:_spawn_whole_rug(...)` 整块模板实例化 | 存在 | **有地毯**（16:51 真机截图：第6关 (2,6)(5,6) 米黄带框方块） |
| 691 / 692 / 693 | 隐藏所有 `rug.*` 实例 + `return false` | 存在但被跳过 | **全空白** |

逐格 `rug_cell_els` 走 `furn` 属性，而 `furn` 处理器第一行就是：

```lua
elseif key == "furn" then
    if self._furn_tpl_ok then return true end   -- 真机 things prefab 可用 ⇒ 恒真，直接跳过
```

真机上桌椅、书架、植物、雕塑全靠 `things` 模板显示 ⇒ `_furn_tpl_ok = true` ⇒ 逐格永远不画。
691 又把整块模板关掉，**两条绘制路径同时断开**，所以 691/692/693 全部没有地毯。
693 只改了逐格算法（按边开放），没有恢复模板，故用户看到「仍然没渲染」。

**行为级实证**（`验证694行为.mjs` 直接 mock 调 `_spawn_furn_tpl`）：

```
693: furn.rug=true:false; furn.rug.2=true:false; furn.rug.3=true:false;
     furn.rug.4=true:false; furn.rug.5=true:false        ← 五个变体全断
694: furn.rug=true:true;  furn.rug.2=true:true;  furn.rug.3=true:true;
     furn.rug.4=true:true;  furn.rug.5=true:true          ← 五个变体全通
```

## 三、修改清单

### P1 恢复整块地毯模板实例化

`_spawn_furn_tpl` 的 rug 分支由「隐藏实例 + `return false`」改回 `return self:_spawn_whole_rug(...)`，并把 692 新建的 `rug_4`/`rug_5` 一并纳入。
走的是**与桌椅/书架/植物/雕塑完全相同**的一条素材引用路线：

```
F.layout（carpet pieces + L3a/L3b variant）
  → TPL_KEY.carpet → build_layout 的 furn_tpl / span / offset
  → _spawn_furn_tpl → _spawn_whole_rug → board.rugs
  → InstantiateClientUIControl(prefab, parent)
```

| 变体 | 模板 | 画布 | 用途 |
|---|---|---|---|
| 单格 | `furn.rug` | 108×108 | 单格地毯 |
| h2 | `furn.rug.2` | 216×108 | 横双格 |
| v2 | `furn.rug.3` | 108×216 | 竖双格 |
| L3a | `furn.rug.4` | 216×216，缺右下 | 第3关 (3,2)(3,3)(4,2) |
| L3b | `furn.rug.5` | 216×216，缺左下 | 第7关 (2,3)(2,4)(3,4) |

三格 L 形沿用 692 新建的**独立素材**（源/母本/引用三件套 + 216×216 content + 9 层「按边开放」），边框只沿外围、内部无格线；**没有复用或拉伸任何双格模板**。

### P2 关闭逐格 `rug_cell_els`

`F.layout` 不再给地毯格写 `els`。一举两得：
- 杜绝 691 文档记录过的「整块模板 + 逐格手搭层双绘 / 双层边框 / 压墙线」；
- 彻底消除「三张单格地毯拼接」的观感（用户上一轮明确否决）。
地毯现在**只有整块模板一条路径**。

### M1 第3关删右上角装饰植物

`case_003.objects.植物`：`(1,1) + (1,6)` → **只剩 `(1,1)`**。
- `(1,1)` 是功能株，线索「A 在植物旁边」「B 在植物旁边」依赖它，保留。
- `(1,6)` 是 693 新加的纯装饰株，删除。
- V 房间其余按上一轮要求保留：**1 书架 (1,5) + 1 雕塑 (2,6)**。
- 家具格总数 12 → 11；卡序 `[4,2,3,6,5,1]`、人名、卡面、答案、墙门全部不变 ⇒ **静态文本零改动**。
- `(1,6)` 的四邻是书架 (1,5)、雕塑 (2,6) 与两个越界格，均不可站 ⇒ 浅蓝提示格不变，仍为 `1:2 / 2:1`。
