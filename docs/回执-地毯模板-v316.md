## §4 ★ 需要用户做一次（约 1 分钟）
**目的**：我们上一轮发现"手写模板会被编辑器在保存时整段删除"（520.1 是编辑器重存档，205 条手写模板记录被删）。
所以这一版要验证：**编辑器认的模板（用户自己建的空模板）里，我们手写填进去的"层"能不能被编辑器保存保留**。

1. 用千星编辑器打开 **`525-一二关美术-v316.gil`**；
2. **保存**；
3. **导出**存档（记作 X）；
4. 把 X 放到工作区/发我 —— integrator 会 diff `525 → X`：
   - **8 个模板的层还在**（9/10/10/10/10/10/12/3）⇒ **V1 成立** ⇒ 这套"模板 + 运行时实例化"可以直接上真机；
   - **层被删** ⇒ 编辑器不接受手写层 ⇒ 转方案 A 变体 2：用户按 integrator 给的最小步骤手动建模板（我们会把每件压到最少层数，减少手工量）。
