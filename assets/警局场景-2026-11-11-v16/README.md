## 一、阴影为什么是「平板」，以及设计图到底是什么

把设计图 1920×1080 等比缩到 1600×900 后，在阴影区（档案袋右缘 ~ x1263）
逐点与「v15 官方背景（底色 + 52 条右侧渐变 + 单层 106060 渐晕，不含阴影）」相除：

| 采样点 | 设计图 | v15 背景 | 比值 R/G/B |
|---|---|---|---|
| (1050,280) | (149,58,27) | (181,73,32) | 0.823 / 0.795 / 0.844 |
| (1150,280) | (143,56,26) | (175,71,31) | 0.817 / 0.789 / 0.839 |
| (1240,300) | (133,54,24) | (163,66,28) | 0.816 / 0.818 / 0.857 |
| (1050,450) | (151,57,29) | (182,74,32) | 0.830 / 0.770 / 0.906 |
| (1100,700) | (150,57,23) | (177,71,31) | 0.847 / 0.803 / 0.742 |

三通道比值一致 ≈ **0.82** ⇒ 设计图的阴影根本不是一块纯色 `#973813`，
而是**背景整体压暗 18%**。因此它天然带右侧渐暗与圆形渐晕的连续过渡。
v15 用不透明纯色矩形把渐晕盖掉，才变成平板、并在 y<150 与右侧形成硬边。

**v16 做法（全部原生基本图形，且半透明形状零重叠）**

1. 单个整条 `100001` 矩形 `x[900,1223] / y[170,763]`，染黑 `opacity=0.18`。
   左斜边由**后画的不透明档案袋遮挡**自然形成（档案袋右缘 `x=924+0.2755y`
   在 y≤695 始终在 x=900 右侧），不需要旋转矩形与补缝三角；
2. `x[1223,1283]` 20 条渐隐带，与主矩形不重叠，alpha 由 0.18 线性收到 0；
   带高同样限制在 `y[170,763]`，避免 v15 那种「整幅高渐隐带」在上方无阴影区
   造出 `x=1222` 的竖直硬边；
3. 上边界实测：`y≤140` 设计图是**无阴影**的原背景（比值≈1.02），
   `y≥260` 才是 ×0.82；取 `y=170` 正好落在上方胶带带内被完全盖住。

**效果（与设计图的平均绝对误差，背景掩膜内）**

| 区域 | v15 | v16 |
|---|---|---|
| 档案袋右上区 y50–150 | 14.60 | **6.68** |
| 阴影区整体 x950–1280 | 27.10 | **22.84** |
| 阴影中段 x1000–1260 / y250–720 | 22.04 | **19.44** |
| 左侧、x≥1300 | 不变 | 不变 |

定点：设计图 (1050,280)=(149,58,27) → v15 (151,56,19) → **v16 (149,60,26)**；
设计图 (1100,700)=(150,57,23) → v15 (177,71,31) → **v16 (146,58,26)**。

## 二、再加「一个」钝角三角形补缺口

v15 的第一枚 `100003`（`rot=90 / w=323 / h=58 / (433,551.5)`）补了下半段，
但沿楔形左缘仍残留 **163 个**亮橙底色像素的尖牙状洞
（上半段 y298–328 共 69 个、中段 y488–508 共 94 个），即用户截图里那道细长三角缺口。

v16 加**第二枚**：`rot=86 / w=460 / h=45 / 中心 (432,460)`，顶角≈158°（`w/h≈10`），
顶点 `(409.6,458.4)`，底边 `(470.5,232.1)-(438.4,691.0)`。

- **零溢出**：整枚三角落在设计图实测楔形凸四边形
  `[(474,238),(464,500),(453,713),(413,500)]` 的 14px 容差内，未染到档案袋外的背景/胶带；
- **全覆盖**：v15 残留 163 个内部亮橙洞 → v16 **0 个**（69/69 + 94/94）；
- 仍然只用**一个** `100003` 原生图元，不拼三个等腰三角（历史实测覆盖率仅 94.84%）。
