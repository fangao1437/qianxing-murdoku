## 6. §3-1 的定案（本轮最高优先级，**结论：误报** ✓）

查法（两行 grep，可复现）：

| 位置 | 事实 | 判定 |
|---|---|---|
| `ui_controller.lua:1240-1241` | 所属函数 = **`local function apply_screen_hide(nodes, screen)`**（L1172）⇒ `screen` 是**形参**；调用处 `apply_screen_hide(nodes, self.screen)`（L2772/L2780）| ✅ **合法** |
| `engine_adapter_qianxing.lua:3320-3323` | 所属函数 = **`function Adapter:enforce_screen_layers(screen)`**（L3312）⇒ 形参 | ✅ **合法** |

旁证：项目自己在 `ui_controller.lua:2629` 的注释里就写着「函数末尾的 `apply_screen_hide(nodes, self.screen)`：判据是**参数** `screen`」✓
⇒ **与 v073 修掉的那个恒真 bug 不同型** ✓ —— 那个是**内联副本**里读了不存在的局部；这两处是**正常的形参传递** ✓

**方法论收获**：机械扫描（grep 所有 `== "home"` 形式比较）会**大量误报** ✗ —— 判据必须回到"这个变量的**定义处**在哪" ✓
