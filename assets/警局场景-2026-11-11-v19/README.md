# 警局场景 UI 资产 v19 · 阴影按设计图实测边界重做（2026-11-11）

基于 v18。用户用 `@skill:ui-review` 对比设计图指出 3 个缺陷，本轮全部按设计图实测几何重做。

## 用户指出的 3 个缺陷

| # | 缺陷 | 设计图依据 | 根因（v18） |
|---|---|---|---|
| ① | 第一组：下方轮廓仍然不齐 | `y≈805` 有一条清晰水平硬边，上方深棕楔形 `(152,59,26)`、下方亮红棕 `(183,75,37)` | 阴影一直涂到黑边，且 Q2 下边界误写成水平 `y=763`；黄带下方的深棕楔形完全没有 |
| ② | 第二组：黄带区域没有阴影设计；左侧阴影边界不在一条直线上 | 黄带上有斜向硬边 `x=-0.8847y+1283.75`（实测 MAE 1.06px），左侧是亮黄 `(252,202,0)`、右侧是被压暗的橙黄 `(248,157,4)`；这条斜边与黄带上方深棕三角的左边界**共线** | 阴影画在胶带**之前**被整条黄带盖住；左边界由 TUP(-0.65)、Q1(+0.2755)、TLEFT 三段不同斜率拼成 |

## v19 构造

从设计图逐行取色拟合出四条边界，用 tool 仓 `fit-primitive-shape.mjs` 的 A+B+C 顶角三角生成
**100% 覆盖 / 0 溢出**的不透明 `100003`：

```
L1      x = -0.8847y + 1283.75   黄带内斜向硬边，MAE 1.06px (y140..250)
袋右缘  x = 924 + 0.2755y       与 L1 交于 (1009,310)
底边    y = 978.7 - 0.2745x     档案袋底边，MAE 1.64px (y700..840)
右边界  x = 1263                沿用 v17/v18 的清晰竖直分界
```

- **阴影主体** `shadow-elements.json`：S1（L1 上段 y60..310）/ S2（袋右缘 y310..695）/
  S3（按底边斜线收尖的三角形），按 x 分 3 带取设计图实测色 `#94391A / #8F381A / #873619`。
  黄带上方深棕三角按 L1 重定位（`#6C2D15`）；删除 TLEFT 亮块。
- **同色内接矩形垫底**：每个分块在三角之前先画一个网格法求出的最大内接矩形（同色不透明），
  即使三角边缘有亚像素缝，底下仍是同色 —— 彻底消除「高亮缺漏」。
- **黄带上的阴影** `tape-elements.json`：画在胶带之后、文本框之前，L1 右侧沿黄带上下缘的梯形，
  橙黄 3 带 `#FCA903 / #F89D04 / #F59403`，左边界与阴影 L1 严格共线。
- **下方水平硬边**：`wedge-bottom.json`（黄带下缘 `y=763.4+0.1334(x-800)` 到 `y=805` 的深棕楔形，
  100% 覆盖）+ `lower-band-rects.json`（`y[805,862]` 亮红棕 6 带）。

拍立得配色（用户明确说明是对设计的有意调整，不是差异）、官方 `106060` 渐晕、52 条右侧渐变、
爪印、胶带渐变、档案袋几何、橙红楔形拟合 `wedge-fit.json`、分割线、圆扣、上下黑边全部沿用 v18。
