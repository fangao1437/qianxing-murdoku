## 二 改了什么（只有四个数 + 一个"额外长度"旋钮）

| 项 | v265 | **v266** | 位置 |
|---|---|---|---|
| 厚（墙门同厚） | 8 | **10** | `cfg.cells.edge_thickness` |
| 墙长 | `cw + 4`（缝补） | **`cw + 4 + 4` = cw + 8** | `edge_overlap=4` + 新增 `edge_extra_len=4` |
| 门长 | `cw × 0.30` | **`cw × 0.44 + 4`** | `door_length_ratio=0.44` + 同一个 `edge_extra_len` |
| 门/墙 比 | 27.3 / 95 ≈ 28.7% | **44.0 / 99 = 44.5%** | 与设计图 44.1–44.5% 一致 ✓ |

★ **为什么门也要能被 +4**：v263 的 "+4" 是**墙专用**的缝补（`edge_overlap`，门吃不到 —— 那时用户明确说"只加墙"）。
这次用户要的是"**门墙**一起 +4" ⇒ 新增一个**墙门共用**的 `edge_extra_len`，两个长度各加一次：
```
墙：tlen = cw + edge_overlap(4) + edge_extra_len(4)
门：tlen = cw × door_length_ratio(0.44) + edge_extra_len(4)
```
⚠️ 不要把它并进 `edge_overlap`（并进去门就加不长）；也不要并进 `door_length_ratio`（比例无法表达"+4px"）。
⚠️ 坐标公式**一个字没动**（`pitch/2` / 外框 `(cw−厚)/2`）—— 用户说位置是对的，就不碰。
