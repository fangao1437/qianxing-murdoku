# 音效与动效接线

> 这份说清两件事：**动效**（Tween 时间线）和**音效**（音频 id）各自怎么接、
> 在哪儿改、以及**没配好时会怎么表现**。
>
> 相关文件：`lua/ui_controller.lua`（谁在什么时候触发）、
> `lua/engine_adapter_qianxing.lua`（怎么播）、
> `tests/effects_wiring.lua`（回归防线）。改完跑 `tools/check_all.ps1`。

---

## 一、整条链路

```
玩家操作
   ↓
ui_controller 状态机  →  self:fx(目标控件id, 语义名, 附加参数)
                              ↑ 语义名来自 M.EFFECTS（如 PLACE = "pop_tile"）
   ↓  攒进 self.effects
render() 末尾统一冲
   ↓
adapter:play_effect(控件id, 语义名)      engine_adapter_qianxing.lua
   ├─ ① 查 EFFECTS[语义名] → 取出 {dur, ease, ch, keys} 时间线
   ├─ ② 拆成多段 Tween，用 game.TweenSequence 顺序播（Append）
   ├─ ③ 播完把姿态还原（否则 vanish 那种缩到 0 就再也回不来）
   └─ ④ 查音频 id（cfg.sounds[名] → M.SOUNDS[名]）→ 有就 game.PlayAudio2D(id)
```

**为什么要"攒一帧再统一冲"**：动效的目标控件可能**在同一帧里刚被创建**
（比如一条新线索的文本框）。如果 fx 时就立刻播，控件还不存在，动效就丢了。
所以统一放到 `render()` 末尾、控件都建完之后再交出去。

## 二、动效：12 条语义动效

### 2.1 语义名 → 实现表

两张表分处两个文件，**靠字符串名字对上**：

| `ui_controller.lua` 的 `M.EFFECTS` | `engine_adapter_qianxing.lua` 的 `EFFECTS` |
|---|---|
| `PLACE = "pop_tile"` | `pop_tile = { dur=…, ch=…, keys={…} }` |

### 2.2 全部条目

| 语义名 | 通道 | 时长 | 曲线 | 观感 | 触发时机 |
|---|---|---|---|---|---|
| `pop_tile` | scale | 0.26 | OutBack | 小→略大→收回，"啪" | **落子**（双击 / 长按 / 回车） |
| `note_pop` | scale | 0.14 | OutQuad | 轻轻一跳 | **铅笔笔记**（单击 / 空格） |
| `pulse` | scale | 0.18 | OutQuad | 脉冲 | **X 工具**划格 |
| `sel_pop_glow` | scale | 0.30 | OutBack | 放大+回弹 | **选中头像卡**；提示成功 |
| `undo_flash` | scale | 0.16 | OutQuad | 闪一下 | **撤销 / 重做** |
| `submit_nudge` | scale | 0.28 | OutCubic | 顶一下 | **提交** |
| `clue_box_pop` | scale | 0.22 | OutBack | 从 0.82 弹出来 | **线索卡出现**（每条一次，见 §2.4） |
| `solved_flash` | scale | 0.36 | OutQuad | 整块闪一下 | **破案**（结算面板） |
| `vanish` | scale | 0.20 | InQuad | 缩到 0 | **擦除 / 从格子上拿起** |
| `roomwall` | scale | 0.14 | OutQuad | 轻微一缩 | 区域墙（**备用**，见 §2.6） |
| `shake` | **pos_x** | 0.30 | Linear | 左右摇头 | **判错**（指认失败） |
| `portrait_slide_up` | **pos_y** | 0.34 | OutBack | 从下方顶出来 | **破案时受害者头像**（见 §2.4） |

### 2.3 通道白名单（`ch` 只能是这四种）

时间线构造器 `build_timeline` 只认四个通道，写别的会被测试拦下：

| `ch` | 实际改的字段 | 值的含义 |
|---|---|---|
| （省略 = `scale`） | `localScaleX` / `localScaleY` | 绝对缩放值，1.0 = 原始大小 |
| `pos_x` | `anchoredPositionX` | **相对基准位置的横向偏移**，正 = 往右 |
| `pos_y` | `anchoredPositionY` | **相对基准位置的纵向偏移**，正 = **往上**（画布 Y 向上） |
| `rot` | `localRotationZ` | 相对基准的旋转角 |

> `pos_x` / `pos_y` 都是 `base + v`，基准值在播放前用 `read_pose(ctrl)` 读一次，
> 播完在 `SetOnComplete` 里**原样写回**。所以相邻两次动效不会互相"吃掉"偏移。

**官方可补间字段白名单**（只有这些能吃 Tween，写错就是静默无效）：

```
anchoredPositionX / anchoredPositionY
sizeDeltaX / sizeDeltaY
anchorMinX / anchorMinY / anchorMaxX / anchorMaxY
pivotX / pivotY
localScaleX / localScaleY / localScaleZ
localRotationX / localRotationY / localRotationZ
```

### 2.4 两条容易被忽略的语义

- **`clue_box_pop`（线索卡出现）**：`build_layout` 里维护 `self._clue_fx` 表，
  每条线索**只弹一次**；且**教程页或弹窗正开着时不弹**（弹了也被盖住，白弹），
  等玩家关掉遮罩后的那一帧再弹。控制器每个关卡重建一次，表随关卡自然重置。
- **`portrait_slide_up`（受害者头像顶出来）**：破案时对 `tray.<受害者id>` 播。
  受害者**也在头像卡列里**（`core:view().tray` 中 `is_victim = true` 的那张），
  所以这个控件一定存在，不用额外建。

### 2.5 ⚠️ 没配好时的表现：静默不动（已加防线）

`play_effect` 第一行是 `EFFECTS[语义名]`，查不到就 `return`。
**不动、不报错、逻辑也不受影响** —— 只有肉眼看画面才发现"这个动作没反馈"。
历史上 `portrait_slide_up` 就这么漏了一整轮（`M.EFFECTS.VICTIM` 指着它，
`EFFECTS` 表里却没有）。

现在的两道防线：

1. **运行时**：查不到会走 `warn_once`，日志里能看到
   `没有这条动效定义：xxx（核对 EFFECTS 表与 ui_controller 里 M.EFFECTS 的名字）`。
2. **离线**：`tests/effects_wiring.lua`（41 项断言，挂在 `check_all.ps1` 的 **2b/13** 步）
   纯文本解析两个源文件做集合比对：
   - `M.EFFECTS` 点名的每一条，`EFFECTS` 里必须有实现（**这是核心断言**）；
   - 反向列出"实现了但没人调"的（只提示，不算错）；
   - 每条动效 `dur > 0`、关键帧 ≥ 2 个、`ch` 在白名单里。

> **改这两张表里的任何一张，都必须跑一次 `lua tests/effects_wiring.lua`。**

### 2.6 `roomwall` 目前是备用

棋盘现在**没有**把区域边界画成独立控件（右栏"区域推断"只是文字）。
所以 `roomwall` 实现了但暂时没有触发点 —— 测试会把它列在"备用"里而不是报错。
将来加"区域高亮"时，在区域划分变化处 `self:fx("board", M.EFFECTS.ROOMWALL)` 即可。

### 2.7 退化路径（真机 API 不全时）

适配层不会因为缺 API 就什么都不做：

| 情况 | 行为 |
|---|---|
| `game.TweenSequence` 不存在 | 退化成**只播最"像"的那一段**（优先挑改了缩放的段），至少有个反馈 |
| `game.Tween` 不存在 | 整条动效静默跳过，**不影响逻辑** |
| `SetEase` 不存在 / 枚举名不认识 | 曲线退回 `EaseType.Linear` |
| target 控件找不到 | 静默跳过（不刷日志） |

### 2.8 加一条新动效

1. `engine_adapter_qianxing.lua` 的 `EFFECTS` 表加一条：
   ```lua
   my_effect = { dur = 0.22, ease = "OutBack", ch = "scale",
                 keys = { { 0.00, 0.85 }, { 1.00, 1.00 } } },
   ```
   ⚠️ `keys` 是 `{ 时间比例 0~1, 值 }`，**至少两帧**；`dur` 是**总时长**，
   每段时长 = `(t1 - t0) * dur`。
2. `ui_controller.lua` 的 `M.EFFECTS` 表加个语义名指过去（`MY_THING = "my_effect"`）。
3. 在合适的地方 `self:fx("控件id", M.EFFECTS.MY_THING)`。
4. `lua tests\effects_wiring.lua` + `powershell -File tools\check_all.ps1`。

## 三、音效：音频 id 映射表

### 3.1 现状：**全是占位 nil，所以现在不响**

```lua
-- lua/engine_adapter_qianxing.lua
M.SOUNDS = {
  pop_tile     = nil,   note_pop     = nil,   pulse        = nil,
  sel_pop_glow = nil,   undo_flash   = nil,   submit_nudge = nil,
  clue_box_pop = nil,   solved_flash = nil,   vanish       = nil,
  roomwall     = nil,   shake        = nil,   portrait_slide_up = nil,
}
```

`nil` 的语义就是**"这个动作不发声"**，不是 bug。

### 3.2 怎么把音频 id 填进去（这是你要做的操作）

1. 打开奇域**沙箱编辑器** → **音效资源**（音频 / 音效库，各版本菜单名可能叫
   「音效资源」或「音频资源」）。
2. 试听并挑出需要的音，记下每条资源旁边的 **id**（数字或字符串，以编辑器里
   显示的为准；7.1 的 `game.PlayAudio2D(audio_id)` 收的就是它）。
3. 打开 `lua/engine_adapter_qianxing.lua`，把 id 填进 `M.SOUNDS` 对应那一行：
   ```lua
   pop_tile     = 12345,        -- 落子
   solved_flash = 67890,        -- 破案
   ```
4. 重新打包 + 同步：
   ```powershell
   $lua = "$env:LOCALAPPDATA\Programs\Lua\bin\lua.exe"
   & $lua tools\bundle_client_script.lua
   powershell -ExecutionPolicy Bypass -File tools\install_script_to_sandbox.ps1
   ```

### 3.3 三档优先级（不用改代码就能覆盖）

`play_effect` 里查音频 id 的顺序：

| 优先级 | 来源 | 用途 |
|---|---|---|
| ① | `cfg.sounds[语义名]` | **单关 / 单实例覆盖**：`Murdoku.start(id, { sounds = { pop_tile = 111 } })` |
| ② | `M.SOUNDS[语义名]` | 全局默认（§3.1 那张表） |
| ③ | 都没有 | 不发声 |

所以**临时试音不用改 `M.SOUNDS`**：在 `main.lua` 的 `Murdoku.start` 调用里加
`opts.sounds` 即可。

### 3.4 播放接口与注意事项

| API | 说明 |
|---|---|
| `game.PlayAudio2D(audio_id)` | 2D 音效（不需要世界坐标 → **契合纯 2D 设计**） |
| `game.StopAudio(handle)` | 停掉一条 |
| `game.IsAudioAlive(handle)` | 查是否还在响 |

适配层封装成 `Adapter:play_audio(id)`（`lua/engine_adapter_qianxing.lua`）。

⚠️ **不要用 `PlayAudio3D` / 带世界坐标的那套** —— 本作是 2D 平面界面，
没有"世界坐标"这个概念（见 `docs/操作模式-2D双端输入.md`）。

⚠️ **音频 id 填错不会崩**：`play_audio` 整体包了 pcall，最坏情况是"不响"，
不会打断 `OnUpdate`。但如果**完全不响**，先确认 `M.SOUNDS` 里那条**不是 nil**。
