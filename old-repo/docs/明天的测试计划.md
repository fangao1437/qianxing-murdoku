## 一、根因（今晚最后一步查到的，证据在代码注释里）

**⇒ 适配器 L1732 那段注释写着这个引擎的**点击派发条件**** ✅：

```lua
-- 真机上"点不动界面"的头号原因就是**控件的祖先容器没打开 showCursor**
-- 派发条件：
--   for i = t; i; i = i.parent do
--     if i.kind == "container" and i.showCursor then return true end
--   end
```

**⇒ 一个控件要收到点击，祖先链上必须有一个 `kind == "container"` 且 `showCursor == true` 的容器** ✅。

**⇒ 而脚本靠一份名单去开这个开关** ✅：

```lua
local MANAGED = {
  "root", "topbar", "left", "tray", "clues", "board",
  "right", "actions", "modal", "intro",
}          ← ★ 里面**没有 `home` / `select`**
```

**⇒ 真机日志正好对上** ✅：
```
容器 home 字段：   ... showCursor=false
容器 select 字段： ... showCursor=false
已由脚本打开 9 个容器的「显示常驻光标」     ← 9 个，不是 11 个
```

**⇒ ⇒ 所以 `home.*` / `select.*` 下面的**所有按钮**（主页四键 / 选关卡片 / 返回键）全部落在门控②之外** ⇒ **点不动** ✅。

**⇒ 这也解释了那个一直没解释的不对称**：主页能点（`root` 那条链当时通）✅，一切到选关就全废 ✅。
