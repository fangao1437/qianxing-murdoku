## 一、★ 最重要的发现：**有一个能程序化访问的官方图片素材库**

那个外部编辑器的 API 是**同源相对路径**，可以直接调：

| 端点 | 作用 |
|---|---|
| `/api/library/catalog` | **图片素材目录**（130 KB）|
| `/api/library/sprite/<id>.png` | 单张 sprite |
| `/api/export/gia` | 导出 **GIA**（"游戏素材格式"，**支持文字**）|
| `/api/export/lua` | 导出**客户端绘制脚本**（"可再次导入"，只画图片图元）|
| `/api/export/png` `/svg` `/css` `/json` | 常规格式 |

### `/api/library/catalog` 里有什么

**1543 个游戏图片素材，14 类**：

| 分类 | 数量 | id 区间 | 适合做什么 |
|---|---|---|---|
| 底板-彩色 | **392** | 107001–107402 | 面板/横幅底图（实测是深蓝横幅那种）|
| 装饰图案-彩色 | **317** | 105001–105317 | 图标/徽章/星光/几何（实测：星星、雪花、手势、圆形徽章）|
| 玩法图标-彩色 | 148 | 103001–103148 | 玩法图标 |
| **道具** | **139** | 111001–111139 | **物品图标**（实测：苹果、食物、卷轴、钥匙、宝箱、武器、饰品、药水）|
| 功能图标-单色 | 113 | 100101–100213 | **按钮图标**（我们用的红 ✗ `100101` 就在这里）|
| 底板-单色 | 96 | 106001–106096 | 单色底板（白 `106053` 在这里）|
| 功能图标-彩色 | 80 | 101001–101080 | 按钮图标 |
| 特殊字符 | 75 | 109001–109075 | 符号 |
| 技能天赋 | 53 | 110001–110053 | 天赋图标 |
| 玩法图标-单色 | 52 | 102001–102052 | 玩法图标 |

**★ id 体系与我们存档完全一致** —— 我们 `.gil` 里在用的 `100101`（红 ✗）、`100108`、`106053`（白）
**都在这个目录里**。所以这些 id **在游戏里必然存在**，接线不需要任何"导入"。

## 二、"看图挑"这条路已经打通

目录里**只有 id 和分类名，没有单张素材的名字** —— 想知道哪张是椅子只能看图。
所以我做了个 **接触表（contact sheet）**：把一类的 sprite 拼成一张大图，我直接看图挑。

```powershell
node tools\qx\library.mjs fetch                       # 拉目录
node tools\qx\library.mjs list 道具                    # 看某类的 id
node tools\qx\library.mjs sheet --cat=道具 --max=139   # 下载该类 sprite
# 再拼成一张图（PowerShell + System.Drawing，见下面的脚本片段）
```

**实测已拼好的接触表**：

| 文件 | 内容 | 我看到的 |
|---|---|---|
| `tools/qx/out/sheet-props.png` | 道具 ×139 | 苹果/食物/卷轴/钥匙/宝箱/武器/护腕/饰品/药水/宝石 |
| `tools/qx/out/sheet-creation.png` | 造物 ×42 | 各元素史莱姆、兽面、**戴口罩的角色（112030/112031）**、**戴礼帽的侦探（112040/112041/112042）** |
| `tools/qx/out/sheet-deco.png` | 装饰图案 ×64 | 四角星、雪花、猫头徽章、手势、圆形场景插画 |

## 三、⚠️ 一个如实说明：**2D 库里没有"桌椅盆栽"**

参考图棋盘上的家具（椅子/床/盆栽/箱子）**是 3D 模型**，
它们来自 `BeyondAssistEditor\Resource\Json\Beyond\Official\OfficialPrefab`（**2729 个**），
编辑器把它们**渲染成缩略图**贴在格子上。

**我们这套是 2D 客户端 UI** ⇒ 能用的是上面那 1543 个**2D 图片素材**，
它们的风格是「**物品图标**」而不是「3D 家具」。

**⇒ 所以有两个选择**：

| 方案 | 做法 | 效果 |
|---|---|---|
| **A. 直接用 2D 图标**（推荐，我能自主做完）| 用道具/装饰类里语义接近的图标当代号 | 风格统一、**现在就能配完**；和参考图的 3D 家具观感不同 |
| B. 用那个网站**自己画** | 用图元拟合出桌椅，导出 GIA 导入 | 更接近参考图，但**要导入外部资产**（你说"有很多限制"）|

**⇒ 我按 A 先配一版**，你要 B 的话我们再走导入。
