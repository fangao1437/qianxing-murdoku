## 二 ★★★★ 三条根因（**都有可复跑的判据**）

### 2.1 根因 A ★★ `"hit."` 前缀把选关屏自己的命中层藏了 ✗（**点不动的正解** ✓）

★ 代码位置 ✓：`lua/ui_controller.lua` 的 `apply_screen_hide`，主页/选关那一支的
`PREFIX` 名单里原来有 **`"hit."`** ✓

★ 它**本来是干什么的** ✓：★ 关卡内有**七颗**光标检测区域 `hit.back / hit.submit / hit.redo /
　 hit.undo / hit.hint / hit.ok / hit.no` ✓ —— ★ 主页/选关**必须把它们藏掉** ✓
　 （不藏的话：隐形命中层留在屏幕上吃点击 ✓ —— 2026-10-03 那次"选关页处处有音效"就是这一类 ✓）

★★ 它**错在哪** ✗：★ `"hit."` 是**族前缀** ✓ ⇒ ★★ 它**同时命中 `hit.select.*`** ✓✓
　 ⇒ ★ 选关屏**每帧**把这 7 个命中层设成 `visible = false` ✓
　 ⇒ ★★★ **可视层（白卡）在、命中层被藏 ⇒ 点哪儿都没反应** ✓✓

★★★ 为什么这个 bug **能活到今天** ✗（★ 比 bug 本身更值得记 ✓）：
　 ★ 命中层**本来就是隐形的** ✓ ⇒ ★ "被藏了"与"正常隐藏"**在屏幕上长得一模一样** ✓
　 ⇒ ★ 唯一可观察的差异 = **点击有没有反应** ✓ —— ★ 而这正是用户报的那件事 ✓

★ 判据 ✓（**能红能绿** ✓）：`lua tests/select_hit_visible.lua`

```
修复前：42 通过 / 7 失败    ← 7 条红全是 hit.select.* 的 visible（实测 false）
修复后：42 通过 / 0 失败
```

★ 修法 ✓：★ `"hit."` 整条删掉 ✓，改成 **`HIDE["hit.back"] = true` … 七条具体 id** ✓
　 ★ 规矩 ✓（与 `KNOWN_ABSENT` 那条**同一类病** ✓）：
　 ★★ **族前缀只许给"整族都该藏"的族用** ✗ —— ★ 出现合法例外就必须**列具体 id** ✓

### 2.2 根因 B ★★ 只有一页时，箭头被**整组隐藏** ✗（"看不见箭头"的正解 ✓）

★ 旧写法 ✓：`local pg_visible = (pages > 1)` ⇒ ★ 4 关 = 1 页 ⇒ `select.prev/next/page`
　 **三个一起 `visible = false`** ✓（★ 连**页码**也没有 ✓ —— 所以玩家**完全看不出"只有一页"** ✓）

★ 旧写法错在哪 ✗：★ 它把**两件事**当成了一件 ✓：
　 · ★ "这一屏**有没有**这个控件" ✓（那是**设计**的事 ✓）
　 · ★ "这个方向**现在能不能翻**" ✓（那是**状态**的事 ✓）

★ 新写法 ✓（分开 ✓）：
```
可见性 = 这一屏有没有     ⇒ 选关屏【永远有】左右箭头 + 页码 ✓
可用性 = 能不能往那边翻   ⇒ 不能翻 ⇒ 【变暗】（imageColor 乘算 ✓）
                           能翻   ⇒ 【原色】
点击照旧一律绑上          ⇒ select_page 那边已经夹紧（page 不会越界 ✓）
```

★ 变暗用的**不是新发明的值** ✓（工程里已经在用 ✓）：`0xFFFFFFFF` 原色（`NORMAL_TINT` ✓）·
　 `0x7FFFFFFF` = 50% 透明白 = 整体减淡（`PLACED_TINT`，"已放置头像卡"那种效果 ✓）

★ 页码顺带解决了一个**沟通问题** ✓：★ 现在会显示「**第 1 / 1 页**」✓
　 ⇒ ★ 玩家一眼就懂"箭头为什么是暗的" ✓（★ 这一条正好回应用户这次的疑惑 ✓）

### 2.3 根因 C ★★ 染色（`tint`）在真机上**一直没生效** ✗（"纯白卡"的正解 ✓）

★ 适配层 `key == "tint"` 那一支原来有**两道门槛** ✗，真机**两道都过不去** ✓：

| # | 门槛 | 真机实况 |
|---|---|---|
| ① | `type(value) == "table"` ✗ | ★ 缩略图传的是**打包整数** ✓ ⇒ 不进分支 ⇒ **静默无操作** ✓ |
| ② | 还要 `type(Color) == "function"` ✗ | ★★ 本文件**自己写着** ✓：「`Color()` 全局函数**不存在**」✓ ⇒ 就算进了也拿不到值 ✓ |

⇒ ★★ 结果 ✓：★ **卡片一直纯白、缩略图一直没颜色** ✓（★ 与用户截图完全吻合 ✓）
　 ⚠️ 顺带解释 ✓：★ 缩略图**其实一直在**（白色画在白色卡上 ⇒ **看不见** ✓）✓

★ 修法 ✓（两条，都**不依赖那个不存在的函数** ✓）：
　 · ★ **整数直接认** ✓ —— 真机已证明可用 ✓（`PLACED_TINT` / `NORMAL_TINT` / `HIGHLIGHT_TINT` 全是整数 ✓）
　 · ★ **table 自己打包成 `0xAARRGGBB`** ✓ ⇒ 新导出纯函数 **`M.pack_color(r,g,b,a)`** ✓
　 　 ★ 为什么导出 ✓：★ 纯函数**离线就能测** ✓（`tests/select_hit_visible.lua` §6 直接断言 ✓
　 　 —— 同 `M.press_seconds` 那条老做法 ✓）
