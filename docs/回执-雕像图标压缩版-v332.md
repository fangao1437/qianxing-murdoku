## §1 做法：直接把原作图标压成"纯色矩形层"
用户说的"大面积底色铺底 + 不同色往底色上铺"，正是压缩工具的产物形态：
1. 原作图标 `statue__secret-lab.png`（296×480，**含两级底座**，即用户要的底座样子）；
2. **调色板量化到 8 色** → NEAREST 缩到 **56×91** → 洋红背景键控（去掉透明区域）；
3. 用 `miliastra-image-algorithm` 工具做 **greedy 最大矩形合并**（STD=2，**MAE 0.03**）：
   - 大块=大面积同色区（就是"大面积底色铺底"），小块=边角/高光/描边（"边角单独修、不同色铺上"）；
   - 工具自检：**空洞 0 / 重叠 0 / 越界 0**；
4. 过滤背景（洋红）块 → 纯色矩形（imageId 100001）→ 转成"相对 content 画布中心"的模板层。

结果：
- **381 层纯色矩形**（全部 alpha=FF 不透明、无旋转、互不重叠）；
- **与原作几乎一致**（对照图 `_work/art-work/v332g-statue-compress.png`：左原作 / 右 381 块压缩）；
- **无透明、无空洞、无杂色**（块之间不重叠且不重叠背景，颜色来自 8 色量化，边缘干净）；
- **底座就是原作的两级台阶**（含黑框/深色面/浅色沿），**不再有额外横线**（我们之前的"高光带"已去掉）；
- 画布 108，雕像占 56×91（保持原作 480/296 比例，修长）。

## §2 关于层数
