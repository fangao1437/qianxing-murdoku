# 警局场景 UI 资产 v13（2026-11-11，基于 v12 的三处定点调整）

承接 v12（`assets/警局场景-2026-11-09-v12/`，提交 `2d113da`）。用户给出两张带该背景的 UI 设计图（教程 / 数独）、一张 v12 实机截图、以及一张「对应设计图」（用于档案袋橙红区），要求只改三处，其余一律保持实机版。

## 一、三处调整（均有实测数据）

### 关于第 3 点的取色口径（需复核）
两张 UI 设计图（教程 / 数独）里拍立得照片是**均匀深棕红**且没有明暗分界；「对应设计图」里则是紫色且已有分界。按用户「这一版设计图没有加这个（分界），参考实机效果就行」的说明，v13 取**两张 UI 设计图的深棕红 + 顺时针 14°**，分界仍按 v12 实机的做法保留。若最终想保留紫色照片，只需把 `build-v13.cjs` 顶部 `PHOTO_L/PHOTO_R` 改回 `#4A313D / #513C57` 重跑即可。

### 第 2 点为什么不用逐格实色网格
先试过按设计图亮度场生成的 20×30 / 25×45 不透明网格：控件数 902~1161 虽可用，但导出图左侧出现明显方格色块与竖条纹（相邻格亮度差可达 30/255）。改用官方 `106056` 柔影多层同心椭圆后每层自带渐隐，24 个控件即得到连续压暗，且椭圆半径（≤120×300）保证只作用于左上/左下角，左中与右半幅完全不被覆盖。参数由 `tune-vignette.cjs` 对 8 组候选按设计图 20 个干净采样点数值搜索选出。

## 三、对齐与校验口径

- 实机截图 1604×960，白色标题栏到 y≈58 ⇒ 画布 `crop(4,58,1600,900)`；设计图 1920×1080 等比缩到 1600×900。
- **存档的 `preview/police-v12.png` 是旧渲染器产物**（左上 R=161），当前 API 用 `scene-v12.json` 重渲染的基线为 **R=116**，与用户 v12 实机截图 **R=117** 逐点吻合。因此所有「v12 ↔ v13」对比均以**当前 API 重渲染基线**为准。
- 像素差分（v12 基线 vs v13）：左侧 x0–500 均值差 6.64；右侧背景 x500–1000 均值差 0.50；**最右 x1500–1600 变化像素 0**；变化集中在拍立得区与档案袋右边缘缝隙。

## 四、复现

1. 改 `build-v13.cjs` 顶部常量（或 `scene-v13.json`）；
2. `node build-v13.cjs` → 拼图站 `/api/export/{gia,png}`；
3. `node finalize-v13.cjs` → 落地交付文件、模拟文字预览、对比图；
4. `node verify-v13.cjs`；`artkit.mjs check --kind=gia --file=<...>`；
5. `.gia` 放入 `BeyondLocal/Beyond_Local_Export`，游戏内「导入外部资产 → 转存所选资产」。

## 五、未验证 / 已知差异

- **未做 v13 真机导入验证**，需用户导入后截图复核。
- 档案袋橙红区形状仍以实机版为准（仅做了「延伸到边缘」），设计图里那份不同的橙红区未照搬。
- 设计图档案袋底部另有一片浅橙折角（透视梯形），v12/v13 仍用刚体旋转矩形近似（用户未要求改）。
- 杯子按 v12 既定范围仍缺失。
- 暗角剖面在 x≥160 处保持实机版（设计图该处比实机亮 20~30），这是按「只加强暗角、其余保持实机」处理的；若要把整条左侧提亮到设计图数值，需另加一层提亮，会改变右侧观感，故未做。
