# 警局场景 UI 资产 v15（2026-11-11，官方圆形暗角 + 钝角补形 + 交界柔化）

承接 v14（`assets/警局场景-2026-11-11-v14/`）。用户实机反馈三点，并补充「历史里有圆形暗角怎么做的官方方法」。

## 一、三点修正

| # | 反馈 | 依据与做法 |
|---|---|---|
| 1 | 左侧暗角又成了方形 | 查历史 `assets/警局场景-2026-11-09/README.md` §4.5 与 `v10-params.json`：**官方暗角 = 单层 `106060` 径向渐晕，染黑 1800×1040 铺满 opacity 1**；`106056` 是「白心不透明→窄带渐隐」的柔影，拉伸后中心大片恒定色 ⇒ **硬边方形块**（v11 已踩过）。v14 用的 24 层 106056 正是方形来源 → **全部删除**，改回官方 1800×1040 op1（凹形连续径向渐晕）。实测左上 (10,90) 85 / 左中 (10,450) 136 / 左下 (10,820) 84，四角暗、中部亮，无方形。换渐晕后右侧会被多压暗，按实测 alpha 剖面 `C_new=C_old·(1−a_old)/(1−a_new)` 补偿 52 条渐变条 |
| 2 | 橘红区需要再补一个钝角三角形 | v14 楔形下半段从 (414,500) 直接斜收到 (453,713) 太尖，且细长区域用 3 个等腰三角填充**覆盖仅 94.84%** → 露出尖牙状三角洞。改用**单个 `100003` 钝角三角**：底边竖直 (462,390)-(462,713)、顶点 (404,551.5)，顶角≈140°，`rot=90 / w=323 / h=58`。一个原生图元既补钝角又把所有洞一次盖满 |
| 3 | 交界处太硬 | 定位到 `x=1263` 阴影右边界：v14 左侧是纯色 SHADOW(151,56,19)、右侧是渐变背景，上部色差 11~21/255 形成竖直硬线。纯色阴影右边界退到 **1223**，后接 **20 条半透明渐隐带（alpha 1→0，共 60px）**；半透明混合自动适配不同 y 的渐晕/渐变，不会像固定色过渡带在别的高度产生新色带。实测 y=90 从 151→146→139→135→120 平滑下降；拍立得后画，相框/照片上的竖直分界保持硬边 |

## 三、校验

- 根层无 `field 4`，`.gia+4=2a05362e`；artkit 两份 `ok=true / budgetExceeded=false / kind=3 / trailer 0x679`；276/273 图元远低于 1000 上限。
- **右侧**：v15 vs v14 在 `y=450` 中线按实测剖面补偿；整幅 `x≥1500` 均值差 **3.15/255（≈1.2%）**、最大 17，来自官方渐晕的 y 向 alpha 剖面（补偿按中线一维计算），视觉无感；`x≥1300` 均值差 3.12。
- 原生图形构造（零扫描条）、拍立得角度配色、分界 x=1263、文本框、爪印、档案袋几何均沿用 v14。

## 四、已知限制 / 真机待验

- **未做 v15 真机导入验证**；`100003` 在 `.gil` 图片控件个别旋转角曾不出图，本轮是 `.gia` scene image 图元，预览全部正常但仍需截图复核。
- 官方 `106060` 单层无法同时满足设计图「四角≈52」与「边中≈180」：1800×1040 实测四角 85、边中 136（历史 v10/v12 已记录的 alpha 剖面限制）。1600×900 四角可到 56，但边中掉到 110 整体发灰，故采用历史验证「最柔和」的 1800×1040。
- 左侧暗角强度由官方渐晕单独提供，比 v14（柔影叠加）略弱；若要更接近设计图四角数值，需要改渐晕尺寸或引入新的官方渐晕素材，勿再用 106056 堆层。
- 档案袋底部浅橙折角、咖啡杯仍未做。
