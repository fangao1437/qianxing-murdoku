# 715 UI 自适应修订 v8

日期：2026-11-18。基于 v7，保留首页启动修复。

**2026-11-18 实机反馈更正：用户反馈 v8 整组界面漂移到右上角并露出游戏场景。本版未通过实机验收，请使用后续 v9 修复候选版复验。下文是 v8 当时的历史记录，不再作为全比例通过依据。**

v9 排查确认：v8 将 root 的中心锚点位置写成半个画布宽高；旧测试对 root 特判减去相同的半画布量，因此掩盖了宿主父容器模型下的整屏偏移。修正模型后，未修改的 v8 在 1600×1200 中根中心偏移 (+800,+600)，23 项断言失败，61 条抽查越界。v9 恢复原存档四端零偏移，并加入位置回读与根居中回归。该复现是与实机症状一致的模型证据，v9 的实际宿主映射仍待导入确认。

## 修改内容

1. 所有功能区、静态美术、动态格子与点击层共用根逻辑坐标；使用实际UI画布映射，不再混用原始画布与固定1600宽坐标。
2. 移除触屏/移动手柄1600×900时强制使用1600×720的历史兜底。
3. 最小逻辑内容矩形为1600×900，宽屏扩展横向，4:3扩展纵向；背景独立cover铺满，边缘按钮随对应边缘移动。
4. 所有页面保留首层不透明底色，选关底色独立覆盖全画布；背景649个子层逐层显隐，避免父层隐藏不级联。
5. 保留撕纸独立fit/贴角，不把其board父层误当整幅木板放大；选关白框、缩略图、文字、命中区共享倍率。
6. 版本在构建源头修改，GIL与Lua同步导出；保护记录、玩法模块与线索内容未改。

## 实机反馈与验证边界

已读取用户1280×576（20:9）移动端选关截图，并将该尺寸加入回归。代码确认原版普通控件与背景坐标口径不同、选关关闭了通用底色保障；本版补齐这两点。截图本身不能给出宿主画布宽高与裁切矩形，因此不能把离线四角覆盖直接写成“真实两侧漏出已验证消失”。

测试使用实际GIL控件树和实际生成Lua，但控件API由模型模拟。Lua5.3测试使用fengari，不是官方游戏引擎。边界检查只覆盖列出的主要区域与交互控件；不包含全部装饰图元、真实字体裁剪、安全区、真实射线命中和手柄导航。

宽屏按内容最小矩形做等比映射，内容相较旧固定宽度布局更紧凑。移动端文字可读性、触控尺寸以及外层容器是否仍有安全区裁切需要新文件导入后确认。没有把任何关卡、线索或身份规则删掉来换取布局通过。
