## 一 v318 改了什么（四处，全部围绕"补造链"）

1. **格子建好后主动补造一次**（`ensure_cells` 末尾）：重算映射 → `_furn_tpl_ok` → `_furn_try_all()`；
2. **映射不再钉死**：`_spawn_furn_tpl` 里若当前键查不到模板，**重新读一次 `things`**再查（真机就是晚一步进树）；
3. **失败不再静默**：缺映射时打一次 `家具模板缺映射：模板键=… → 归一化键=… 当前映射 keys={…} things 找到=…`；
   实例化失败也不再永久关掉整关（旧码 `_furn_tpl_ok=false` 会一次性废掉所有家具）；
4. **有上限的补造重试**（`on_tick`，每秒一次、最多 12 次；全部造好后自然不再进入）＋ 换关重置额度；
5. 另加一行**映射体检**：`家具模板映射：things 找到=… 条目=N keys={…} 已缓存的请求格=…`。
