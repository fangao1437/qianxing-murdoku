# 规则规格 · 偷窃版（现行唯一规则依据）

> 2026-11-17 修正：按用户明确的多条件身份规则更新。本文替代旧 R4/R5、旧唯一解验收口径；存档和运行时不在本次修改范围内。教程实档与历史教程草稿必须区分。

## 1. 基本摆位与区域

- N×N 棋盘，N 人（包括受害者），每人一格，每行每列恰好一人。
- 排除不可站格；椅子、地毯可站，其他家具按关卡 occupiable 标记。
- 墙划分区域，门不合并区域；只有门直接连通的区域才相邻，不传递、不含自身。
- 家具“旁边”按同区域上下左右四邻计算。跨房间的门相邻不是家具旁边。
- 有且只有一名盗窃者，受害者不能是盗窃者。

## 2. 身份规则：先按候选数分流，再判定身份

**最多一条线索为假；对每名潜在盗窃者，先在不使用身份规则的前提下，用基本摆位规则和其余适用线索计算其合法可选位置。候选恰好一格，是进入“盗窃者说谎”判定的充要条件；候选多于一格，是进入“盗窃者选位”判定的充要条件。候选为零时，该身份分支无效。** 这三个分支互斥，不能先用人数规则把位置压成一格，再倒推说谎条件成立。

- 受害者、其他无辜者的线索必须为真。
- 无说话人的通用线索必须为真，不能作为可任选的假话。
- 假话以整张线索内容为单位：该句在最终摆位中必须实际为假，不能只删除它而不检查真值。
- 说话人是卡片归属者；who/a/b 是陈述对象，不自动等于说话人。711 的个人卡按 suspects 的人物顺序对应，今后重排卡片必须同步记录归属。
- **说谎分支（恰好一格）**：暂时撤下该候选人的个人线索，只用基本摆位规则和其余线索求候选。若恰好剩一格，才允许把该人作为说谎者；最终必须证明撤下的整句实际为假，并应用人数规则。
- **选位分支（多于一格）**：该候选人的可选位置不止一格时，不能把他判为说谎者；保留线索为真，应用人数规则，从多个位置中筛出盗窃者自身的合法位置。必须证明人数规则确实收窄了他的候选位置。
- 多人暂时未固定并不直接等于多名盗窃者。应逐个候选应用上述互斥分流和完整人数条件；其他人的连带位移不自动构成犯罪身份。

## 3. 候选格在哪个阶段计算

以下为本次验收采用的明确计算口径，避免因读卡顺序或求解器实现不同产生不同身份。

令 H 为基本摆位规则，C 为全部个人及通用线索。候选位置阶段不得读取 roles.thief、solution、meta.false_clue，也不得使用第 4 节人数规则。

1. 对每个非受害者 t，逐条暂时撤下 t 所属的个人线索 j，仅用 H 与其余线索得到 S−j；P−j(t) 是 t 在 S−j 中出现的所有不同格。
2. 若 S−j 为空或 |P−j(t)| = 0，该身份分支无效。
3. 若 |P−j(t)| = 1，**且仅在此时**进入说谎分支：j 必须由 t 说出，最终摆位中 j 必须实际为假，再应用第 4 节人数规则。这个“恰好一格”条件同时是说谎分支的必要条件和充分入口条件。
4. 若 |P−j(t)| > 1，**且仅在此时**进入选位分支：不能把 j 判为假；恢复全部线索为真，得到全真集合 S0，并对 t 应用第 4 节人数规则。只有人数规则确实把 t 的多格候选收窄到唯一格的分支才保留。
5. 对同一人物的分支不能在“说谎”和“选位”之间任选；候选数决定分流。最终还要检查所有人物摆位与盗窃者身份是否唯一。
6. 汇总所有合法分支后再验收唯一性。不要用 meta.false_clue、roles.thief、solution 预先筛选。

可选位置指“至少存在一个完整合法摆位支持的格”，不是初始浅蓝高亮格，也不是某条解题路线暂未划掉的笔记格。房间划分可用于线索真值；第 4 节人数约束必须留到候选集合求出后。

## 4. 人数规则

对每个候选身份 t 及其完整摆位：

- Rv 是受害者所在区域，Adj(Rv) 是有门直接相连的区域集合。
- Rt 是 t 所在区域，必须属于 Adj(Rv)。
- inno(X) 是 X 中除盗窃者（以及显式存在的同伙）外的人数。
- Rt 必须在 Adj(Rv) 中拥有最多无辜人数；默认 tie_policy=forbid，必须严格最多。不要和受害者房间比较，也不要比较全场所有房间。
- tie_policy=allow 只能用于明确允许并列的特殊设计，不能因此宣称身份或摆位唯一。

旧“受害者房内人数≥2强制有同伙”“同伙必须与盗窃者同区”已于 2026-10-18 废止。当前第 3、4、5、7 关未声明同伙，本次不引入额外身份。历史关卡显式声明同伙时须另行验收，不能把该设定移植到没有同伙的关卡。

## 5. 作者字段与玩家可知信息

- roles.thief、solution、meta.false_clue 是作者答案，只在独立求解完成后比对，不能作为玩家前提。
- meta.false_clue 缺省只说明作者目标是全真，不能在 announce=unknown 时让求解器提前排除假话分支。
- announce=none 表示向玩家公开全真；one 表示公开恰有一句假话；unknown 不公开真假数。只有确实对玩家公开的限制才可参与筛选。
- 运行时匹配预设答案不构成逻辑唯一解证明。现有 tools/validate_levels.lua 已移除多解枚举，其结果不能当作本规格的完整验收。

## 6. 验收与线索有效性

1. 在不读取答案身份的前提下分别形成全真集合、逐条撤下个人卡的集合。
2. 检查说话人、真假、候选格阶段、人数条件全部成立。
3. 合法分支合并后，摆位与盗窃者身份必须唯一，并与作者答案一致；零解也是不合格。
4. 假话关须记录撤句后说话人的候选格，而不是只报最终摆位唯一。
5. 全真关须记录人数规则前后盗窃者的候选格，证明人数规则确实发挥作用。
6. 删除某条线索并重新进行整套验收，说明其对摆位、身份或真假分支的作用。单看初始高亮格数量不够。
7. 输出反例或候选集合，以便复核；预设身份后跑出一解不算验收。

## 7. 明确作废的旧口径

| 已作废表述 | 现行替代 |
|---|---|
| 至多一条假话，任何个人或通用线索均可承担 | 至多一条，必须盗窃者本人所述；候选恰好一格才进入说谎分支 |
| 受害者也可能说假话 | 受害者必真 |
| 发现一条假话即可，不必验证说话人位置 | 候选恰好一格才进入说谎分支，并验证整句实际为假 |
| 全真关任何身处人数最多房间的人都可成为盗窃者 | 候选多于一格才进入选位分支，并由人数规则收窄自身位置 |
| 多人未固定就必然身份不唯一 | 按候选数互斥分流，再逐候选应用人数规则，比较最终合法分支 |
| 只允许预设 false_clue 为假 / 预设 thief 后求解 | 独立枚举后才对照作者字段 |
| 每个替代解必须至少违反两条线索 | 也可因说话人、候选格触发条件或人数规则不成立被排除 |
| 给所有人双坐标锁就一定是好关卡 | 全真关必须给盗窃者保留人数规则前的可选位 |
| 受害者同区有人则必须有同伙 | 已废止，不根据受害者房间人数自动生成同伙 |

2026-11-17 对711的核查结果见《711规则修正复核》。旧审阅页中“多人可移动直接证明身份缺口”等判断不再作为验收依据；独立成立的 E 冗余集合证明保留。
