| 项目 | v11 实机 | 设计图实测 | v12 |
|---|---|---|---|

| 深橙四边形 | 110 条局部竖矩形（步长 5.64px）、`opacity 0.95` 叠条，斜边可见 ~6px 阶梯 | 斜边 `X=1288−0.901Y` | 310 条（步长 **2px**）、**实色不透明**，台阶降到 2px |
| 阴影溢出 | 黑边先画、阴影四边形后画，顶点 (1263,28) 露在黑边之上，右上角有三角尖溢出 | 阴影尖角被上黑边盖住 | **调换绘制顺序**：阴影四边形 → 上下黑边 → 胶带/物件；右上 3× 放大复核无溢出 |

### 暗角方案选型（实测排除过的坑）

| 方案 | 关键点 MAE | 结论 |
|---|---|---|
| 单个大 `106056` 柔光圆 | — | 中心是大片恒定深色，只有很窄的渐隐带 ⇒ 仍是**硬边圆盘**，比 v11 更糟 |
| 多个同心 `106056` + 补偿 | 12.2 | 渐隐带造成吸光损耗，中段偏亮；角部易过暗 |
| **50 层同心实心圆 `100002`** | **10.4** | ✅ 平滑圆形、无同心环、可精确按查表复现剖面 |

`VIG_RADIUS=350 < 450`，因此四角圆都够不到 `y=450` 中线，右侧渐暗曲线完全不受影响。这是满足用户「不要破坏右侧渐暗」约束的关键。

### 本轮新踩的坑（可复用）

1. **绘制顺序决定溢出**：v11 把上下黑边放在阴影四边形之前，阴影顶点 (1263,28) 就画到黑边上去了。黑边必须**后于**阴影、但仍**早于**胶带（物件压在黑边上，与设计一致）。
2. **扫描填充步长直接决定「平直」观感**：5.6px 步长在 45° 斜边上是肉眼可见的阶梯；≤2px 才接近实色刚体边。不是刚体矩形的形状一律用细步长，或保留刚体旋转矩形。
3. **半透明叠条不能重叠**：`opacity 0.95` + 条带重叠 0.6px 会产生规律竖条纹，v12 深橙区改为不透明实色。
4. **`106056` 不是径向渐变素材**：它是「白心不透明 → 向外窄带渐隐」的柔影，拉伸后中心仍是大片恒定色。要做真正的圆形暗角必须分层叠加，或用官方 `106058/106059` 渐晕（后者四周都暗，会压暗上边中部，不适合本图）。
5. **拍立得竖直分界不能只画一个竖矩形**：相框是旋转刚体，右半必须拆成「与相框同角度的旋转矩形」+「补到竖直线的细长三角」，否则上/下边缘会在分界处出现错位台阶。

## 四、复现

1. 改 `scene-v12.json`（或 `build-v12.cjs` 顶部常量）；
2. `node build-v12.cjs` → 拼图站 `/api/export/{gia,png}`；
3. `node finalize-v12.cjs` → 模拟文字预览 + `v12-params.json`；
4. `node verify-v12.cjs` 查 root 层；`artkit.mjs check --kind=gia --file=<...>` 查容器；
5. `.gia` 放入 `BeyondLocal/Beyond_Local_Export`，游戏内「导入外部资产 → 转存所选资产」。
