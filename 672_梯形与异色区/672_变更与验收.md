## 二、构造方式（按「最少图元」重做）

层序（`recTop` 与 `childList` 同步，全部在最早文本控件 `letter` 之前）：

```
backrop1  330×85.4  #FF491B1E   ← 描边：灰 #56565E → 暗红（本版唯一改色）
  → backrop2 324×79.4 #FF68262A   主色（不变）
  → art671.clueN.hi   #9D3033     左上亮红（不变）
  → art672.clueN.trap 100001 矩形 #611F23   右侧梯形底
  → art671.clueN.lo   100003 #68262A        复用：改形为主色遮盖三角
  → art672.clueN.mid1 100003 #702830       中间异色区 ①
  → art672.clueN.mid2 100003 #702830       中间异色区 ②
  → art672.clueN.corner 100003 #611F23     梯形斜边补到底边
  → letter / what / face / who
```

**中间异色区＝2 枚等腰三角，解析构造、部分重叠、100% 覆盖**：

| 层 | 角色 | 参数（cx, cy, w, h, rot） |
|---|---|---|
| `mid1` | 等腰钝角三角，**底边 = 目标区左边界 A→C**，一条腰 `C→P` 正好沿右边界下段 | `(777.209, 445.953, 69.583, 17.996, −111.695°)` |
| `mid2` | 等腰三角，**顶点落在顶边左端 A（左上方）**，底边 = 右边界上段 | `(792.187, 422.372, 73.672, 31.969, 40.954°)` |

两枚三角的三顶点全部落在 `324×79.4` 内（凸性 ⇒ 零溢出），同色不透明重叠无缝；
栅格自检 6,487 点 **覆盖率 100.00% / 溢出 0**。这正是用户所述「左侧边用等腰钝角三角形底边、右侧边用该三角形一条腰 + 另一个顶点在左上方的等腰三角形底边拼合」。

**右侧梯形＝1 个矩形 + 复用 lo 遮盖三角 + 1 枚极小补角三角**：

- `trap`：`100001` 矩形 `#611F23`，`cx=910.947 / cy=450 / 102.106×79.4`，左边界 `x=859.894`；
- `lo`（671 原有）改形为主色遮盖三角 `#68262A`（与 backrop2 同色）：`w=142.457 h=47.816 rot=33.874°`，**底边就是梯形左斜边**，顶点 `(859.894,410.30)` 落在卡片上边。矩形先画、遮盖三角后画 ⇒ 斜边干净、无竖直硬边；
- `corner`：斜边在 `y≈468` 后落到矩形左边界以左，需一枚很小的暗红等腰三角把斜边补到卡片下边（`(863.195,479.827,70.433,23.500,−146.126°)`，拟合覆盖率 100%、零溢出，面积仅占卡面 0.14%）。

> **为什么比「多一个矩形」多了一枚小三角**：零溢出约束下 `100003` 只能是等腰三角，
> 其右腰无法一路延伸到卡片下边；只留矩形时斜边会在 `y≈468` 折成竖线，底部露出 32.5px
> 竖直硬边（670 曾因同类硬边返工）。补角三角是单斜边梯形在零溢出下最省的补法，
> 仍是「多不了几个图元」：每模板可见视觉层 **4 → 8**（新增 4 = 1 矩形 + 3 三角，其中 lo 复用改形），
> 只有 670 拼接版 32 层的 25%，671 的最少图元目标不破坏。

> **100003 参数口径**：`h` 是顶点到底边的高（本地模型顶点 `(0,−h/2)`、底边 `y=+h/2`），
> 中心 = 底边中点与顶点的中点，顶点方向 `(−sin rot, −cos rot)`。本版参数由设计图边界解析推导，
> 不用手填近似值，避免边界共线处出现亚像素缝。

**描边与高亮**：`backrop1` 静态色 `#FF56565E`（灰）→ `#FF491B1E`（暗红，取主色调的约 0.70 亮度）；
**内嵌 Lua 636,660 B 与 671 逐字节相同**，其中 `HIGHLIGHT_TINT = 4294956107 (0xFFFFD44B)` 未动 ⇒ **高亮色不变**，
选中态仍只染 `backrop1` 露出的 3px 一圈。左上亮红 `#9D3033`、主色 `#68262A`、白字、26 条文本、v19 背景子树均不变。

## 五、范围与真机待验

- **本版未做游戏内导入与真实渲染验证**；离线模拟只画静态层 + 5 行模板实例，文字为占位说明。
- `100003` 在本版用了 **4 个非标准旋转角**：`−111.695°`(mid1)、`40.954°`(mid2)、`33.874°`(lo 遮盖)、`−146.126°`(corner)；
  仓库历史记录 `.gil` 图片控件个别旋转角（rot −90）曾真机不出图，671 的 225° 也仍待确认。
  若实机某个三角不出图，按 `docs/美术资产-原生图形构造与v12-v15演进.md` 用「沿斜边共线的旋转矩形」替补。
- 配色取设计图实测，暗红描边 `#491B1E` 若实机偏重/偏轻，只改 `backrop1` 的 `502`（不影响高亮）。
- 若严格坚持「梯形只多一个矩形」，可删 `corner` 层退化为「上斜下竖」折线，但底部会露 32.5px 竖直硬边，不建议。
