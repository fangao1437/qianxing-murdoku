## 迭代中修掉的问题

1. **首版亮色全高矩形把斜边盖成阶梯** → 亮矩形右边界收进斜边最左端以内，斜边只由三角长底边给出。
2. **票券被白框盖住下半** → 票券层移到 recTop 末尾。
3. **褐色封面比白框小、完全被压住** → 封面放大到 456×570，白框改 396×515，四周露出深棕带。
4. **格纹纸盖住左上返回按钮** → 背景层提前绘制 + 按实测边界收窄，MAE 93.28 → 48.29。
5. **封面/模板暗部的大三角 bbox 溢出到棋盘和相邻卡片** → 精简掉这些非必要三角，只保留 4 枚核心斜边三角；校验改为「三顶点是否落在目标矩形内」而非包围盒（压矮三角包围盒天然偏大）。
6. **撕裂凹口做成深棕菱形像铆钉** → 改为 `100002` 背景色半圆压边，形成内凹缺口。
7. **审计序列化整棵重读树导致卡死** → 只保留标量字段。

## 实机重点复核

1. **`100003` 等腰三角在非 0/90/180 角度是否出图**——项目历史实测 `rot −90` 不出图，本轮只用**正角度**（43.3° / 65.5° / 71.4°）；若真机不出图，回退方案是把这几层的 `imageId` 换成 `100001` 并保留几何，用旋转矩形长边充当斜边（651 已验证 ±45° 旋转矩形可靠）。
2. 注释票券的半圆凹口与尖角在不同背景上的观感（左端格纹纸、右端白框/橙黄）。
3. 倾斜格纹纸四周露出的宽度、橙棕封面三边虚线是否对齐、白框上沿是否被票券正确压住。
4. 两套 `clue` 模板实例化后，斜边三角是否落在网格视窗内不越到相邻行。
5. 659 的滚动条关闭状态、其它屏不漏格纹纸、问号按钮点击热区。
