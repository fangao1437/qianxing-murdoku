一、图文输入框的功能
图文输入框
可以配置在界面布局中，适用于图片和文本混排使用的情景
在图文输入框中，图片会基于文本内容的实际长度进行动态适配
二、图文输入框的编辑
1.添加图文输入框
在
界面控件组编辑窗口
，添加界面控件模板-图文输入框
2.文本框设置
字号
：图文输入框中文本的字号大小
行间距
：图文输入框中的行距，其单位为图文输入框的字号尺寸，即：实际行距尺寸=当前图文输入框字号*行间距值
3.图片设置
在图文输入框中，点击【插入图片】后可添加图片
图片不能够修改颜色；当图片源设置为【静态引用】时，无法使用素材组
位置
：图文输入框的位置，其单位为图文输入框的字号尺寸，即：实际偏移值=当前图文输入框字号*偏移值
