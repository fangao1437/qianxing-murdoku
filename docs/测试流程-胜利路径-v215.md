## 四 服务端结算（**只在会话内生效**，务必先看这段）

★★ 实测发现：**存档文件的 `serverLogic` 在加载时被忽略** ✗
（文件里明明写了 2 条规则，load 回来是 `rules: []` ✓ 已验证）

⇒ 所以本测试档的**服务端规则要单独设一次**（我已在当前会话设好，revision 7863 ✓）。
你自己复现的话，在「模拟器 → 服务端逻辑」页填这两条：

| 监听信号 | 动作 |
|---|---|
| `murdoku/solved` | 设置 `Level.solved_level` = 信号参数 1 |
| `murdoku/settle` | 设置 `Level.settle_level` = 信号参数 1；设置 `PlayerSelf.settle_win` = true |

**验收读数**（通关并点第 4 键之后）：

```
Level.solved_level  = "selftest_theft_5x5"     ← 结案判定成功
Level.settle_level  = "selftest_theft_5x5"     ← 第 4 键「存档并结算」
PlayerSelf.settle_win = true
```

- 有值 ⇒ 客户端 → 服务端这条链**通了** ✓
- 没值 ⇒ 信号没发出去 / 规则没生效 ✗
