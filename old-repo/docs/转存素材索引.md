## 用法

`lua/entry_client_script.lua` 的 `cfg.prefab_of[节点id] = 索引` + `cfg.parent_of[节点id] = 父节点`，
适配器会调 `InstantiateClientUIControl(索引, 父控件)` 把它造出来。

**⇒ 关键前提**：实例化的对象必须是「**客户端控件模板**」（带图形子层的那种）。
第一次转存失败，是因为那批是**图片素材**；这一次转存下来的**都是控件模板**，所以这条路通了。

## ⚠️ 改索引前先核对

**别凭记忆填数字** —— 索引会随每次转存变化。核对方法：

```powershell
node tools/gil/diff_ids.mjs --a="<含资产的.gil>" --b="baseline/103-干净底座-能点.gil"
```
它会列出"只在 A 里出现"的 id（新转存进来的那批），再用名字对齐即可。
