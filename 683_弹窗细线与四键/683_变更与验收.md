## 二、★ 本轮根因：为什么 682 真机「只有文字、没有按钮」

用户截图里四个按钮只剩文字、完全没有胶囊轮廓，而 682 存档里胶囊 24 层明明存在、颜色也是 `#FCECD4`。
原因不是颜色太淡，是**被运行时隐藏了**：

- 内嵌 Lua `engine_adapter_qianxing.lua` 的 `DECOR` 表只豁免**短名**
  （`label / bg / icon / face / art / frame / card / image / img / …`）。
- `Adapter:enforce_hidden_subtrees()` 对 `_hidden_ids` 里控件的**直接子控件和孙子**逐个 `SetVisible(false)`，
  只跳过 `DECOR` 命中的名字；**只会隐藏、从不恢复**。
- 682 新增的 `art682.modal.exit.capsule.body` 等是 `modal.exit` 的直接子控件，用的是**完整长名**，
  不在 DECOR ⇒ 弹窗打开时它们已被关掉；同名 `label` 是短名且在 DECOR ⇒ 幸存
  ⇒ 真机就是「四个可点的空壳 + 文字」。682 验收文档里「胶囊在米白纸面上偏淡」的判断只说对了一半。

**683 修法**：每个按钮下建一个名为 `art` 的透明 DECOR 容器（`312×64`，`#00FFFFFF`），
把 3 层填充胶囊 + 新增 3 层描边全部收进它下面。DECOR 命中后 `enforce_hidden_subtrees`
跳过**整个 if 块**（连孙子都不遍历），子树全部幸存。**内嵌 Lua 零改动**。

> 另一条同口径细节：`rim`（外圈深墨细线）挂在 `modal`/`help617` 下，也必须用 DECOR 短名 `art`；
> 且它不能挂在 `frame` 容器下 —— 容器自身是 633×600 棕框，子层更大就会把棕框盖掉。

## 三、本轮做了什么

### 1. 四键居中（只动退出菜单这一组）

- `modal.exit/save/settle/cancel`：y 228/148/68/−12 → **120/40/−40/−120**。
  682 把 633×383 旧面板换成 633×600 居中通用框后，四键仍沿用旧面板中心 108，所以整体偏上。
- `modal.settle.countdown`（「60秒后可结算」）单独移到 **y = −200**（四键下方留白）。
  若只随按钮下移到 −95，会被 683 真正显示出来的「取消」胶囊盖住 —— 682 因为胶囊被隐藏才没这个遮挡。
- 结算态 `result.*` 四键（−22/−102/−182/−262）、标题与成绩布局**保持 682 不动**。

### 2. 按钮轮廓可见（8 组 × 6 层）

| 层 | 形状 | 颜色 |
|---|---|---|
| 描边 body / 左右圆 | 256×64 矩形 + 64×64 圆 @±128 | `#6C402E` 深棕（露出 2px） |
| 填充 body / 左右圆（682 原有，仅改父级） | 252×60 矩形 + 60×60 圆 @±126 | `#FCECD4` 首页同色 |
| `label`（682 原有） | 文本 | `#6B3A22` / 24 号 |

8 个按钮共新增 8 个 DECOR 容器 + 24 层描边；填充层几何一字未改（容器中心＝按钮中心）。

### 3. 通用边框补齐（12.png，两组框）

| 新增层 | modal 633×600 | help617 760×420 | 说明 |
|---|---|---|---|
| `rim`（挂在弹窗下、frame 之前） | 637×604 `#47271A` | 764×424 | 外框最外侧深墨细线，露 2px |
| `inner.line`（paper 之后） | 583×550 `#6C402E` / 107102 | 706×366 | 内页里距边 10px 的内圈深色细线 |
| `inner.face` | 579×546 `#FFF5D6` / 107102 | 702×362 | 盖住内部，只留 2px 线 |
| `glass` | 144×144 @(8,200) | 110×110 @(8,20) | **官方图元 100120**（＝提示按钮 `hex.hint` 的放大镜），染 `#F9EFC7` |

- 放大镜**没有拼圆＋柄**：直接用存档里已有的官方素材 ID `100120`（`hex.hint` / 教程页 `ico.hint` 同款，可染色）。
- 放大镜放在四键**上方留白**（dy=200），避免居中后 144px 水印被不透明胶囊完全盖住；层序仍在按钮之下，是背景水印。
- 内圈线颜色按用户「深色细线」取深棕 `#6C402E`，比 12.png 原图的浅米黄 `#EEE1B7` 更可见；
  12.png 的红绶带、按钮占位、小叉依旧不复制。

### 4. 首页杂质矩形

`art656.home.paper.edge`（ID `1073757882`，`art657.grid.reuse` 下 `5×705 @(322,-62)`，`#FFE4D2A8`）
是 656 单独加的一条笔直细长矩形。像素复核：用户给的第 5 张图是首页截图
**x=1101..1143 / y=221..945 的精确裁剪**（模板匹配误差 0），其中 x=22..24 恒为 `#e4d2a8`、
贯穿 y=0..660，正是这条控件；设计稿与 12.png 均无此元素 ⇒ 三处同步删除
（recTop / recs / 父 childList 重算），被删 ID 全文 0 引用。

## 五、剩余差距 / 真机待验

1. **未导入游戏**。需复核：DECOR 容器 `art` 在真机确实让胶囊显示（这是本轮主修复点）、
   2px 深棕描边在真机缩放/抗锯齿下的清晰度、`107102` 拉伸后内圈线的圆角比例、
   放大镜 `100120` 染色 `#F9EFC7` 在米白纸上的深浅、放大镜放在四键上方是否嫌偏上。
2. **「杂质矩形」的定位说明**：本轮删的是纸右缘那条**笔直 3px 浅色细长矩形** `paper.edge`。
   它右侧还露出一条米黄色斜网格纸（`art656.home.grid.paper` 旋转后溢出，宽度随 y 从 26px 收到 0），
   属 656 设计内元素，本轮**未动**；若用户指的是那块米黄色楔形，下一轮单独收窄/裁掉即可。
3. 放大镜在结算态会与标题/成绩文字区域重叠（水印很淡，文字深色），需目视确认不干扰阅读。
4. 倒计时小字移到四键下方留白 y=−200，离「存档并结算」按钮较远；若嫌远可改回缝隙位置，
   但需同时缩小字号/高度并调整层序，否则会被胶囊盖住。
5. 7621 条记录的加载性能、两组通用框新增 8 层后的层序观感。
