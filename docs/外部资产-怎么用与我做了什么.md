## 零、★ 结论：图像编辑器的 `.gia` **本来就不是给"外部资产"用的**

导入失败后，我拿**你能用的那个 `100+家具分享.gia`** 当模板，逐字段对比，差异一目了然：

| | `100+家具分享.gia`（能导入）| 我生成的 `btn-hex.gia` |
|---|---|---|
| 顶层结构 | **一堆 `#1`**（每个 ~705 字节 = 一个资产）| `#1` + `#3` + `#5` + 一堆 `#2` |
| 资产类型 `#1.#3` | **2** | 8 |
| `#5` | **3** | 61 |
| 数据字段 | **`#12`** | `#19` |
| 文件名 `#3` | 无 | **`170427528-…-\image_template.gia`** |

**⇒ 最后一行是答案**：我导出的那份**文件名里就写着 `image_template`** ✅
—— 它是 **「图片控件模板」**，不是「游戏素材」❌。

**⇒ 而图像编辑器自己的说明就写了它要怎么用** ✅：

```
export.lua.setup: "填写脚本中的 IMAGE_PREFAB_ID（图片控件模板索引），挂到专用空客户端容器节点。"
```

**⇒ 所以它的正路是 `.lua` + `.gia` 配一对**：`.gia` 是模板、`.lua` 是绘制脚本 ✅。

### 导出的 `.lua` 才是能用的东西

我拿六边形试了 `/api/export/lua`，得到的是一份**完整自解释的客户端绘制脚本**（7215 字符）：

```lua
-- 1. 准备一个客户端图片控件，设为「仅存为模板」。关闭模板遮罩/羽化。
-- 2. 必填：将下面 IMAGE_PREFAB_ID = 0 改为该图片控件的「控件模板索引ID」。
-- 3. 挂载：创建专用空客户端容器节点，将本文件作为客户端脚本挂到该节点。
--    进入运行预览即绘制（OnStart）。脚本会设置该节点尺寸，
--    请不要挂在已有界面的根节点上。
local IMAGE_PREFAB_ID = 0
local BASE_SCALE = 1
local OFFSET_X = 0
local OFFSET_Y = 0
local ROOT = {0.0,0.0,256.0,256.0, 0.5,0.5, ...}
-- 数据顺序：图片资产,x,y,w,h,pivotX,pivotY,anchorMinX,anchorMinY,anchorMaxX,anchorMaxY,scaleX,scaleY,rotZ,r,g,b,a
local ELEMENTS = {
  {100001, 0.0,  0.0, 176.0,102.0, ..., 0,   27,32,48,255},
  {100003, 0.0, 77.0, 176.0, 52.0, ..., 0,   27,32,48,255},
  {100003, 0.0,-77.0, 176.0, 52.0, ..., 180, 27,32,48,255},
  ...
}
```

**⇒ 它用的正是游戏自带素材 id** ✅（`100001` = 基础形状矩形、`100003` = 三角 —— 都在那 1543 个里）。

### 对我们的价值（怎么用）

那个脚本**是独立绘制脚本**，不能直接并进我们的 `ui_controller`（它要自己设节点尺寸、
且明说"不要挂在已有界面的根节点上"）。但它给了我们两样东西：

1. **一个图形设计器**：我在网页上摆好图形 ⇒ 导出 ⇒ 拿到 **`ELEMENTS` 数据**（每种图元用哪个素材 id、放在哪、多大、转多少度、什么颜色）
2. **我可以照着这份数据，在我们自己的 UI 里画** —— 用同样的素材 id、同样的坐标/颜色，
   生成我们自己的子控件（走 `sync_plan` 那条已跑熟的路）

**⇒ 也就是说：把那个网站当"设计工具"，产出物由我自己接进项目** ✅

**⇒ 两者本质不同**：参考图的观感**没法在 2D 里完全复刻**。

## 五、踩过的坑（都已修，注释在代码里）

| 坑 | 症状 |
|---|---|
| **把图像编辑器的 `.gia` 当"外部资产"** | 导入失败且无报错 —— 它是**图片控件模板**，用途不同 |
| 直接 POST 场景本身 | **422** —— body 必须是 `{ scene, giaGroupName }` |
| `'file:///' + argv[1]` 判断入口 | 路径含中文时 URL 是**百分号编码** ⇒ 永远不等 ⇒ **一行输出都没有**。用 `pathToFileURL()` |
| 头/尾按小端读 | 误报"尾标记错" —— **全是大端** |
| PowerShell `Set-Content -Encoding UTF8` 写 JSON | **加 BOM** ⇒ `JSON.parse` 失败。要 `UTF8Encoding($false)` |
| 两个三角形拼六边形 | 得到**八角星** —— 正解是**矩形+上下三角** |
