# 715 UI 自适应修订 v6：页面显隐恢复与官方比例覆盖

日期：2026-11-18。

本版沿用 v5 的构建器和适配结构，以原始 715 存档为输入重新生成独立 v6。v5、原始 715 及更早版本均保留。

## 本轮发现的历史问题

### 1. 页面显隐只有隐藏，没有恢复

原有 `apply_screen_hide` 在页面切换时只把不属于当前页的节点写成 `visible = false`，没有把当前页节点恢复为其声明状态。一个节点一旦在上一页被隐藏，返回当前页后仍可能保持隐藏，造成大量控件、背景和按钮显隐失效。

### 2. v5 适配层每帧强制打开完整背景

v5 的 `sync_adapt715r` 每次更新都会遍历新增完整背景树，并对所有子节点调用 `SetActive(true)` / `SetVisible(true)`。新增完整背景、选关背景和页面根层又都是 root 的并列子层，因此适配层会在原页面模块完成显隐切换后再次覆盖状态，造成页面串层。

## v6 修复

1. 页面显隐改为双向收口：
   - 先计算当前页面应该隐藏的节点；
   - 保存节点的声明显隐状态；
   - 当前页恢复声明状态，非当前页明确隐藏。

2. 新增完整背景按页面互斥：
   - `home`、`game`：显示完整客户端背景和底色层；
   - `select`：隐藏完整客户端背景和底色层，只保留选关页自己的背景层；
   - 弹窗不改变当前页面背景，由弹窗模块独立控制。

3. 适配层不再把非当前页面的静态根层强制设为可见；`art641.home`、`art641.select`、`art641.game` 仍由原有页面同步逻辑负责。

4. 选关页衬纸、白框、缩略图、标题、成绩文字和点击区域继续使用 v5 的同倍率布局；撕边保持 fit 等比尺寸和原始 16:9 边缘关系。

5. 火漆继续使用独立客户端父级，按完整背景的等效中心和 cover 倍率变换；拍立得仍保留在完整背景素材中，没有拆出。

## 官方比例覆盖

按官方设备选择菜单纳入以下 10 种组合：

| 设备 | 比例 |
|---|---|
| PC | 16:9、21:9 |
| 触屏设备 | 16:9、19.5:9、4:3 |
| 主机手柄 | 16:9、21:9 |
| 移动手柄 | 16:9、19.5:9、4:3 |

运行时按当前画布宽高比，在对应设备支持的比例中选择最近档位。四种比例常量均已写入运行时：16:9、21:9、19.5:9、4:3。

## 实机边界

本轮完成的是存档和 Lua 运行时的离线回归。尚未操作游戏导入 v6，也没有把离线模拟当成真实渲染通过。实际设备仍需重点观察：

1. 选关页返回后是否只保留选关背景；
2. 打开结果弹窗时是否只叠加当前页面弹窗；
3. 触屏 4:3、触屏 19.5:9、移动手柄 4:3 是否出现背景裁切过量或控件越界；
4. PC 21:9 和主机手柄 21:9 的完整背景、火漆与撕边是否保持预期露出关系。

原始 715、v1–v5 成品均保留。本轮未发布内容、未删除用户磁盘文件、未修改系统设置。
