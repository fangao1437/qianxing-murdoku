## 6. 已知风险 / 边界

1. **容器位置口径**沿用 v4：记录 `(0,0)`（相对父中心=画布中心）；真机若仍偏移 ⇒ `--container-pos=center` 一条命令对照。
2. **旋转符号**按默认（数据 rot 与 `#508/#3` 同号）；新数据 `rot≠0` 262 条，真机若方向反 ⇒ `--rot-sign=-1` 重跑。
3. **透明图元**：新数据多了"铺底大色块"（A 通道多为 FF），叠加顺序 = 数据顺序 ⇒ 色块在前（底层）、图元在后（上层）；若真机看起来仍"缝隙发白"，先确认色块是否被后面大图元盖住（属数据/顺序问题，`.gil` 只按数组顺序登记）。
4. **957 < 1000** ✓（单个界面控件组 1000 上限内）；未真机验证，只做结构与离线回读断言。
5. 编号：本轮按 lead 指定用 **509**（506 被 v305 占用、507=v4、508=lead 的 v306 合并档）。
