## 1. 改动方式（一行开关，不改写盘结构）

```powershell
node tools/gil/gen_bake_art.mjs --in=502-一二关美术-容器-v3.gil `
  --out=511-一二关美术-容器-v6.gil --child-visible=false
```

- `--child-visible`（默认 `true`）：
  - `true` = v4/v5 口径（子控件 visible=true，等脚本按关卡打开）；
  - `false` = **v6 口径**（子控件默认全关，脚本在关卡内把当前关卡的容器 + 455 个子控件**逐个** `SetVisible(true)`）。
- 为什么默认 true：保住 507/509 的可复现性；v6 出包显式传 false。
- **幂等复跑也要带同一个 flag**（`--child-visible=false`）：工具对"已存在"的子控件不重写可见性，若不带 flag，断言会按 true 口径报"可见性=隐藏"失败 —— 这是刻意的防误用检查。
