# 警局场景 UI 资产 v12（2026-11-09，按 v11 实机截图修复）

承接 v11（本仓库提交 `dfa8708`）。用户给出**原始设计图**与 **v11 实机截图**对照，指出下列问题，并在途中补充/更正了几条约束：

1. 档案袋橘红色区域边缘不够平直；
2. 旁边阴影部分上方有溢出；
3. 不同物体间的衔接没做好；
4. 拍立得的阴影表现错误；
5. 暗角有明显差异，v11 角落阴影是**矩形**的（用户先称「圆形暗角」，后更正「渊星」是笔误）；
6. 「**设计图的暗角是凹的，是从中心往周围渐暗**；你的是凸的。暗角实现 v10 及以前版本应该有提」；
7. 「若还有其它**除杯子外**的不相符之处也一并修复」；
8. 「但 v11 的**右侧渐暗**做得很好，修复暗角时**不要破坏**这个」。

本目录只保留**最终结果 + 可复现方法**，中间迭代版本不入库。

## 二、对齐口径

- 实机截图 1604×960，白色标题栏到 y≈58 ⇒ 游戏画布 **`crop(4,58,1600,900)`**。
- 原始设计图 1280×720 ×1.25 ⇒ 设计坐标 1600×900。
- **v11 实机截图与 `police-v11.png` 离线导出逐像素一致**（背景采样差 0~1，全图均值差 3.08，差异集中在文字），因此可以完全离线迭代。
- 用 `scene-no-cup.png`(A) 与 `background.png`(B) 逐像素差分剥出前景，再做紧阈值颜色分类 + 逐行边界拟合；单纯颜色阈值会被背景暗角污染。
- 暗角评分用原始设计图/`background.png` 的 131 个干净背景采样点（排除胶带、文字、爪印、黑边）。

### 暗角：为什么回到 v10 的 106060

`finalize-v10.cjs` / `build-v5~v10.cjs` 里明确记录过：

> `vignette: { name: '官方暗角（不再用圆环）', assetId: 106060, recipe: '单层 106060 染黑，1800×1040 铺满，opacity 1' }`
> `knownDiffs: ['暗角是径向渐变，原设计图右侧另有额外压暗']`

即**设计图 = 官方径向渐晕（凹形）+ 右侧额外压暗**。v11 修好了「右侧额外压暗」（52 条渐变条），却把「径向渐晕」换成了 4 个 `106056` 大方块，于是变成矩形硬块。v12 把两者重新组合起来：

```
底色 → v11 的 52 条右侧渐变条 → 官方 106060 径向渐晕 → 阴影四边形 → 上下黑边 → 爪印 → 胶带 → 物件
```

**顺序是关键**：渐晕必须画在渐变条**之上**。若放在其下，渐变条只覆盖 x≥1080，会在 x=1080 处留下一条竖直硬边（候选导出图里可见）；放在其上则整幅连续，且 `106060` 大尺寸在中线 alpha 极小，右侧渐暗几乎不受影响。渐晕仍画在胶带/物件**之下**，所以胶带保持明亮。

### 暗角方案选型（实测排除过的坑）

| 方案 | 结果 | 结论 |
|---|---|---|
| 单个大 `106056` 柔光圆 | 中心大片恒定深色、边缘窄渐隐 | 仍是**硬边圆盘**，比 v11 更糟 |
| 多个同心 `106056` + 补偿 | MAE 12.2 | 渐隐带吸光损耗，中段偏亮 |
| **四角各 50 层同心实心圆 `100002`** | 关键点 MAE 10.4 | ❌ 圆心在四个角 ⇒ 四个**孤立凸起的圆形暗斑**，被用户指出「是凸的」，废弃 |
| 官方 `106058/106059` 强渐晕 | 四角够暗但四边中被压暗 60~90 | 整体发灰，不如 106060 |
| 多层同心官方渐晕叠加 | 数值搜索无改善 | alpha 剖面 LU/UM 比不足，叠层无法陡峭化 |
| **单层官方 `106060` 2200×1100 op1** | ✅ **凹形连续、v10 传承、右侧偏差 2.89/255** | **采用** |

累计导出 53+57+17+5 组候选，并提取 24 层 alpha 剖面做数值叠加搜索。

**已知限制**：官方 `106060` 的 alpha 剖面无法同时满足「四角 ≈50」与「四边中 ≈182」（角落/边中 alpha 比不足），因此四角仍弱于设计图。若更看重数值/保守，把渐晕参数改成 `2600×1400 op0.7`：整图 MAE 降到 11.99、`y=450` 右侧偏差仅 0.71，但暗角观感偏淡。**如果更看重四角压暗**，可以改 `1800×1040 op1`（v10 原配方，左上 85），代价是四边中偏暗、右侧偏差升到 7.49。

### 本轮新踩的坑（可复用）

1. **绘制顺序决定溢出**：v11 把上下黑边放在阴影四边形之前，阴影顶点 (1263,28) 就画到黑边上去了。黑边必须**后于**阴影、但仍**早于**胶带。
2. **扫描填充步长直接决定「平直」观感**：5.6px 步长在 45° 斜边上是肉眼可见的阶梯；≤2px 才接近实色刚体边。
3. **半透明叠条不能重叠**：`opacity 0.95` + 条带重叠 0.6px 会产生规律竖条纹，v12 深橙区改为不透明实色。
4. **`106056` 不是径向渐变素材**：它是「白心不透明 → 向外窄带渐隐」的柔影，拉伸后中心仍是大片恒定色；拿它在四角堆同心圆，得到的是四个**凸**斑而不是整幅**凹**形渐晕。整幅凹形要用官方 `106058/106059/106060`（中心透明→四周渐暗）。
5. **渐晕不能压在渐变条之下**：会在渐变条起始 x 处露出一条竖直硬边。
6. **拍立得竖直分界不能只画一个竖矩形**：相框是旋转刚体，右半必须拆成「与相框同角度的旋转矩形」+「补到竖直线的细长三角」，否则上/下边缘会出现错位台阶。

## 四、复现

1. 改 `scene-v12.json`（或 `build-v12.cjs` 顶部常量）；
2. `node build-v12.cjs` → 拼图站 `/api/export/{gia,png}`；
3. `node finalize-v12.cjs` → 模拟文字预览 + `v12-params.json`；
4. `node verify-v12.cjs` 查 root 层；`artkit.mjs check --kind=gia --file=<...>` 查容器；
5. `.gia` 放入 `BeyondLocal/Beyond_Local_Export`，游戏内「导入外部资产 → 转存所选资产」。

## 五、未验证 / 已知差异

- **未做 v12 真机导入验证**；链路与 v10/v11 一致（v10 已成功导入），需用户截图复核。
- **暗角四角强度弱于设计图**（官方 `106060` 素材 alpha 剖面限制，见上「已知限制」，附两档可调参数）。
- 设计图档案袋底部另有一片浅橙折角（透视梯形），v12 仍用刚体旋转矩形近似。
- 杯子按用户要求不在修复范围，仍缺失。
- 预览器把文本框画成固定小字；`police-v12-simulated.png` 是 48px 粗体模拟，真机中档案袋会自然遮住下带左段文字右半。
