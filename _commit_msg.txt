archive: close out the tutorial text problem and file everything it produced

The project had long held that the archive format cannot store control text,
which is why fifteen button captions were typed by hand in the editor and the
tutorial texts were planned to be filled the same way. That belief is wrong: a
full tree scan finds text in every archive, eighty one of three hundred sixty
eight records in the largest one, sitting under a fixed path inside each record
as a UTF-8 leaf, and the old probe missed it only because it walked nothing but
state blocks and ignored anything longer than sixty four bytes. A controlled
write then changed one caption and filled one empty one with all four writer
gates passing and the source archive untouched.

Applying the v356 checklist to the current build exposed what was really lost,
and it was structure rather than storage: one hundred eighty four text records
had been dropped when the pages were rebuilt, and one record had lost its text
property group entirely. Those were cloned back from the v356 archive with new
ids, corrected parent pointers and their original sibling order, after which all
nine hundred forty two checklist entries read back correctly from the written
file.

The last piece was not storage either: the text boxes were simply too small for
the engine to draw, so v361 raises the minimum height to twice the font size and
the minimum width of narrow boxes to one and a half times, keeping the centres
fixed. Re-exporting the checklist from v361 yields a file identical to the v356
design checklist, which is the closure this commit records.

Everything is filed under docs/tutorial-design/文本问题-v356到v361: the write up,
the four diagnosis reports and six verification snapshots. The tools that did
the work are the new scripts under tools/gil, from the full tree probe through
checklist comparison, filling, loss diagnosis, cloned restoration and the text
metrics fix. The intermediate builds and the final v361 archive are kept at the
repository root alongside the existing history.
