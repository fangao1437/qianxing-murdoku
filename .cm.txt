fix: grey cards clear when a piece is taken back, and report the press-time spread.

The user reported that after cancelling a placement the grey overlay never returns to normal. The
placement path sets a refill request so the grey can appear -- that was added deliberately when the
grey was first built -- and the take-back path never did, so a card could light up and never clear.
Only the "register" half was ever written; the "unregister" half was missing from the start.

The same gap covered undo and redo, which move pieces the opposite way and need the refill for the
same reason, so both now request it too. All four actions go through the existing in-place refill
rather than a RefreshItems resend, so the scroll position does not move, matching what placement
already did.

The new suite gray_unplace is written against the controller, not the core, because the core was
never wrong here -- it cleared core.placed correctly all along. The defect was whether the
controller asked for a repaint, so the assertions watch that request, and it exercises four
actions plus the full place/lift round trip including "lifting one piece must not clear another".
I verified it catches the bug by disabling the take-back request: the assertion goes red and the
file is restored byte-for-byte.

On the remaining press-time variance: the new log shows 0.50 to 1.00 and no longer monotonic, so
the drift is gone. What is left cannot be settled by reading the numbers, because "still drifting"
and "the hand is just slower sometimes" look alike in a list. So the build now prints one summary
after eight presses -- min, max, mean, and the mean of the first four against the last four. If the
second half is much larger it is still drifting and those two lines are worth sending me; if they
are close, it is hand timing, and the spread only reflects that a threshold gives no feedback about
when to let go.

Also repaired a stale mutation in the sabotage gate. One of the seven mutations still targeted the

effect" rather than passing. That is the tool catching its own staleness. Re-anchored to the
current write; all seven are caught again.
