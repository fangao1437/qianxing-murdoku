# 官方素材方案：脚本一体化（**推荐路线**）

> 2026-10-03，用户提出的关键认识：
> 「**如果我找官方素材的话就没有控件类型限制了，你就可以用脚本一体化解决了，
> 我只需要选好素材，调色位置等都可以直接走脚本**」
>
> **这是对的**，而且它把前面几轮卡住的问题一次解开。

---

## 一、为什么官方素材这条路没有限制

| 路线 | 挂载限制 | 尺寸 | 脚本能做吗 |
|---|---|---|---|
| **外部资产**（`.gia` 转存）| ❌ **只能挂服务器控件**（须在客户端容器之外）| ❌ **生成时定死，之后改不动** | ❌ 不能创建、不能改尺寸 |
| **官方素材**（游戏自带 sprite）| ✅ **无限制** | ✅ **随便改** | ✅ **`SetImage` 设图 + `imageColor` 调色 + `SetSizeDelta` 改尺寸 + 摆位置** |

**⇒ 脚本侧的三个接口，适配器里**已经在用****（`lua/engine_adapter_qianxing.lua`）：

```lua
img:SetImage(imageSource, imageId)     -- 写接口（7.1 API 文档 1503）
img.imageColor = col                    -- 乘算着色（正片叠底）
img.imageType                           -- Basic / Stretch / Sliced
```

**⇒ 也就是说**：**素材 ID + 颜色 + 尺寸 + 位置，全部脚本说了算** ✅ —— **你不用在编辑器里摆任何东西** ✅。

## 三、底板与配色

**⇒ 牌形底板**：**官方**底板-彩色**类（`107001`–`107402`，382 张）**里挑** ✅ ——

**⇒ 参考图的暖黑**：**`rgb(44, 40, 32)` = `#2C2820`**（**从你 5 张参考图逐像素采样得来**）✅

## 四、脚本一体化要做的改动（**我这一侧的清单**）

| # | 改动 | 位置 |
|---|---|---|
| **1** | 加一张**图标配置表**：`按钮名 → { imageId, color, size, pos }` | `entry_client_script.lua` 的 `cfg` |
| **2** | 加一个**通用函数** `set_icon(ctrl, imageId, color)` —— 封装 `SetImage` + `imageColor` + `imageType` | `engine_adapter_qianxing.lua` |
| **3** | **六个图标控件全部由脚本创建**（不再依赖编辑器摆放）| `ui_controller.lua` 的 `build_layout` |
| **4** | **确认卡**：默认隐藏，点 提交/重置/返回 时显示（**位置：返回菜单右侧**）| 已有 `sync_confirm()` |

**⇒ 我需要你定的只有一件事** ✅：**上面那张 ID 表要不要调整**（**或者你直接说"就按这个来"** ✅）。
