## §1 三条要求的落点

### ① 关卡外显示 → 逐子控件隐藏
真机上"父容器 `visible=false`"**不一定级联**到子控件（用户实测关卡外还能看到图元）。
⇒ 适配层 `baked_level` 分支改成：切容器 visible 的同时，**遍历容器子控件逐个 `SetVisible(show)`**（455 个，只在切屏时跑一遍）。
另外 `views` 里非关卡状态一律 `baked_level = false` ⇒ 两个容器全关。

### ② 旧家具图层 → 烘焙模式下不再下发
`FurnArt.layout` 会给**所有非地毯件**都算手搭层元素，之前只看 `furn_art` 是否生成，忘了关 `furn`
⇒ 真机上**旧的手搭椅子压在静态烘焙的椅子下面**（截图里那种"米白卡片"就是它）。
⇒ v307：烘焙模式下 `furn` 只保留 **桌子 / 书架 / 地毯**（它们本来就是这一代产物）；
椅子 / 植物 / 雕像 的手搭层一律置 false。

### ③ 边缘平滑 → "色块铺底 + 只拼边缘"
按用户原话重做图元数据（`_work/art-tools/gen_art_records.py`）：
- **每件先铺 1~3 个"铺底色块"**（大而平滑的椭圆/矩形，颜色取原作主色）：把同色区域连成一片、把图元之间的缝隙盖住；
- 后面才是拟合图元（= "只拼边缘"）；同时加**平滑过滤**：最短边 <0.012 格 / 面积 <0.0004 格² / alpha <40 的碎片丢弃。
- 结果：椅子 130 条、植物 187、雕像 138（含铺底色块），比上一版更整；铺底块排在最前（先画=垫在后面）。
