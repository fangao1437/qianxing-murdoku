# 可复现构建：加载与操作延迟优化 v362

## 1. 成果概述

v362 以 `583-教程文本可见-v361.gil` 为基线，**不删功能、不改控件树**，只优化脚本执行路径。交付 `584-加载与操作延迟优化-v362.gil` 与 583 的字段级差异仅有内嵌脚本一处，且已经实机验证。

同一场景（开局 → 选关 → 第一关完整流程 → 第二关 → 第三关 → 首页）：

| 指标 | 583 内嵌 v358 | v362 | 变化 |
|---|---:|---:|---:|
| 开局 OnInit+OnStart | 797,319 | 81,731 | −90% |
| 开局后 30 帧 | 2,972,133 | 48,213 | −98% |
| 进第二关 | 2,711,938 | 253,347 | −91% |
| 关卡内稳态（每帧） | ~607 | ~328 | −46% |
| 点格子 | 658 | 276 | −58% |
| **全流程引擎调用合计** | **12,424,249** | **1,325,868** | **−89%** |
| 实例化模板节点 | 10,557 | 4,942 | −53% |

最终 5,254 个控件的路径与兄弟序号、显隐、激活、尺寸、位置、文字、图片、缩放逐行一致；47 套回归结果与旧版一致，其中 5 套旧设计断言原本就失败，并非本版新增。离线数字是引擎调用次数，不冒充毫秒；加载与操作体验以本次实机通过为准。

## 2. 九项优化模式

1. **同帧名字索引**：一趟先序限深走树建立 `Adapter:find` 索引，保留重名命中顺序；命中校验，未命中保留重查语义。
2. **按名单预取**：格子、光标容器、教程触发判据等连续查找合并走树，不改变缓存/TTL/path_map 语义。
3. **结构自检一趟计数**：`tut_verify` 不再为每个期望控件分别遍历整棵树。
4. **教程家具空闲预热**：开局 60 帧后每帧一件；打开教程时立即补齐，保持兄弟顺序。
5. **家具按 render 批次实例化**：同一渲染趟只按最终 tpl/span/offset 愿望建一次。
6. **尺寸变化就地缩放**：同模板仅尺寸、跨格或偏移变化时不销毁重建。
7. **关卡外不造家具**：所有补造路径统一遵守 `furn_level ~= false`，避免隐藏实例和换关残留。
8. **素材映射同帧缓存**：网格列表项重复读取的 assets 子项每帧只查一次。
9. **选关查找按屏门控**：`selbar/selbtn.*` 只在选关屏查找。

同时修复了换关家具愿望残留、6×6 家具反复重建及 `_furn_scale_children` 未声明变量问题。

## 4. 单命令复现

在仓库根目录执行（只需 Node.js）：

```bash
node tools/build_perf_v362.mjs
```

构建器会依次：

1. 校验 583 基线 SHA256；
2. 对 `dist/client_script.lua` 做 Lua 5.3 LOAD/RUN；
3. 将 v362 脚本嵌入 583，输出 `tools/perf_faithful/out/584-v362.rebuilt.gil`；
4. 将输出与交付 584 逐字节比较，并核对交付 SHA256。

看到 `REPRODUCIBLE BUILD OK` 才表示构建成功。手工等价命令：

```bash
node tools/lua53check/check.cjs dist/client_script.lua --run
node tools/gil/embed_script.mjs \
  --in="583-教程文本可见-v361.gil" \
  --out="tools/perf_faithful/out/584-v362.rebuilt.gil" \
  --expect-marker=v362
cmp "tools/perf_faithful/out/584-v362.rebuilt.gil" "584-加载与操作延迟优化-v362.gil"
```

从 Lua 源码重新生成 `dist` 时，先执行项目既有打包器，再运行上述构建器：

```bash
lua tools/bundle_client_script.lua
node tools/build_perf_v362.mjs
```

```bash
node tools/perf_faithful/export_tree.mjs "584-加载与操作延迟优化-v362.gil"
git show HEAD^:dist/client_script.lua > tools/perf_faithful/out/old.lua
lua tools/perf_faithful/bench.lua tools/perf_faithful/out/tree.lua tools/perf_faithful/out/old.lua old
lua tools/perf_faithful/bench.lua tools/perf_faithful/out/tree.lua dist/client_script.lua new
lua tools/perf_faithful/compare.lua old new
```

`compare.lua` 退出码 0 表示最终界面状态无差异。Lua 在中文路径下取不到参数时，按 `tools/perf_faithful/README.md` 使用 ASCII 相对路径。

## 6. 回退开关与边界

排障可分别设置：`find_index=false`、`prefetch=false`、`furn_batch=false`、`furn_rebuild_on_resize=true`，或给教程实例设置 `eager_furniture=true`。这些开关用于定位，不是默认构建配置。

本版未删除旧 `teach.*` 控件、未剥离注释、未修改 `enable_cursor` 收敛条件，也未顺手改写 5 套旧设计测试。完整回执见 `docs/回执-加载与操作延迟优化-v362.md`。
