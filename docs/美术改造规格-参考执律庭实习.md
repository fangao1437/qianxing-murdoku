## 一、选关界面（参考 `2317A88F…` / `C0025148…`）

**布局**：

```
┌──────────────────────────────────────────────────────────┐
│  ↰（返回箭头，左上角）                                     │
│                                                          │
│   ┌──────────┐   ┌──────────┐   ┌──────────┐            │
│   │ 关卡名字  │   │ 关卡名字  │   │ 关卡名字  │  ← 米色纸条标题
│   │ ┌──────┐ │   │ ┌──────┐ │   │ ┌──────┐ │            │
│   │ │棋盘缩略│ │   │ │棋盘缩略│ │   │ │棋盘缩略│ │  ← 关卡的真实布局预览
│   │ └──────┘ │   │ └──────┘ │   │ └──────┘ │            │
│   │ 9x9 8名…  │   │ 5x5 4名…  │   │ 7x7 6名…  │  ← 网格尺寸 + 人数
│   └──────────┘   └──────────┘   └──────────┘            │
│   ▬▬▬▬▬●───────────────（横向滚动条）                     │
└──────────────────────────────────────────────────────────┘
```

**要点**：
1. **卡片是"深色板夹 + 四角胶带"** 的拟物风格，不是普通按钮
2. **卡片中间是关卡棋盘的真实缩略图** —— **这是最关键的一点**：
   一眼能看出这关多大、房间怎么分
3. 标题在**米色纸纸条**上，卡片下方是 `NxN　M名嫌疑人+1名受害人`
4. **横向滚动**（卡片多于 3 张时可滑）

**⇒ 我们对齐方案**：
- 卡片控件已在 `.gil`（`select.card.1..8`）⇒ 继续用
- **缩略图**：用**子控件拼**（每关一个 N×N 的小格子矩阵）。
  ⚠️ 这需要**按关卡动态建控件** ⇒ 属于"运行时生成"那一类，只能走脚本
  （或用 `ReferenceControl` 模板 + `instantiate`，和棋盘格子同一套机制）
- 标题与尺寸文字：脚本写（文字存不进 `.gil`）

## 二、局内 UI（参考 `8174665A…`）

### 2.1 左侧面板 = **两张可滚动列表**

```
┌─ 返回菜单 ↰ ─┐
└─ 重置关卡 ↻ ─┘
┌───────────────────────────┐
│ ◉  坐在"一把椅子"上    [B] │  ← 深色圆角卡
│───────────────────────────│
│ ◉  唯一"站在地毯"上的人 [C] │  ← **选中态：白色描边 + 手绘勾边**
│───────────────────────────│
│ ◉  在"卧室"里          [D] │
│───────────────────────────│
│         ▐（细滚动条）      │
└───────────────────────────┘
```

**每条线索卡的构成**（从左到右）：
1. **人物头像**（圆形/异形图标，按角色配色）—— 可用 `portrait.*`
2. **线索文字**，其中**关键字标红**（"一把椅子"/"站在地毯上"/"卧室"）
3. **右侧字母徽章**（B / C / D）= 嫌疑人编号
4. 卡片是**深色底 + 圆角 + 淡边框**；选中时**白描边 + 手绘感**

**⇒ 我们对齐方案**：
- 现有 `clue.*` 是平铺的卡片 ⇒ 改成**竖向滚动列表**（带滚动条）
- **关键字标红**：文字只能脚本写 ⇒ 需要**拆成多个文本子控件**
  （前缀 / 红字 / 后缀），或者整条用一个文本框 + 不做红字（降级方案）
- 人物头像：我们已有 `portrait.*` 调色板 ⇒ 直接用
- **滚动**：✅ 官方有「网格视窗控件」（见缓存 `mhfkrr0i7gds`）—— 需要查它能不能做滚动列表

### 2.2 右侧三个六边形按钮

参考图上是**人形 / ✕ / 铅笔** 三个深色六边形 ✅。

**⇒ 用户要求**：「右侧那三个按键就改成我们右上那三个」
**⇒ 即把我们右上角现有的三个按钮**（`action.undo` 撤销 / `action.redo` 重做 / `action.submit` 提交，
或 `action.hint` 提示 / `action.reveal` 揭示 —— **待用户确认是哪三个**）
**挪到右侧、改成这种深色六边形样式**。

### 2.3 棋盘

参考图的棋盘：
- **房间用颜色区分**（米/蓝/绿…），**每个房间在右下角写房间名**（餐厅/厨房/前院/门廊/卧室）
- **家具图标**（椅子/床/盆栽/箱子）铺在格子里
- **粗黑网格线 + 黑色外框**，整体像"桌游板"

**⇒ 我们对齐方案**：
- 房间染色：✅ 已有 `room_color`（`imageColor` 乘算着色）—— 与参考图思路一致
- **房间名标签**：⚠️ 新增，需要我们有关卡的房间名数据 + 脚本写文字
- **家具图标**：现在 `obj` 子控件是占位（白图）⇒ 需要**成对配 `imageSource`+`imageId`**
  （按《工作约定》：**直改 `.gil`**）
- **粗黑网格 + 外框**：可通过墙/门素材 + 底板实现

## 三、改造优先级（建议）

| 序 | 项 | 走哪条路 | 依赖 |
|---|---|---|---|
| **1** | 选关卡片：标题 + 尺寸/人数文字 | 脚本（文字） | 无 |
| **2** | 选关卡片：**棋盘缩略图** | 脚本（按关卡建小格子）或模板 instantiate | 需要先定"缩略图用什么素材" |
| **3** | 左侧线索卡：**改可滚动列表** | 待查「网格视窗控件」能否滚动 ⇒ 决定走控件还是脚本 | 官方文档 mhfkrr0i7gds |
| **4** | 线索卡：关键字标红 | 脚本（拆文本子控件） | 需要 `.gil` 里加红字子控件（直改控件） |
| **5** | 右侧三按钮：挪位 + 六边形样式 | **直改 `.gil`**（几何/素材）+ 脚本（文字/事件） | 需确认是哪三个 |
| **6** | 棋盘：房间名标签 | 脚本（文字）+ 关卡数据补 `room_name` | 需要关卡数据 |
| **7** | 棋盘：家具图标 | **直改 `.gil`**（配 `obj` 的成对 source+id） | 需要美术素材 |
