## 一、★ 先回答你的问题：引用了模板，为什么没有线索条出现 ✗

★ 按**官方文档**，最可能的**四个原因**（★ 按嫌疑排序 ✓）：

### ① ★★ 最可能：★ **模板配错了位置** ✓

★ 文档原文（《网格视窗控件》§2 列表项来源）✓：

> ★「**引用控件模板：**网格视窗的列表项将以此控件模板为基础显示」
> ★「**注意：**★ **仅配置在列表项来源中的模板**可应用网格视窗的列表滚动效果，
>    ★ **配置在网格视窗层级下的控件不会应用此效果**」

⇒ ★★ 即：★ **把模板拖成网格视窗的子节点是无效的** ✗
   ★ 必须在编辑器里选中网格视窗 ✓ ★ 在「**列表项来源 → 引用控件模板**」**那一栏**填/选它 ✓✓

### ② ★★ 次可能：★ **预览数量是 0** ✗

★ 文档原文（§1 列表设置）✓：

> ★「**排列限制和预览数量：**将**预览数量**对应的列表项**展示在界面中**，
>    以模拟实际运行时的效果」

⇒ ★★ 即：★ **编辑器里能不能"看见"若干项，取决于「预览数量」** ✓
   ⇒ ★ 若它是 0 ✗ ⇒ ★ **编辑器里一项都不画** ✓（★ 你会以为"没出现" ✓）
   ★ **先把它设成 3~5** ✓ 再看 ✓

### ③ ★ **列表项大小 / 边距 是 0** ✗

★ 文档原文（§1）✓：「**列表项大小**：决定列表中每项内容的宽度和高度」
   ★「**边距**：决定列表内容距离网格视窗控件顶部、底部、左边、右边的距离」

⇒ ★ 若**列表项大小 = 0** ✗ 或★ **边距把内容挤到框外** ✗ ⇒ ★ 项存在但**看不见** ✓

### ④ ★★ 运行时：★ **复用列表只加载"可见范围内"的项** ✓

★ 文档原文（§2 实现原理）✓：

> ★「网格视窗的列表**采用复用列表结构**，出于性能考虑，
>    ★ **仅会加载处于可见范围内的列表项**」
> ★「网格视窗列表发生滚动时：对列表项内容进行刷新（触发回调），
>    可以使用接口 **`RefreshItems`** 触发」

⇒ ★★ 两个后果 ✓：
```
★ ① ★ 运行时**必须先 `RefreshItems(n, 回调)`** ✗ —— ★ 否则列表项根本不建 ✓
   ★★ 而 ★ `itemCount` 在 API 里是【**只读**】✗✓（★ 见 §三 ✓）
     ⇒ ★★★ **数量只能通过 `RefreshItems` 给** ✓ —— ★ 写 `itemCount = 8` 是**无效**的 ✓
★ ② ★ 看不见的项**本来就不会建** ✓ ⇒ ★ 排查时要**先滚一下**或★ **把数量设小** ✓
```

⇒ ★ 若整个界面什么都不显示 ✗ ⇒ ★ **先查这个** ✓（★ 而不是查网格视窗 ✓）

### 第 1 步：★ 先把「模板」做成客户端模板 ✓

```
★ ① ★ 做一个**单项**控件 ✓（★ 即"线索条" ✓）—— ★ 建议结构 ✓：
   ★ 容器（★ 项根 ✓）
```

### 第 3 步：★ 脚本侧（★ 关键：只能用 `RefreshItems` 给数量 ✓）

```lua
-- ★ 取到网格视窗（★ 按控件名找 ✓）
local grid = <按你们的方式取到 ClientUIGridScrollerControl>
if grid == nil then print("[grid] 找不到网格视窗") return end

-- ★★ 两个"读得到"的字段（★ 用来确认配置对不对 ✓）
print("[grid] itemPrefabIndex = " .. tostring(grid.itemPrefabIndex))   -- ★ 必须等于模板索引 ✓
print("[grid] itemCount(改前) = " .. tostring(grid.itemCount))         -- ★ 通常是 0 ✓

-- ★★★ 唯一能给数量的接口 ✓
--     ★ 回调签名：fun(control: ClientUIBaseControl, index: integer)
grid:RefreshItems(#rows, function(control, index)      -- ★ rows = 你的线索数据 ✓
    local row = rows[index]
    if row == nil then return end
    local who  = control:GetChild("who")
    local text = control:GetChild("text")
    if who  ~= nil then who.text  = row.who  end       -- ★ 文本字段名以你们的控件为准 ✓
    if text ~= nil then text.text = row.text end
end)

-- ★ 想滚到某一条（★ 例如"回到顶部" ✓）
grid:ScrollToItemAt(1, Enum.ScrollAlignType.Top)       -- ★ 枚举见下 ✓
```

### 第 4 步：★ 自查命令（★ 抄这段就能定位 ✓）

```lua
-- ★ 一次性体检：把"为什么看不见"的四个原因一次打全 ✓
local function grid_check(grid)
    if grid == nil then print("[grid] ✗ 控件本身取不到") return end
    print("[grid] itemPrefabIndex = " .. tostring(grid.itemPrefabIndex) ..
          "   ← ★ 若为 0/nil ⇒ 列表项来源没配上 ✗")
    print("[grid] itemCount = " .. tostring(grid.itemCount) ..
          "   ← ★ 运行时为 0 是正常的（还没 RefreshItems）✓")
    print("[grid] scrollDirection = " .. tostring(grid.scrollDirection))
    print("[grid] layoutConstraint = " .. tostring(grid.layoutConstraint) ..
          "  fixedCount = " .. tostring(grid.layoutConstraintFixedCount))
    local x, y = grid:GetItemSize()
    print("[grid] GetItemSize = " .. tostring(x) .. " x " .. tostring(y) ..
          "   ← ★ 若为 0 ⇒ 列表项大小没填 ✗")
    local t, b, l, r = grid:GetPadding()
    print("[grid] GetPadding = " .. tostring(t) .. "/" .. tostring(b) .. "/" ..
          tostring(l) .. "/" .. tostring(r))
    print("[grid] GetContentLength = " .. tostring(grid:GetContentLength()))
    local kids = grid:GetChildren()
    print("[grid] 子控件数 = " .. tostring(#kids) ..
          "   ← ★ 网格视窗层级下的控件【不参与】滚动列表 ✗（文档明确 ✓）")
end
```

★ **读法** ✓：
```
★★ `itemPrefabIndex == 0 or nil` ✗ ⇒ ★ **[列表项来源] 没配** ✓ ← ★ **最常见** ✓
★★ `GetItemSize()` 返回 0 ✗        ⇒ ★ **[列表项大小] 没填** ✓
★★ `itemCount == 0` 且★ 已 Roll ✗   ⇒ ★ **`RefreshItems` 没调 / 回调里 return 掉了** ✓
★ 子控件数 > 0 而★ 项不出现 ✗       ⇒ ★ 那些子控件**不参与**列表 ✓（★ 文档明确 ✓）
```

## 四、★★ 与 40 轮查实事实的交叉（★ 重要 ✓）

```
★★ 网格视窗的 `itemPrefabIndex` ★ **和模板引用控件的 `referencedPrefabIndex` 是同一套机制** ✓
   ⇒ ★★ 所以 40 轮查实的两条**同样适用** ✓：
     ★ ① ★ **模板必须真的存在于【客户端模板】里** ✓ ⇒ ★ 没"存为客户端模板"就选不到 ✓
     ★ ② ★ 索引会**冲突** ✗ —— ★ guid 空间在服务端控件与客户端模板间**共享** ✓
       ⇒ ★ 若模板索引与某个**服务端控件**撞号 ✗ ⇒ ★ 模板会被**丢弃** ✓
       ⇒ ★★ 现象与"引用了但没出现"**完全一样** ✓✓
★ 判据 ✓：★ 运行时读 ★ `grid.itemPrefabIndex` ✓ —— ★ 若它与你在编辑器里填的**不一致**（★ 变成 0 ✓）
   ⇒ ★★ 就是**被丢弃/没配上** ✓
```
