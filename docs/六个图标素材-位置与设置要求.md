## 四、设置要求（逐项）

| 项 | 要求 |
|---|---|
| **图片** | **静态引用 → 选中对应素材**（不是"动态引用"） |
| **尺寸** | **按上表** —— ⚠️ **尺寸改不动，不对就回"生成素材"那步重做** |
| **父子关系** | **必须挂在客户端控件容器之外**（例如直接挂 `root`，或与 `topbar`/`right` 平级） |
| **层级** | **放在对应按钮的**下面**一层**（先摆图标，再把按钮摆上去），否则按钮的文字会被图标压住 |
| **可点性** | **不要给图标加点击事件** —— 点击由对应的按钮（`action.back` / `action.redo` / `action.hint` / `action.submit` / `action.undo` / `confirm.ok`·`confirm.no`）负责 |
| **按屏显隐** | **不用你管** —— 脚本会按屏（主页/选关/关卡内）对它们 `SetVisible` |
| **命名** | **请按上表的控件名**（`hex.back` 等）—— 脚本靠名字找它们；换了名请告诉我 |
