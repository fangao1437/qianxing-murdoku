# 回执 —— 头像专用层 `portrait`（家具不再盖住放置的头像）· v283（2026-10-20）

> 用户原话：「**查看最新版本，基于最新版处理一个几何问题，现在家具图层会盖在放置的头像上，把这个问题解决**」
> 基线：`存档/470-遗留清理-v282.gil`（最新版 v282）
> 交付：★ **`472-头像层-v283.gil`**（1,617,307 B / **371** 条 / 内嵌 **v283**，在工程根目录）

## 〇 一句话

头像原来画在 **face（最底层）**，而家具 `obj` 在它上面 ⇒ 一放人就只看见家具。
`face` 是不透明的房间色板，**不能**简单对调（会把家具整个盖掉）。
⇒ 给模板**补一层 `portrait`**（克隆自 `face`），层序插在 **obj 之上、wall 之下**，头像改画这一层；
房间色仍留在 `face` ⇒ **有棋子的格子连房间色也不会丢了**（以前被白色顶掉）。

## 一 改了什么

| 层 | 改动 |

| 界面层 | 格子的 `tint` **一律房间色**（撤掉 2026-10-16 那条"有棋子时下发白色"的权宜修法 —— 头像已经不在 face 上了） |
| 测试 | 新增 `tests/portrait_layer.lua`（**12 条**）；`tests/card_fit_gate.lua` ③ 的贴格判据从 `face` 换成 `portrait`（10/0） |

## 二 为什么不是"直接把 obj 挪到 face 之下"

`face` 是**不透明**的房间色板（100001 + 房间色）。家具放到它下面 = 被整块盖住 ⇒ 家具永远看不见 ✗
（这正是 v281 刚修完"家具不显示"的那个方向，不能又退回去）
