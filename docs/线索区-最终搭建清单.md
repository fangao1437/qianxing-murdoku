## 一、每个控件的类型与能力

| 控件 | 编辑器里加的类型 | 脚本接口 | 能收光标事件 |
|---|---|---|---|
| `clues` | **容器节点** | `ClientUIContainerControl` | ❌ |
| `clue.1..5` | **预设按钮** | `ClientUIPresetButtonControl` | ✅ **必须用这个** |
| `clues.bg` / `.track` / `.knob`、`clue.i.face` / `.plate` | **图片** | `ClientUIImageControl` | ❌ |
| `clue.i.who` / `.what` / `.letter` | **文本框** | `ClientUITextControl` | ❌ |
| `clues.bar` | **预设按钮**（隐形）| 同上 | ✅ |

**三条硬规则**：
1. 要收点击的只能用「**预设按钮**」或「光标检测区域」——容器与文本框都**不接受**光标事件。
2. 「预设按钮」自己不画东西，外观来自状态节点引用的子控件；但**往它下面加图片子控件、不动状态节点也照常显示**。
3. **容器节点什么都不画** ⇒ 底板必须用**图片子控件** `clues.bg` 来做。

## 三、铺排要说清的四点

1. **文本框 `H ≥ 字号 + 6`**：本工程字号 24 ⇒ 给 30；**名字用字号 20 ⇒ 给 26**。
   依据：`docs/编辑器搭建指南.md:119-121` —— **装不下时实机会裁掉文字，编辑器预览不裁**（H=20 就是踩过的那次）。
2. **正文那一格 180×56**（可 2~3 行）—— 这就是把名字挪到头像上方换来的空间。
3. **名字与头像同轴**：两者中心 X 都是 **85.5** ✓
4. **滚动条只有条、没有 ▲▼**（按用户要求去掉）。滚动靠「**点轨道翻页 + 拖滑块**」。
   ⚠️ **未验证**：引擎是否支持"拖动"事件（现有资料只确认了**点击**）；16 宽的条在手机上可能难按。
   回退：加宽 `clues.bar`（视觉不变，它是隐形的）／用卡片区滑动／恢复小号 ▲▼。
